# Первые шаги

VKUI — библиотека адаптивных React-компонентов для веб-приложений. В её основе — одноимённая [дизайн-система ВКонтакте](https://www.figma.com/@vk).

</Overview>

Подробнее о библиотеке — в разделе [«Обзор»](../about/).

## Быстрый старт

Отправьте этот промпт агенту, чтобы подключить VKUI к проекту.

```md copy wrap
Подключи `@vkontakte/vkui` к проекту.

1. Установи `@vkontakte/vkui` через пакетный менеджер проекта.
2. Проверь, что зависимости проекта соответствуют требованиям из `peerDependencies` установленной версии `@vkontakte/vkui`.
3. Если в проекте нет `AGENTS.md`, создай его. Добавь в файл правило о том, что перед использованием VKUI нужно прочитать `node_modules/@vkontakte/vkui/docs/llms.txt`.
```

Затем можно попробовать компоненты VKUI на примере простого счётчика.

```md filename="Пример" copy
Добавь в приложение счётчик с кнопками `−` и `+`.
Для интерфейса используй только компоненты VKUI.
```
