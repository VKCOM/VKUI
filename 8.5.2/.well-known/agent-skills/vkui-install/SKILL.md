# Установка VKUI

Подключи `@vkontakte/vkui` к проекту.

1. Установи `@vkontakte/vkui` через пакетный менеджер проекта.
2. Проверь, что зависимости проекта соответствуют требованиям из `peerDependencies` установленной версии `@vkontakte/vkui`.
3. Если в проекте нет `AGENTS.md`, создай его. Добавь в файл правило о том, что перед использованием VKUI нужно прочитать `node_modules/@vkontakte/vkui/docs/llms.txt`.
