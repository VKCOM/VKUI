<Overview type="doc">
# MCP-сервер

Подключите MCP-сервер VKUI к Cursor, Claude Desktop или другому MCP-клиенту. Ассистент сможет искать компоненты и хуки, читать их документацию и находить примеры кода и рекомендации по миграции.

</Overview>

## Зачем нужен [#why]

- Узнать, какие свойства принимает компонент.
- Найти пример использования компонента или хука по имени или идентификатору (`slug`).
- Проверить, как обновить код при переходе на новую мажорную версию VKUI.

Сервер загружает данные из CDN VKUI для выбранной версии библиотеки.

## Что такое MCP [#what-is-mcp]

Model Context Protocol (MCP) — открытый протокол, через который ИИ-ассистенты получают доступ к внешним данным и инструментам. Клиент вызывает инструменты, чтобы выполнить запрос, и читает ресурсы напрямую по URI. [Model Context Protocol](https://modelcontextprotocol.io/)

## Подключение [#setup]

### Подключение к MCP-клиенту [#setup-client]

Для запуска MCP-сервера нужен Node.js. Выберите свой клиент и добавьте команду запуска.

<McpClientsTabs>
  <McpClientsTab id="cursor" title="Cursor">
    Добавьте конфигурацию сервера в `.cursor/mcp.json`.

    ```json
    {
      "mcpServers": {
        "vkui": {
          "command": "npx",
          "args": ["-y", "@vkontakte/vkui-mcp"]
        }
      }
    }
    ```

    [Настройка MCP в Cursor](https://cursor.com/docs/context/mcp#installing-mcp-servers)
  </McpClientsTab>

  <McpClientsTab id="vscode" title="VS Code">
    Выполните команду в терминале.

    ```bash
    code --add-mcp '{"name":"vkui","command":"npx","args":["-y","@vkontakte/vkui-mcp"]}'
    ```

    Сервер также можно добавить через конфигурационный файл VS Code.

    ```json
    {
      "mcpServers": {
        "vkui": {
          "command": "npx",
          "args": ["-y", "@vkontakte/vkui-mcp"]
        }
      }
    }
    ```

    [Настройка MCP в VS Code](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_add-an-mcp-server)
  </McpClientsTab>

  <McpClientsTab id="claude-code" title="Claude Code">
    Выполните команду в терминале.

    ```bash
    claude mcp add vkui npx -y @vkontakte/vkui-mcp
    ```

    [Настройка MCP в Claude Code](https://docs.claude.com/en/docs/claude-code/mcp)
  </McpClientsTab>

  <McpClientsTab id="codex" title="Codex">
    Добавьте конфигурацию сервера в `~/.codex/config.toml`.

    ```toml
    [mcp_servers.vkui]
    command = "npx"
    args = ["-y", "@vkontakte/vkui-mcp"]
    ```

    [Настройка MCP в Codex](https://github.com/openai/codex/blob/main/docs/config.md#mcp_servers)
  </McpClientsTab>

  <McpClientsTab id="gemini-cli" title="Gemini CLI">
    Выполните команду в терминале.

    ```bash
    gemini mcp add vkui npx -y @vkontakte/vkui-mcp
    ```

    [Настройка MCP в Gemini CLI](https://github.com/google-gemini/gemini-cli/blob/main/docs/tools/mcp-server.md#how-to-set-up-your-mcp-server)
  </McpClientsTab>

  <McpClientsTab id="other" title="Other">
    Добавьте параметры запуска в конфигурационный файл клиента. Путь к файлу и его формат зависят от клиента.

    ```json
    {
      "mcpServers": {
        "vkui": {
          "command": "npx",
          "args": ["-y", "@vkontakte/vkui-mcp"]
        }
      }
    }
    ```
  </McpClientsTab>
</McpClientsTabs>

Флаг `-y` позволяет `npx` установить пакет без запроса подтверждения.

### Установка в проект [#setup-install]

Чтобы зафиксировать версию MCP-сервера в проекте, установите его как зависимость для разработки.

```bash
npm install -D @vkontakte/vkui-mcp
# или
yarn add -D @vkontakte/vkui-mcp
```

В конфигурации MCP укажите абсолютный путь к точке входа установленного пакета. Замените `/path/to/project` на путь к корню своего проекта.

```json
{
  "mcpServers": {
    "vkui": {
      "command": "node",
      "args": ["/path/to/project/node_modules/@vkontakte/vkui-mcp/dist/cli.js"]
    }
  }
}
```

## Переменные окружения [#env]

| Переменная | Описание |
|------------|----------|
| `DATA_URL` | Базовый URL данных. По умолчанию — `https://vkui-mcp.cdn-vk.ru`. |
| `VKUI_VERSION` | Версия VKUI, для которой сервер запрашивает данные. По умолчанию — `latest`. Адрес запроса имеет вид `{DATA_URL}/{VKUI_VERSION}/...`. |

Сервер поддерживает следующие версии VKUI.

- v7 — `7.5.4`, `7.6.4`, `7.7.2`, `7.8.2`, `7.9.2`, `7.10.2` и `7.11.7`.
- v8 — все версии начиная с `8.0.1`.

Задайте переменные в секции `env` конфигурации MCP. В примере сервер использует документацию VKUI `8.1.0`.

```json
{
  "mcpServers": {
    "vkui": {
      "command": "npx",
      "args": ["-y", "@vkontakte/vkui-mcp"],
      "env": {
        "VKUI_VERSION": "8.1.0"
      }
    }
  }
}
```

## Инструменты (Tools) [#tools]

MCP-клиент вызывает инструменты, чтобы получить нужные данные для ответа.

### Компоненты

| Инструмент | Описание |
|------------|----------|
| `list_components` | Возвращает список компонентов с именами, идентификаторами (`slug`), описаниями, количеством примеров и тегами. |
| `get_component_metadata` | Возвращает описание и свойства компонента. Передайте имя в `name` (например, `Button`) или идентификатор в `slug` (например, `button`). |

### Теги [#tags]

Теги помогают подобрать компонент по задаче. Например, тег `form` объединяет компоненты для форм.

> Инструменты для работы с тегами и поле `tags` в ответе `list_components` доступны начиная с VKUI **8.2.0**. Используйте `VKUI_VERSION` со значением `8.2.0` или новее либо оставьте `latest`.

| Инструмент | Описание |
|------------|----------|
| `list_tags` | Возвращает список доступных тегов. |
| `list_components_by_tag` | Возвращает компоненты с указанным тегом. Передайте в `tag`, например, `form`, `modal` или `navigation`. |

### Хуки

| Инструмент | Описание |
|------------|----------|
| `list_hooks` | Возвращает список хуков с именами, идентификаторами (`slug`), описаниями и количеством примеров. |
| `get_hook_metadata` | Возвращает описание и параметры хука. Передайте `name` или `slug`. |

### Примеры кода

| Инструмент | Описание |
|------------|----------|
| `get_examples` | Возвращает примеры использования компонента или хука. Передайте `name` (например, `Alert`) или `slug` (например, `alert`). |

### Документация

> Инструмент `get_docs` доступен начиная с VKUI **8.3.0**. Используйте `VKUI_VERSION` со значением `8.3.0` или новее либо оставьте `latest`.

| Инструмент | Описание |
|------------|----------|
| `get_docs` | Возвращает полную документацию компонента или хука в Markdown. Передайте `name` (например, `Button`) или `slug` (например, `button`). |

### Миграция на новые мажорные версии

| Инструмент | Описание |
|------------|----------|
| `list_migration_targets` | Возвращает имена компонентов и хуков, для которых есть рекомендации по переходу на v8. |
| `get_migration_target` | Возвращает рекомендации по миграции и может включать фрагменты кода «до» и «после». Передайте в `name` имя из ответа `list_migration_targets`. |

Примеры запросов для ассистента и обновления кода есть в руководстве [«Миграция с v7 на v8»](/migrations/migration-v8).

## Ресурсы (Resources) [#resources]

Ресурс можно прочитать по URI и добавить в контекст ассистента.

| URI | Описание |
|-----|----------|
| `vkui://migration/v8` | Обзор миграции на v8 и список всех компонентов и хуков с рекомендациями по переходу. Формат — JSON. |
| `vkui://component/{slug}` | Карточка компонента по идентификатору, например `vkui://component/button`. Список ресурсов содержит все компоненты. Доступно автодополнение по идентификатору. |
| `vkui://migration/{name}` | Рекомендации по миграции компонента или хука по имени, например `vkui://migration/Button`. Список ресурсов содержит все компоненты и хуки с рекомендациями. Доступно автодополнение по имени. |

В Cursor ресурс можно выбрать из списка или добавить по URI.
