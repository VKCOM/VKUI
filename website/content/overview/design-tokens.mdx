# Дизайн-токены

Дизайн-токены — переменные для отступов, цветов, типографики и анимаций. Компоненты VKUI используют их, чтобы получать значения из темы, выбранной для текущей платформы и цветовой схемы. [О дизайн-токенах](https://foundation.mozilla.org/en/docs/design/websites/design-tokens/)

</Overview>

Готовые наборы токенов поставляются в пакете [`@vkontakte/vkui-tokens`](https://github.com/VKCOM/vkui-tokens).

Пакет предоставляет токены в форматах `css`, `scss`, `less`, `pcss`, `styl`, `js` и `json`. VKUI использует CSS.

Каждый набор токенов объявлен в CSS-классе вида `vkui--<themeName>--<colorScheme>`. В VKUI встроены темы `vkBase`, `vkIOS` и `vkCom`, каждая со светлой и тёмной схемами. [Темы](/overview/themes)

Например, для тёмной схемы темы `vkBase` используется класс `vkui--vkBase--dark`. [CSS-файл тёмной схемы](https://esm.cdn-vk.ru/@vkontakte/vkui-tokens@4/themes/vkBaseDark/cssVars/declarations/onlyVariablesLocal.css)

Все CSS-переменные токенов начинаются с `--vkui--`. Используйте переменные подключённой темы в CSS или в свойстве `style`.

```jsx
<div style={{ color: `var(--vkui--color_accent_lime)` }}>
  Я использую цветовой токен цвета лайма.
</div>
```

## Переопределение токенов

Чтобы переопределить токен для части интерфейса, задайте новое значение CSS-переменной в классе родительского элемента.

```css filename="app-styles.css"
.forceColorRed {
  --vkui--color_text_primary: red;
}
```

В примере потомки элемента с классом `forceColorRed` наследуют значение `red` для токена `--vkui--color_text_primary`, пока на них не задано собственное значение.

Если классы темы и переопределения стоят на одном элементе, учитывайте каскад CSS. При одинаковой специфичности и в одном слое применяется правило, объявленное позже. Для набора переопределений можно создать собственную тему на основе готовой. [Документация по токенам](https://vkcom.github.io/vkui-tokens)
