# Обзор

VKUI — библиотека адаптивных React-компонентов для веб-приложений. В её основе — одноимённая [дизайн-система ВКонтакте](https://www.figma.com/@vk).

</Overview>

## Возможности VKUI [#preimushestva]

- **Адаптивность.** Компоненты подстраиваются под размер экрана смартфона, планшета или компьютера.

- **Стили для разных платформ.** Компоненты учитывают особенности интерфейсов iOS и Android и сохраняют стиль ВКонтакте. [vk.ru](https://vk.ru) · [m.vk.ru](https://m.vk.ru)

- **Цветовые схемы.** Компоненты поддерживают светлую и тёмную схемы.

## Релизный цикл

VKUI использует [семантическое версионирование](https://semver.org/).

- **Патчи** (x.y.Z) выходят по мере готовности исправлений.
- **Минорные версии** (x.Y.z) выходят один-два раза в месяц.
- **Мажорные версии** (X.y.z) с обратно несовместимыми изменениями выходят раз в год.

## Дизайн

Для работы над макетами доступны две открытые библиотеки. [VK в Figma Community](https://www.figma.com/@vk)

- **VKUI Common Library [Beta]** — компоненты для Android и настольных интерфейсов.
- **VKUI iOS Library** — компоненты и шаблоны экранов для iOS.
