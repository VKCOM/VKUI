# NativeSelect [tag:component]

Позволяет выбрать одно значение из выпадающего списка на основе HTML-элемента `select`.

Связанные компоненты:

- [`Select`](/components/select)

</Overview>

> Чтобы в контролируемом режиме показать поле без выбранного значения, передайте `value={null}`. Значение `undefined` включает неконтролируемый режим.

{/* @example-description: Базовый `NativeSelect` с набором нативных опций выбора. */}
<Playground style={{ maxWidth: 280 }}>
  ```jsx
  <FormItem top="Опция" htmlFor="native-select-native-option">
    <NativeSelect id="native-select-native-option" name="native-option">
      <option value="1">Опция 1</option>
      <option value="2">Опция 2</option>
      <option value="3">Опция 3</option>
    </NativeSelect>
  </FormItem>
  ```
</Playground>

> Используйте `NativeSelect` на мобильных устройствах. Чтобы VKUI автоматически подбирал компонент для устройства, используйте [`Select`](/components/select). Для единого оформления на всех устройствах используйте [`CustomSelect`](/components/custom-select).

## Режим работы

- В неконтролируемом режиме компонент хранит значение сам. Чтобы задать начальное значение, передайте `defaultValue`.
- В контролируемом режиме передайте текущее значение в `value` и обновляйте его в обработчике `onChange`.

Подробнее о режимах работы в [документации React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

```jsx
// Неконтролируемое состояние
<NativeSelect defaultValue="f">
  <option value="f">Женский</option>
  <option value="m">Мужской</option>
</NativeSelect>;

// Контролируемое состояние
const [gender, setGender] = React.useState('f');

<NativeSelect value={gender} onChange={(_, newGender) => setGender(newGender)}>
  <option value="f">Женский</option>
  <option value="m">Мужской</option>
</NativeSelect>;
```

## Состояния

### `disabled`

Свойство `disabled` блокирует взаимодействие с компонентом и показывает, что он недоступен.

> Чтобы также заблокировать кнопку удаления у [`FormItem`](/components/form-item#removable), задайте `disabled` и у `FormItem`.

{/* @example-description: `NativeSelect` в неактивном состоянии `disabled`. */}
<Playground style={{ maxWidth: 280 }}>
  ```jsx
  <FormItem top="Опция" htmlFor="native-select-native-select-option-2" disabled>
    <NativeSelect id="native-select-native-select-option-2" name="native-select-option-2" disabled>
      <option value="1">Опция 1</option>
    </NativeSelect>
  </FormItem>
  ```
</Playground>

## Валидация

Свойство `status` показывает результат проверки поля. Используйте `"error"` для ошибки и `"valid"` для успешной проверки.

> Если вы оборачиваете `NativeSelect` в [`FormItem`](/components/form-item), достаточно задать `status` у `FormItem`.

{/* @example-description: `NativeSelect` с результатами проверки `error` и `valid`. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <FormItem top="Опция" htmlFor="native-select-native-select-option-3" status="error">
    <NativeSelect id="native-select-native-select-option-3" name="native-select-option-3">
      <option value="1">Опция 1</option>
    </NativeSelect>
  </FormItem>
  <FormItem top="Опция" htmlFor="native-select-native-select-option-4" status="valid">
    <NativeSelect id="native-select-native-select-option-4" name="native-select-option-4">
      <option value="1">Опция 1</option>
    </NativeSelect>
  </FormItem>
  ```
</Playground>

## Кастомизация

Через `slotProps` передавайте свойства внутренним элементам, например CSS-классы, атрибуты `data-*` и `aria-*` или обработчики событий. Для доступа к элементу передайте `getRootRef`.

{/* @example-description: Кастомизация `NativeSelect` через `slotProps` и доступ к внутреннему `select` по `ref`. */}
<Playground style={{ maxWidth: 280 }}>
  ```jsx
  const selectRef = React.useRef();

  return (
    <FormItem top="Опция" htmlFor="native-select-id">
      <NativeSelect
        name="native-select-option-5"
        className="my-root-class"
        data-testid="native-select-root"
        id="native-select-id"
        slotProps={{
          root: {
            id: 'select-root-id',
          },
          select: {
            className: 'my-select-class',
            'data-test-id': 'select',
            getRootRef: selectRef,
            'aria-label': 'Пример slotProps'
          }
        }}
      >
        <option value="1">Опция 1</option>
        <option value="2">Опция 2</option>
        <option value="3">Опция 3</option>
      </NativeSelect>
    </FormItem>
  )
  ```
</Playground>

## Доступность (a11y) [#a11y]

`NativeSelect` использует HTML-элемент `select`. Свяжите заголовок со списком через `label`. Если видимого заголовка нет, задайте доступное имя через `aria-label` или `aria-labelledby`. Если у поля есть дополнительное описание, свяжите его со списком через `aria-describedby`.

Заголовок и описание можно передать через `FormItem`.
