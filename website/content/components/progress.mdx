# Progress [tag:component]

Индикатор выполнения задачи. Цвет и высоту индикатора можно настроить.

</Overview>

import { BlockWrapper } from '@/components/wrappers';

  ```jsx
  <Progress value={25} />
  ```

## Предустановленные цвета

{/* @example-description: Предустановленные варианты `Progress` для обычного, негативного и позитивного состояний. */}
<Playground Wrapper={BlockWrapper} style={{ maxWidth: 270 }}>

  ```jsx
    <Progress aria-labelledby="progresslabel" value={40} />

  <FormItem id="progresslabelNegative" top="Ошибка">
  ```

</Playground>

## Пользовательские цвета

Чтобы настроить цвет полосы прогресса, передайте HEX-код или CSS-переменную в `appearance`.

### HEX-коды

{/* @example-description: Пользовательский цвет прогресса через HEX-значение в `appearance`. */}
<Playground Wrapper={BlockWrapper} style={{ maxWidth: 270 }}>
  ```jsx
  <Progress appearance="#FFA500" value={45} />
  ```
</Playground>

### CSS-переменные

{/* @example-description: Пользовательский цвет прогресса через CSS-переменную в `appearance`. */}
<Playground Wrapper={BlockWrapper} style={{ maxWidth: 270 }}>
  ```jsx
  <div style={{ '--custom-progress': '#00FF00' }}>
    <Progress appearance="var(--custom-progress)" value={80} />
  </div>
  ```
</Playground>

## Прозрачный фон

Чтобы убрать фон полосы прогресса, передайте `trackDisable`.

{/* @example-description: Прогресс-бар без фона трека с включенным `trackDisable`. */}
<Playground Wrapper={BlockWrapper} style={{ maxWidth: 270 }}>
  ```jsx
  <Progress appearance="#FFA500" trackDisable value={65} />
  ```
</Playground>

## Доступность (a11y) [#a11y]

Компонент использует роль `progressbar` для обозначения хода выполнения задачи. [Описание роли в WAI-ARIA](https://www.w3.org/TR/wai-aria-1.2/#progressbar).
