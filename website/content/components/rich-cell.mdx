# RichCell [tag:component]

Ячейка с несколькими текстовыми блоками и действиями. Подходит для карточек пользователей, списков транзакций и других элементов с дополнительными сведениями.

</Overview>

{/* @example-description: Базовый `RichCell` с аватаром, описанием и кнопками действий. */}
<Playground>
  ```jsx
  <RichCell
    before={<Avatar size={72} />}
    overTitle="Команда ВКонтакте"
    subtitle="Санкт-Петербург"
    actions={
      <ButtonGroup mode="horizontal" gap="s" stretched>
        <Button mode="primary" size="s">
          Принять
        </Button>
        <Button mode="secondary" size="s">
          Отклонить
        </Button>
      </ButtonGroup>
    }
  >
    Илья Гришин
  </RichCell>
  ```
</Playground>

## Основные возможности

### Визуальные блоки

#### Контент в начале/в конце

В `before` передайте элементы слева от основного содержимого, в `after` — справа.

Для `before` рекомендуются аватары `Avatar` размером `40px`, `48px` и `72px`. Для `after` — иконки `RichCell.Icon` размером `28px` или короткие значения, например суммы и проценты.

> Чтобы показать дополнительные сведения внутри основного блока, используйте `meta` и `submeta`.

### Текстовые элементы

Компонент поддерживает следующие текстовые элементы:

- `overTitle` — надзаголовок;
- `subtitle` — основной подзаголовок;
- `extraSubtitle` — дополнительное описание;
- `meta` — текст после основного контента (внутри центрального блока);
- `submeta` — текст под `meta`.

### Интерактивные элементы

Для группы кнопок (`actions`) рекомендуется:

- использовать кнопки размера `s`;
- применять режимы `primary` и `secondary`.

## Выравнивание элементов

### Свойства выравнивания

Компонент поддерживает следующие свойства:

- `beforeAlign` — вертикальное выравнивание левого блока;
- `contentAlign` — вертикальное выравнивание основного содержимого;
- `afterAlign` — вертикальное выравнивание правого блока.

{/* @example-description: Настройка вертикального выравнивания блоков `before/content/after` в `RichCell`. */}
<Playground>
  ```jsx
  <RichCell
    beforeAlign="center"
    contentAlign="center"
    afterAlign="center"
    before={<Icon56WalletOutline />}
    after="+5%"
  >
    <Text weight="2">Премиум статус</Text>
    <Text>Активен до 12.12.2024</Text>
  </RichCell>
  ```
</Playground>

## Многострочный режим

Передайте `multiline`, чтобы разрешить перенос длинного текста.

### Поведение при переносе текста [#osobennosti]

Текст переносится во всех текстовых блоках. Ячейка подстраивает высоту под содержимое и сохраняет вертикальные отступы.

{/* @example-description: `RichCell` с переносом длинного текста и дополнительными сведениями. */}
<Playground>
  ```jsx
  <RichCell
    multiline
    subtitle="Длинное описание новости, которое не должно обрезаться и требует переноса на несколько строк для полного отображения информации пользователю"
    meta="15:30"
    submeta="Время публикации"
  >
    Важное обновление правил платформы
  </RichCell>
  ```
</Playground>
