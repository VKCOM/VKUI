# Tooltip [tag:component]

`Tooltip` открывает подсказку при наведении на элемент в `children` или при нажатии на него на мобильном устройстве.
Для ссылки или другого интерактивного элемента внутри подсказки включите `enableInteractive`.

</Overview>

<Playground hide>
  ```jsx
  <Tooltip hideWhenReferenceHidden strategy="absolute" disableFlipMiddleware placement="bottom" description="Привет" shown>
    <Button>Наведи</Button>
  </Tooltip>
  ```
</Playground>

## Интерактивная подсказка

Свойство `action` позволяет добавить в подсказку интерактивный элемент. Установите `enableInteractive`,
чтобы при наведении на содержимое подсказка оставалась открытой. Свойство `closable` добавляет кнопку закрытия.

{/* @example-description: Подсказка со ссылкой на документацию и кнопкой закрытия. */}
<Playground>
  ```jsx
  <Tooltip
    title="Как работают подсказки"
    description="Узнайте больше о компоненте Tooltip и его возможностях."
    action={
      <Button size="s" href="https://vkui.io/components/tooltip">
        Подробнее
      </Button>
    }
    enableInteractive
    closable
  >
    <Button>Наведи</Button>
  </Tooltip>
  ```
</Playground>

## Пользовательская стрелка

Передайте свой компонент стрелки в `ArrowIcon`.

При создании стрелки учитывайте следующие требования.

1. Нарисуйте стрелку так, чтобы она указывала вверх.
2. Чтобы на некоторых экранах между стрелкой и подсказкой не появлялся зазор, растяните кривую по высоте на `1px` и на столько же увеличьте высоту в `height` и `viewBox`. [Пример исправления](https://github.com/VKCOM/VKUI/pull/4496).
3. Компонент должен принимать стандартные SVG-атрибуты.
4. SVG и вложенные элементы должны наследовать цвет через `fill="currentColor"`.
5. Если стрелка перекрывает якорный элемент, увеличьте отступ между ним и подсказкой.

{/* @example-description: Подсказка со своей SVG-стрелкой через `ArrowIcon`. */}
<Playground>

```jsx
const ARROW_HEIGHT = 11;

const CustomIcon = (props) => {
  return (
    <svg
      width="80"
      height={ARROW_HEIGHT}
      viewBox={`0 0 80 ${ARROW_HEIGHT}`}
      xmlns="http://www.w3.org/2000/svg"
      {...props}
    >
      <path d="M40 0C33 5.5 20 10 0 10v1h80v-1C60 10 47 5.5 40 0Z" fill="currentColor" />
    </svg>
  );
};

return (
  <Tooltip
    description="У этого тултипа кастомная стрелка"
    offsetByCrossAxis={ARROW_HEIGHT}
    arrowPadding={6}
    ArrowIcon={CustomIcon}
    shown
  >
    <Button>Якорь</Button>
  </Tooltip>
);
```

</Playground>

## Хук useTooltip [#use-tooltip]

Хук `useTooltip` связывает подсказку с якорным элементом через `anchorRef` без передачи элемента в `children`.

{/* @example-description: Использование хука `useTooltip` для привязки подсказки к элементу через `anchorRef`. */}
<Playground>

```jsx
const { anchorRef, anchorProps, tooltip } = useTooltip({
  placement: 'right',
  description: 'Привет',
});

return (
  <>
    {tooltip}
    <Button getRootRef={anchorRef} {...anchorProps}>
      Наведи на меня
    </Button>
  </>
);
```

</Playground>

## Доступность (a11y) [#a11y]

### Использование `disableTriggerOnFocus`

При `disableTriggerOnFocus` подсказка открывается только при наведении. Пользователи клавиатуры и скринридеров не смогут открыть её при фокусе.

Используйте это свойство только для декоративных элементов с `aria-hidden`.

```jsx
<Tooltip
  aria-hidden="true"
  disableTriggerOnFocus
  description="Какая-то информация"
  aria-label="Тултип с какой-то информацией"
>
  <Button>Якорь</Button>
</Tooltip>
```
