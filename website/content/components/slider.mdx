# Slider [tag:component]

На горизонтальной шкале один ползунок выбирает значение, а два — границы диапазона.

</Overview>

import { BlockWrapper } from '@/components/wrappers';

{/* @example-description: Базовый одноползунковый `Slider` с начальным значением. */}
<Playground Wrapper={BlockWrapper} style={{ width: 270 }}>
  ```jsx
  <Slider defaultValue={30} />
  ```
</Playground>

## Режим работы

- В неконтролируемом режиме компонент хранит значение сам. Чтобы задать начальное значение, передайте `defaultValue`.
- В контролируемом режиме передайте текущее значение в `value` и обновляйте его в обработчике `onChange`.

Подробнее о режимах работы в [документации React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

```jsx
// Неконтролируемое состояние
<Slider step={0.2} min={0} max={1} defaultValue={0.4} />;

// Контролируемое состояние
const [valueStep, setValueStep] = useState(0.4);

<Slider step={0.2} min={0} max={1} value={valueStep} onChange={setValueStep} />;
```

## Диапазон значений

Чтобы задать диапазон значений, передайте `multiple={true}`.

Передайте массив из двух чисел `[m, n]` в `defaultValue` для неконтролируемого режима или в `value` для контролируемого. `m` — значение начального ползунка, `n` — конечного.

{/* @example-description: Диапазонный `Slider` с двумя ползунками через `multiple={true}`. */}
<Playground Wrapper={BlockWrapper} style={{ width: 270 }}>
  ```jsx
  <Slider defaultValue={[25, 75]} multiple />
  ```
</Playground>

## Размеры ползунков

Задаётся свойством `size`.

- `"s"` — маленький;
- `"m"` — средний;
- `"l"` — большой (по умолчанию).

Размеры ползунков зависят от `density`. В режиме `density="regular"` они больше, чем при `density="compact"`.

## Всплывающая подсказка

Передайте `withTooltip`, чтобы при наведении или фокусе появлялась подсказка с текущим значением. Текст подсказки задаёт компонент.

{/* @example-description: `Slider` с всплывающей подсказкой текущего значения через `withTooltip`. */}
<Playground Wrapper={BlockWrapper} style={{ width: 270 }}>
  ```jsx
  <Slider defaultValue={30} withTooltip />
  ```
</Playground>

## Состояния

### `disabled`

Свойство `disabled` блокирует взаимодействие с компонентом и показывает, что он недоступен.

{/* @example-description: `Slider` в неактивном состоянии `disabled`. */}
<Playground Wrapper={BlockWrapper} style={{ maxWidth: 270 }}>
  ```jsx
  <Slider defaultValue={30} disabled />
  ```
</Playground>

## Тестирование (e2e) [#e2e]

Чтобы находить ползунки в тестах, задайте тестовые идентификаторы.

- `startThumbTestId` — идентификатор начального ползунка.
- `endThumbTestId` — идентификатор конечного ползунка, только при `multiple={true}`.

```jsx
<Slider multiple startThumbTestId="startSlider" endThumbTestId="endSlider" />
```

## Доступность (a11y) [#a11y]

`Slider` использует HTML-элемент `input[type="range"]`. Значение можно менять стрелками влево и вправо. Компонент принимает стандартные атрибуты `aria-*`.

Чтобы скринридер объявлял назначение ползунка, задайте имя через `aria-label` или `aria-labelledby`. По умолчанию он читает числовое значение. Чтобы изменить его озвучивание, передайте `aria-valuetext` или функцию `getAriaValueText`, которая получает текущее значение ползунка. `aria-valuetext` удобно использовать в контролируемом режиме, `getAriaValueText` — в неконтролируемом.
