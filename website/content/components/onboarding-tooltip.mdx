## Когда показывать подсказку [#koncepciya]

Показывайте подсказку пользователю один раз и сохраняйте факт показа между сессиями. Рекомендуется показывать её, как только нужный элемент появляется в области просмотра. Для этого используйте [Intersection Observer API](https://developer.mozilla.org/ru/docs/Web/API/Intersection_Observer_API).

> Показывайте по одной подсказке. Открывайте следующую после закрытия текущей.

## Использование

Чтобы добавить подсказку к элементу интерфейса, оберните его в `OnboardingTooltip`.

## OnboardingTooltipContainer [tag:component]

Внутри [`Panel`](/components/panel), [`PanelHeader`](/components/panel-header) и [`FixedLayout`](/components/fixed-layout) позиционирование подсказки настраивается автоматически.

В других контейнерах используйте `OnboardingTooltipContainer`.

- В контейнере с прокруткой замените один из непрокручиваемых вложенных элементов на `OnboardingTooltipContainer`. Задайте ему `position: relative` или другое значение, отличное от `static`.
- Внутри элемента с `position: fixed` используйте `<OnboardingTooltipContainer fixed>`.

## Доступность (a11y) [#a11y]

У `OnboardingTooltip` с ролью `dialog` должно быть доступное имя. Задайте его через `title`, `aria-label` или `aria-labelledby`, чтобы скринридер мог объявить назначение подсказки.
