# RadioGroup [tag:component]

Объединяет переключатели [`Radio`](/components/radio) в группу. Их можно расположить в строку или столбец.

Связанные компоненты:

- [`Radio`](/components/radio)

</Overview>

{/* @example-description: Базовая группа `RadioGroup` с несколькими вариантами выбора и неактивной опцией. */}
<Playground>
  ```jsx
  <RadioGroup>
    <Radio name="fit" value="classic">
      Classic
    </Radio>
    <Radio name="fit" value="regular">
      Regular
    </Radio>
    <Radio name="fit" value="slim" disabled description="Нет в наличии">
      Slim
    </Radio>
  </RadioGroup>
  ```
</Playground>

## Доступность (a11y) [#a11y]

Группа использует `role="radiogroup"`, поддерживает стандартные атрибуты `aria-*` и позволяет переключаться между вариантами клавишами со стрелками.

Задайте имя группы через `aria-labelledby` или `aria-label`. Для дополнительного описания используйте `aria-describedby`. Если выбор обязателен, передайте `aria-required={true}`.
