## Функциональность

Передайте якорный элемент в `children`. Всплывающее окно откроется рядом с ним.

> Если якорный элемент — пользовательский компонент, он должен передавать свойство `getRootRef` либо реализовывать [forwardRef](https://react.dev/reference/react/forwardRef) на корневой `DOM`-элемент.
> Также передавайте на корневой элемент все `DOM`-атрибуты и обработчики событий (в частности, `onMouseOver`, `onMouseLeave`, `onClick`, `onFocus`, `onBlur`).

## Механизм вызова всплывающего окна

Свойство `trigger` определяет, как открывается и закрывается окно.

### `"click"`

Нажатие на якорный элемент открывает или закрывает окно.

{/* @example-description: Поведение `Popover` с триггером `click` для явного открытия/закрытия. */}
<Playground>
  ```jsx
  <Popover
    placement="bottom"
    role="tooltip"
    aria-describedby="tooltip-1"
    content={
      <Box padding="system">
        <Text>Привет</Text>
      </Box>
    }
    restoreFocus="anchor-element"
  >
    <Button id="tooltip-1" mode="outline">
      Нажми на меня
    </Button>
  </Popover>
  ```
</Playground>

### `"hover"`

Окно открывается при наведении указателя на якорный элемент и закрывается, когда указатель покидает его.

Используйте только `hover` для декоративных элементов в сочетании с `aria-hidden` и `disableFocusTrap`. Подробнее в разделе [«Доступность»](#a11y).

> ⚠️ Предупреждение про `"hover"`:
>
> - Избегайте использования только `trigger="hover"`, так как пользователи клавиатуры или скринридеров не смогут использовать компонент.
> - На сенсорном экране нажмите на якорный элемент, чтобы открыть окно. Чтобы закрыть его, нажмите за пределами окна и якорного элемента.

{/* @example-description: `Popover` с триггером `hover` для декоративной подсказки. */}
<Playground>
  ```jsx
  <Popover
    trigger="hover"
    placement="bottom"
    content={
      <Box padding="system">
        <Text>Привет</Text>
      </Box>
    }
    aria-hidden="true"
    disableFocusTrap
  >
    <Button mode="outline">Наведи на меня</Button>
  </Popover>
  ```
</Playground>

### `"focus"`

Окно открывается, когда якорный элемент получает фокус, и закрывается, когда элемент его теряет.

{/* @example-description: `Popover` с триггером `focus` для клавиатурной навигации. */}
<Playground>
  ```jsx
  <Popover
    trigger="focus"
    placement="bottom"
    role="tooltip"
    aria-describedby="tooltip-1"
    content={
      <Box padding="system">
        <Text>Привет</Text>
      </Box>
    }
    restoreFocus="anchor-element"
  >
    <Button id="tooltip-1" mode="outline">
      Сфокусируйся на меня (Tab или клик)
    </Button>
  </Popover>
  ```
</Playground>

### `"manual"`

В этом режиме видимость окна задаёт только `shown`. При нажатии `Esc` или на область за пределами окна и якорного элемента вызывается `onShownChange`.

{/* @example-description: Ручное управление видимостью `Popover` через `shown` и `onShownChange`. */}
<Playground>

```jsx
const [shown, setShown] = React.useState(false);

const handleShownChange = React.useCallback((value, reason) => {
  if (!value) {
    switch (reason) {
      case 'callback':
      case 'escape-key':
      case 'click-outside':
        setShown(false);
        break;
      default:
        break;
    }
  }
}, []);

return (
  <Popover
    trigger="manual"
    shown={shown}
    placement="bottom"
    role="tooltip"
    aria-describedby="tooltip-1"
    onShownChange={handleShownChange}
    content={
      <Box padding="system">
        <Text>Привет</Text>
      </Box>
    }
    restoreFocus="anchor-element"
  >
    <Button id="tooltip-1" onClick={() => setShown((prev) => !prev)} mode="outline">
      Нажми на меня
    </Button>
  </Popover>
);
```

</Playground>

## Хук usePopover [#use-popover]

Хук `usePopover` позволяет задать якорный элемент отдельно от `children`.

{/* @example-description: Использование хука `usePopover` для управления якорем и рендером поповера. */}
<Playground>

```jsx
const { anchorRef, anchorProps, popover } = usePopover({
  'trigger': 'click',
  'role': 'dialog',
  'id': 'menupopup',
  'aria-labelledby': 'menubutton',
  'content': ({ onClose }) => (
    <Box padding="system">
      <Text>Привет</Text>
    </Box>
  ),
});

return (
  <>
    {popover}
    <Button getRootRef={anchorRef} id="menubutton" aria-controls="menupopup" {...anchorProps}>
      Нажми на меня
    </Button>
  </>
);
```

</Playground>
## Доступность (a11y) [#a11y]

### Текстовые метки

Задайте всплывающему окну [`role`](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Roles). Например, для текстовой подсказки подходит [`tooltip`](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Roles/tooltip_role), для диалогового окна — [`dialog`](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Roles/dialog_role).

Атрибуты `aria-*` якорного элемента зависят от роли окна. Сверьтесь с документацией выбранной роли. Компонент задаёт `aria-expanded` автоматически с учётом роли.

### `trigger="hover"` [#a11y-hover]

События наведения не возникают при навигации с клавиатуры или скринридера. Сочетайте `hover` с `focus`, чтобы содержимое окна было доступно при такой навигации.

```jsx
// ❌ WCAG
<Popover trigger="hover">{children}</Popover>

// ✅ WCAG
<Popover trigger={['hover', 'focus']}>{children}</Popover>
```
