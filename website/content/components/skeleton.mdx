# Skeleton [tag:component]

Анимированная заглушка на время загрузки.
Заглушка подстраивается под размеры и стили ожидаемого содержимого.

</Overview>

{/* @example-description: Базовая заглушка `Skeleton` для одиночной строки контента. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <Skeleton width="100%" />
  ```
</Playground>

## Пример использования

{/* @example-description: Комплексный пример `Skeleton` в ячейке и текстовом блоке во время загрузки. */}
<Playground>
  ```jsx
  <Group>
    <SimpleCell
      before={<Skeleton width={36} height={36} borderRadius="50%" />}
      subtitle={<Skeleton width={90} />}
    >
      <Skeleton width={120} />
    </SimpleCell>
    <Box padding="system">
      <Skeleton width="100%" />
      <Skeleton width="100%" />
      <Skeleton width="75%" />
    </Box>
  </Group>
  ```
</Playground>

## Настройка анимации

- `duration` задаёт длительность анимации.
- `colorFrom` задаёт начальный цвет.
- `colorTo` задаёт конечный цвет.

```jsx
<Skeleton colorFrom="#f0f0f0" colorTo="#e0e0e0" duration={1.5} />
```

### Отключение анимации

Чтобы отключить анимацию, передайте `noAnimation`.

{/* @example-description: `Skeleton` без анимации при `noAnimation`. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <Skeleton noAnimation />
  ```
</Playground>

## Особенности

Высота заглушки в текстовом блоке подстраивается автоматически.

{/* @example-description: Автоматическая высота `Skeleton` внутри типографического компонента `Title`. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <Title style={{ width: '100%' }}>
    <Skeleton />
  </Title>
  ```
</Playground>

Чтобы задать свои размеры, используйте CSS-переменные.

```jsx
<Skeleton inlineSize="var(--custom-width)" blockSize="var(--custom-height)" />
```
