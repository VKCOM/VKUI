# UsersStack [tag:component]

`UsersStack` показывает аватары и может выводить подпись. Используйте его, например, для списка участников чата или подписчиков.

</Overview>

{/* @example-description: Базовый `UsersStack` с аватарами пользователей и сопровождающим текстом. */}
<Playground>
  ```jsx
  <UsersStack
    photos={[
      'https://avatars.githubusercontent.com/u/14944123?s=50',
      'https://avatars.githubusercontent.com/u/5850354?s=50',
    ]}
  >
    Даниил и Ином подписаны
  </UsersStack>
  ```
</Playground>

## Использование

Передайте в `photos` массив ссылок на изображения или массив объектов. Каждый объект содержит ссылку и свой [компонент-обёртку](#wrappers) для аватара.

## Положение аватаров [#avatar-position]

Чтобы расположить аватары перед текстом, задайте `avatarsPosition="inline-start"`, а после текста — `avatarsPosition="inline-end"`.
Для аватаров над текстом используйте `avatarsPosition="block-start"`, предпочтительно вместе с `size="m"`.

{/* @example-description: Пример `UsersStack` с `avatarsPosition="block-start"` и счётчиком участников. */}
<Playground>
  ```jsx
  <UsersStack
    avatarsPosition="block-start"
    size="m"
    visibleCount={2}
    count={3}
    photos={[
      'https://avatars.githubusercontent.com/u/7431217?s=50',
      'https://avatars.githubusercontent.com/u/61377022?s=50',
    ]}
  >
    Виктория, Эльдар и ещё 3 человека пойдут на это мероприятие
  </UsersStack>
  ```
</Playground>

## Счётчик

Если элементов в `photos` больше, чем указано в `visibleCount`, рядом с аватарами появляется счётчик. По умолчанию он показывает число скрытых элементов.
Чтобы задать другое число, используйте `count`. Если число больше 99, компонент скрывает счётчик. [Пример расположения аватаров](#avatar-position).

## Кастомизация аватаров [#wrappers]

Передайте `renderWrapper` в элементе массива `photos`, чтобы обернуть аватар в свой компонент. В примере при наведении на аватар появляется подсказка с именем пользователя.

{/* @example-description: Кастомные обёртки аватаров в `UsersStack` с `Tooltip` и интерактивным элементом. */}
<Playground>
  ```jsx
  <UsersStack
    size="l"
    photos={[
      {
        src: 'https://avatars.githubusercontent.com/u/14944123?s=50',
        renderWrapper: (props) => (
          <Tooltip description="Даниил Суворов">
            <Tappable onClick={() => {}}>{props.children}</Tappable>
          </Tooltip>
        ),
      },
      {
        src: 'https://avatars.githubusercontent.com/u/5850354?s=50',
        renderWrapper: (props) => (
          <Tooltip description="Ином Мирджамолов">
            <Tappable onClick={() => {}}>{props.children}</Tappable>
          </Tooltip>
        ),
      },
    ]}
  />
  ```
</Playground>

## Ограничения

- Если значение счётчика больше 99, компонент его скрывает.
- При `size="s"` счётчик не отображается.
- Рекомендуется использовать `avatarsPosition="block-start"` вместе с `size="m"`.
