Индикатор загрузки внутри экрана. Компонент центрирует индикатор и добавляет стандартные отступы.

{/* @example-description: Использование `PanelSpinner` для индикации загрузки внутри панели. */}
<Playground Wrapper={FixedLayoutWrapper} style={{ height: 415, overflow: 'hidden' }}>

```jsx
<Panel centered>
  <PanelHeader>PanelSpinner</PanelHeader>
  <PanelSpinner />
</Panel>
```

</Playground>

### Свойства

Наследует все свойства компонента [`Spinner`](/components/spinner).

- `size` — размер индикатора.
- `disableAnimation` — отключение анимации.
- `noColor` — наследование цвета.

#### Высота компонента

Свойство `height` задаёт высоту области индикатора.

```jsx
<PanelSpinner height={300} />
```

### Когда использовать

- При загрузке контента внутри экрана.
- Когда нужен центрированный спиннер с отступами.
- Для индикации загрузки всей страницы укажите нужную высоту через `height`.

### Альтернативы

- [`Spinner`](/components/spinner) — для индикации загрузки внутри элемента.
- [`ScreenSpinner`](/components/screen-spinner) — для индикации загрузки поверх интерфейса.
