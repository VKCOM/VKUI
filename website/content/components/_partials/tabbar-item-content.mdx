Пункт навигации с иконкой и необязательной подписью. Передайте иконку в `children`, а подпись — в `label`. Обычно используют иконку размером `28px`.

{/* @example-description: Пример `TabbarItem` с иконкой и текстовой подписью. */}
<Playground>
  ```jsx
  <TabbarItem label="Профиль">
    <Icon28UserCircleOutline />
  </TabbarItem>
  ```
</Playground>

Чтобы расположить иконку и подпись горизонтально или вертикально, задайте `mode` у
[`Tabbar`](/components/epic#tabbar-align).

### Выбранное состояние

Передайте `selected`, чтобы выделить текущий раздел.

{/* @example-description: Выбранный `TabbarItem` с текстом для скринридера через `VisuallyHidden`. */}
<Playground>
  ```jsx
  <TabbarItem selected>
    {/* Данный текст будет озвучен скринридером */}
    <VisuallyHidden>Профиль</VisuallyHidden>
    <Icon28UserCircleOutline />
  </TabbarItem>
  ```
</Playground>

### Индикатор

Чтобы добавить счётчик или индикатор уведомления, передайте в `indicator` компонент `Counter` с `size="s"` или `Badge`.

{/* @example-description: `TabbarItem` с индикатором уведомления, переданным в свойство `indicator`. */}
<Playground>
  ```jsx
  <TabbarItem indicator={<Badge />}>
    {/* Данный текст будет озвучен скринридером */}
    <VisuallyHidden>Профиль</VisuallyHidden>
    <Icon28UserCircleOutline />
  </TabbarItem>
  ```
</Playground>

### Тег компонента [#teg-komponenta]

По умолчанию компонент использует тег `a` при передаче `href`, а в остальных случаях — `button`. Свойство `Component` позволяет выбрать другой тег.

### Доступность (a11y) [#a11y]

Если у пункта нет видимой подписи `label`, задайте имя для скринридеров. Передайте в `children` иконку и компонент `VisuallyHidden` с текстом.

```jsx
import { Icon28UserCircleOutline } from '@vkontakte/icons';
import { TabbarItem, VisuallyHidden } from '@vkontakte/vkui';

<TabbarItem>
  {/* Данный текст будет озвучен скринридером */}
  <VisuallyHidden>Профиль</VisuallyHidden>
  <Icon28UserCircleOutline />
</TabbarItem>;
```

Можно также указать текст в `aria-label` или передать в `aria-labelledby` идентификатор элемента с подписью.

```jsx
<TabbarItem aria-label="Профиль">
  <Icon28UserCircleOutline />
</TabbarItem>
```

```jsx
<span id="my-label">Профиль</span>

<TabbarItem aria-labelledby="my-label">
  <Icon28UserCircleOutline />
</TabbarItem>
```
