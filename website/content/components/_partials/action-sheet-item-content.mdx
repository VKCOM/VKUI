Пункт всплывающего меню [`ActionSheet`](/components/action-sheet). Для каждого пункта можно настроить цвет, добавить иконки и метаданные.

<Playground>
  ```jsx
  <ActionSheetItem>Сохранить</ActionSheetItem>
  ```
</Playground>

### Цвет

Задаётся свойством `mode`.

#### `"default"`

Стандартный цвет текста для действий, которые не нужно выделять.

<Playground>
  ```jsx
  <ActionSheetItem>Сохранить</ActionSheetItem>
  ```
</Playground>

#### `"destructive"`

Цвет критических действий (чаще всего красный). Чтобы такие действия были заметнее, размещайте их в начале списка.

<Playground>
  ```jsx
  <ActionSheetItem mode="destructive">Удалить</ActionSheetItem>
  ```
</Playground>

#### ~`"cancel"`~

> **@deprecated** С версии 8.0.0. Значение `"cancel"` устарело и будет удалено в **VKUI v10**.
> Используйте компонент [`ActionSheetDefaultIosCloseItem`](/components/action-sheet#action-sheet-default-ios-close-item) или передайте свойства через `slotProps.iosCloseItem` в `ActionSheet`.

Цвет действия отмены.

<Playground>
  ```jsx
  <ActionSheetItem mode="cancel">Отмена</ActionSheetItem>
  ```
</Playground>

### ~Кнопка "Отмена"~

> **@deprecated** С версии 8.0.0. Свойство `isCancelItem` устарело и будет удалено в **VKUI v10**.
> Используйте компонент [`ActionSheetDefaultIosCloseItem`](/components/action-sheet#action-sheet-default-ios-close-item) или передайте свойства через `slotProps.iosCloseItem` в `ActionSheet`.

Свойство `isCancelItem` помечает пункт как действие «Отмена».

Apple рекомендует добавить в `ActionSheet` кнопку «Отмена», которая закрывает меню без выполнения других действий.

> Передайте кнопку «Отмена» в `iosCloseItem` компонента `ActionSheet`, чтобы визуально отделить её от остальных пунктов.

Подробнее о кнопке «Отмена» читайте на странице [`ActionSheet`](/components/action-sheet#cancel-item).

### Текстовые элементы

Передайте текст заголовка в `children`.

<Playground>
  ```jsx
  <ActionSheetItem>Скорость воспроизведения</ActionSheetItem>
  ```
</Playground>

Свойство `subtitle` задаёт текст под заголовком.

<Playground>
  ```jsx
  <ActionSheetItem subtitle="Обычная">Скорость воспроизведения</ActionSheetItem>
  ```
</Playground>

Свойство `meta` добавляет пояснение или индикатор рядом с заголовком.

<Playground>
  ```jsx
  <ActionSheetItem meta={<Icon12Circle fill="var(--vkui--color_icon_negative)" />}>
    Закрепить запись
  </ActionSheetItem>
  ```
</Playground>

#### Многострочный режим

По умолчанию каждый текстовый элемент занимает одну строку. Если текст не помещается, компонент обрезает его и добавляет многоточие. Чтобы включить перенос строк во всех текстовых элементах, передайте `multiline`.

<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <ActionSheetItem multiline>
    Очень длинный заголовок просто для примера, старайтесь избегать такого
  </ActionSheetItem>
  ```
</Playground>

### Контент в начале/в конце

Передайте иконку, аватар или другое содержимое в `before`, чтобы разместить его слева от текста, или в `after`, чтобы разместить справа.

Дизайн-система рекомендует иконки размером `20px` для настольных устройств (режим `compact`) и `28px` для мобильных (режим `regular`). Для автоматического выбора размера используйте [`AdaptiveIconRenderer`](/components/adaptive-icon-renderer).

<Playground>
  ```jsx
  <ActionSheetItem
    before={
      <AdaptiveIconRenderer IconCompact={Icon20WriteOutline} IconRegular={Icon28EditOutline} />
    }
  >
    Редактировать профиль
  </ActionSheetItem>
  ```
</Playground>

### Состояния

#### `disabled`

Свойство `disabled` отключает взаимодействие с пунктом меню.

<Playground>
  ```jsx
  <ActionSheetItem subtitle="Отсутствуют" disabled>
    Субтитры
  </ActionSheetItem>
  ```
</Playground>

#### `selectable`

При `selectable` пункт меню выглядит и работает как радиокнопка. Можно передать стандартные свойства радиокнопок.

- `name` — имя группы радиокнопок.
- `value` — значение радиокнопки.
- `defaultChecked` — выбор по умолчанию.
- `checked` и [`onChange`](/components/action-sheet#onchange) — управление выбором в контролируемом режиме.

<Playground direction="column">

```jsx
const [filter, setFilter] = useState('Нормальная');

const onChange = (e) => {
  // e.target.value будет равно значению, переданному в `value` выбранного компонента `ActionSheetItem`
  setFilter(e.target.value);
};

return ['0.25x', '0.5x', '0.75x', 'Нормальная', '1.25x', '1.5x', '2x', '3x'].map((speed) => (
  <ActionSheetItem
    key={speed}
    onChange={onChange}
    checked={filter === speed}
    name="filter"
    value={speed}
    selectable
  >
    {speed}
  </ActionSheetItem>
));
```

</Playground>

Чтобы заменить стандартную иконку выбранного пункта, передайте `iconChecked`.

<Playground>
  ```jsx
  <ActionSheetItem
    defaultChecked
    selectable
    iconChecked={
      // квадратные иконки выбора
      <AdaptiveIconRenderer IconCompact={Icon20CheckBoxOn} IconRegular={Icon24CheckBoxOn} />
    }
  >
    0.75x
  </ActionSheetItem>
  ```
</Playground>

### Обработчики событий

#### `onClick`/ `onImmediateClick`

По умолчанию компонент вызывает `onClick` после анимации закрытия меню и вызова `onClosed`. К этому моменту `currentTarget` в объекте события уже недоступен. Чтобы получить событие в момент нажатия, используйте `onImmediateClick`.

> По умолчанию нажатие на пункт закрывает меню и вызывает `onClosed` у `ActionSheet`. Чтобы закрывать меню вручную, передайте `autoCloseDisabled`.

#### `onChange`

При `selectable={true}` обрабатывайте выбор пункта через `onChange`. См. [пример выбора пункта](/components/action-sheet#selectable).

### Ссылки

Если передать `href`, компонент отобразится как ссылка `<a>`. Для ссылки можно задать `target`.

```jsx
<ActionSheetItem href="https://vk.ru" target="_blank">
  Перейти на vk.ru
</ActionSheetItem>
```
