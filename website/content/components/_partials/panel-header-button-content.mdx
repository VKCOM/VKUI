Кнопка для шапки [`PanelHeader`](/components/panel-header). Передайте её в `before` или `after`.

{/* @example-description: Базовый `PanelHeaderButton` с иконкой действия в шапке. */}
<Playground>
  ```jsx
  <PanelHeaderButton aria-label="Уведомления">
    <Icon28Notifications />
  </PanelHeaderButton>
  ```
</Playground>

### Контент

Передайте [иконку](/icons/) или текст в `children`. Текстовые кнопки чаще используются на iOS, иногда их используют и на Android.

Для планшетов и настольных устройств рекомендуемый размер иконки — `24px`, для мобильных — `28px`. Для выбора размера можно использовать [`AdaptiveIconRenderer`](/components/adaptive-icon-renderer).

Чтобы разместить несколько кнопок в ряд, объедините их в `React.Fragment`.

{/* @example-description: Несколько кнопок в шапке с группировкой через `React.Fragment`. */}
<Playground>
  ```jsx
  <React.Fragment>
    <PanelHeaderButton aria-label="Настройки">
      <Icon28SettingsOutline />
    </PanelHeaderButton>
    <PanelHeaderButton aria-label="Уведомления">
      <Icon28Notifications />
    </PanelHeaderButton>
  </React.Fragment>
  ```
</Playground>

### Пресеты

#### PanelHeaderBack [#panel-header-back]

Кнопка возврата на предыдущий экран внутри [`View`](/components/view). Компонент выбирает иконку по платформе. Текст из `label` виден на `vkcom` и iOS. На Android он доступен скринридерам. Свойства `hideLabelOnVKCom` и `hideLabelOnIOS` скрывают текст визуально на соответствующих платформах, сохраняя его для скринридеров.

{/* @example-description: Кнопка возврата `PanelHeaderBack` с платформенной иконкой. */}
<Playground>
  ```jsx
  <PanelHeaderBack />
  ```
</Playground>

#### PanelHeaderClose [#panel-header-close]

Кнопка «Отмена». Передайте в `onClick` обработчик, который закроет модальное окно или переключит активный [`View`](/components/view) в [`Root`](/components/root).

На iOS кнопка показывает текст из `label`. На Android и настольных устройствах она показывает `<Icon28CancelOutline />` или `<Icon24CancelOutline />`, а текст из `label` доступен скринридерам.

{/* @example-description: Внешний вид кнопки «Отмена» (`PanelHeaderClose`). */}
<Playground>
  ```jsx
  <PanelHeaderClose />
  ```
</Playground>

#### PanelHeaderEdit [#panel-header-edit]

Кнопка редактирования. Свойство `isActive` показывает, включён ли режим редактирования. Чтобы изменить подписи, передайте `editLabel` и `doneLabel`. На iOS подписи видны, а на Android и настольных устройствах доступны скринридерам.

{/* @example-description: Кнопка редактирования `PanelHeaderEdit` с переключаемым состоянием. */}
<Playground>
  ```jsx
  <PanelHeaderEdit />
  ```
</Playground>

#### PanelHeaderSubmit [#panel-header-submit]

Кнопка «Готово» для сохранения результата и закрытия текущего модального окна или текущего [`View`](/components/view) внутри [`Root`](/components/root). На iOS кнопка показывает текст из `label`. На Android и настольных устройствах она показывает `<Icon28DoneOutline />` или `<Icon24DoneOutline />`, а текст из `label` доступен скринридерам.

{/* @example-description: Кнопка подтверждения `PanelHeaderSubmit` для завершения действия. */}
<Playground>
  ```jsx
  <PanelHeaderSubmit />
  ```
</Playground>
