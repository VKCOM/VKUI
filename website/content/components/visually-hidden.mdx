# VisuallyHidden [tag:component]

`VisuallyHidden` скрывает содержимое с экрана, оставляя его доступным ассистивным технологиям.
По умолчанию компонент выводит содержимое в `span`.

</Overview>

{/* @example-description: Базовый пример `VisuallyHidden` для текста, доступного только скринридерам. */}
<Playground>
  ```jsx
  <Text>Здесь есть ещё текст для скринридера</Text>
  <VisuallyHidden>Доступно только для скринридеров</VisuallyHidden>
  ```
</Playground>

> Чтобы скрыть содержимое и с экрана, и от ассистивных технологий, используйте CSS-свойства `display: none` или `visibility: hidden`.
