# Checkbox [tag:component]

Чекбокс для выбора одного или нескольких вариантов из списка.
Поддерживает три состояния — «выбрано», «не выбрано» и «не определено».

</Overview>

{/* @example-description: Базовый чекбокс с текстовой подписью. */}
<Playground>
  ```jsx
  <Checkbox name="notifications">Уведомления включены</Checkbox>
  ```
</Playground>

## Применение компонента

- Если один чекбокс управляет группой, используйте `indeterminate`, когда выбрана только часть элементов.
- Для выбора одного из трёх и более взаимоисключающих вариантов используйте группу [`Radio`](/components/radio).

## Режим работы

Подробнее о режимах работы читайте в [документации React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

В неконтролируемом режиме не передавайте `checked`. Чтобы задать начальное состояние, используйте `defaultChecked`.
В контролируемом режиме задавайте состояние через `checked` и обрабатывайте его изменения в `onChange`.

Чтобы задать состояние «не определено», передайте `defaultIndeterminate` в неконтролируемом режиме или `indeterminate` в контролируемом. Обработчик `onChange` не возвращает это состояние.

```jsx
// Неконтролируемое состояние, по умолчанию в состоянии "выбран"
<Checkbox defaultChecked />

// Неконтролируемое состояние, по умолчанию в состоянии "не определено"
<Checkbox defaultIndeterminate />

// Контролируемое состояние, значение "не выбран"
const [checked, setChecked] = React.useState(false);

<Checkbox checked={checked} onChange={(event) => setChecked(event.target.checked)} />;
```

## Состояния

### `disabled`

Свойство `disabled` блокирует взаимодействие с компонентом и добавляет визуальную индикацию недоступности.

{/* @example-description: Чекбокс в неактивном состоянии с `disabled`. */}
<Playground>
  ```jsx
  <Checkbox name="notifications" disabled>
    Уведомления включены
  </Checkbox>
  ```
</Playground>

## Визуальное оформление

По умолчанию компонент использует два набора иконок для трёх состояний — для режимов `regular` и `compact`. Чтобы заменить иконки, используйте следующие свойства.

- `IconIndeterminate` — иконка для неопределённого состояния;
- `IconOffCompact` — иконка для невыбранного состояния в режиме `"compact"` (планшеты, десктоп);
- `IconOffRegular` — иконка для невыбранного состояния в режиме `"regular"` (мобильные устройства);
- `IconOnCompact` — иконка для выбранного состояния в режиме `"compact"` (планшеты, десктоп);
- `IconOnRegular` — иконка для выбранного состояния в режиме `"regular"` (мобильные устройства).

Рекомендуется использовать иконки размером `24px` для режима `"regular"` и `20px` для режима `"compact"`.

{/* @example-description: Кастомный набор иконок для состояний чекбокса в `compact` и `regular` режимах. */}
<Playground>
  ```jsx
  <Checkbox
    IconOffCompact={Icon20LikeOutline}
    IconOffRegular={Icon24LikeOutline}
    IconOnCompact={Icon20Like}
    IconOnRegular={Icon24Like}
  >
    Пицца с ананасами
  </Checkbox>
  ```
</Playground>

## Кастомизация

Передавайте свойства внутренним элементам через `slotProps`.

Например, передайте CSS-класс, атрибут `data-*` или `aria-*`, обработчик события или `getRootRef` для доступа к элементу.

{/* @example-description: Пример `slotProps` для настройки корня и внутреннего `input` чекбокса. */}
<Playground>
  ```jsx
  const inputRef = React.useRef();

  return (
    <Checkbox
      defaultChecked={false}
      className="my-root-class"
      data-testid="checkbox-root"
      id="checkbox-input-id"
      slotProps={{
        root: {
          id: 'checkbox-root-id',
        },
        input: {
          className: 'my-input-class',
          'aria-label': 'checkbox',
          getRootRef: inputRef,
        },
      }}
    >
      Уведомления включены
    </Checkbox>
  )
  ```
</Playground>

## Доступность (a11y) [#a11y]

Компонент `Checkbox` обеспечивает базовую доступность, используя нативные `HTML`-элементы `input[type="checkbox"]` и `label`.

Чтобы задать доступное имя или описание, передайте `aria-labelledby`, `aria-label` или `aria-describedby`.
