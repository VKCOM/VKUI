# ScreenSpinner [tag:component]

Показывает [`Spinner`](/components/spinner) поверх интерфейса и блокирует взаимодействие с ним до завершения асинхронной операции.

</Overview>

<Playground hide>
  ```jsx
  <ScreenSpinner.Container>
    <ScreenSpinner.Loader />
    <ScreenSpinner.SwapIcon />
  </ScreenSpinner.Container>
  ```
</Playground>

{/* @example-description: Базовый `ScreenSpinner` с оверлеем и закрытием в состоянии `cancelable`. */}
<Playground>

```jsx
const [spinner, setSpinner] = React.useState(null);

const showSpinner = () => {
  setSpinner(<ScreenSpinner state="cancelable" mode="overlay" onClick={() => setSpinner(null)} />);
};

return (
  <>
    <Button onClick={showSpinner}>Показать индикатор</Button>
    {spinner}
  </>
);
```

</Playground>

## Подкомпоненты

Соберите индикатор из подкомпонентов, если хотите управлять его частями отдельно и самостоятельно настраивать размещение или блокировку прокрутки.

{/* @example-description: Сборка `ScreenSpinner` из подкомпонентов `Container`, `Loader` и `SwapIcon`. */}
<Playground>
  ```jsx
  <ScreenSpinner.Container>
    <ScreenSpinner.Loader />
    <ScreenSpinner.SwapIcon />
  </ScreenSpinner.Container>
  ```
</Playground>

### ScreenSpinner.Container

Контейнер для всех частей индикатора.

### ScreenSpinner.Loader

Индикатор загрузки.

### ScreenSpinner.SwapIcon

Контейнер для иконок.

## Внешний вид

По умолчанию используется `mode="shadow"`. Для индикатора поверх цветных элементов или фотографий используйте `mode="overlay"`.

{/* @example-description: Вариант `ScreenSpinner` в режиме `overlay` для контрастного фона. */}
<Playground>
  ```jsx
  <ScreenSpinner.Container mode="overlay">
    <ScreenSpinner.Loader />
    <ScreenSpinner.SwapIcon />
  </ScreenSpinner.Container>
  ```
</Playground>

## Состояния

Задаётся свойством `state`.

- `"loading"` — операция выполняется (по умолчанию);
- `"cancelable"` — операция выполняется и её можно отменить;
- `"done"` — успешное завершение процесса;
- `"error"` — завершение процесса с ошибкой;
- `"custom"` — пользовательский вариант состояния процесса.

Иконка зависит от состояния. Для своей иконки задайте `state="custom"` и передайте иконку в [`customIcon`](#custom-icon).

{/* @example-description: Демонстрация состояний `ScreenSpinner`: loading, cancelable, done, error и custom. */}
<Playground>
  ```jsx
  <ScreenSpinner.Container>
    <ScreenSpinner.Loader />
    <ScreenSpinner.SwapIcon />
  </ScreenSpinner.Container>
  <ScreenSpinner.Container state="cancelable">
    <ScreenSpinner.Loader />
    <ScreenSpinner.SwapIcon />
  </ScreenSpinner.Container>
  <ScreenSpinner.Container state="done">
    <ScreenSpinner.Loader />
    <ScreenSpinner.SwapIcon />
  </ScreenSpinner.Container>
  <ScreenSpinner.Container state="error">
    <ScreenSpinner.Loader />
    <ScreenSpinner.SwapIcon />
  </ScreenSpinner.Container>
  <ScreenSpinner.Container state="custom" customIcon={<Icon56CheckCircleOutline />}>
    <ScreenSpinner.Loader />
    <ScreenSpinner.SwapIcon />
  </ScreenSpinner.Container>
  ```
</Playground>

## Сопроводительный текст

Передайте видимый текст под иконкой в `label`. Если под иконкой нет текста, передайте её описание для ассистивных технологий в `children`.

## Пользовательские иконки [#custom-icon]

Передайте иконку в `customIcon` и задайте `state="custom"`.

```jsx
import { ScreenSpinner } from '@vkontakte/vkui';
import { Icon56CheckCircleOutline } from '@vkontakte/icons';

<ScreenSpinner state="custom" customIcon={<Icon56CheckCircleOutline />} />;
```

## Управление порталами

VKUI использует [порталы](https://react.dev/reference/react-dom/createPortal) для рендеринга `ScreenSpinner`.

Свойство `usePortal` позволяет настраивать порталы:

- `true` (по умолчанию) — помещает индикатор в `portalRoot` из `AppRoot` или в `document.body`, если `portalRoot` не задан.
- `false` или `null` — размещает индикатор там, где вы добавили его в дерево компонентов.

Также можно указать конкретный `DOM`-элемент (полученный, например, через `document.getElementById`)
или ссылку на `DOM`-элемент ([`ref`-объект](https://react.dev/learn/manipulating-the-dom-with-refs)).

## Доступность (a11y) [#a11y]

Чтобы скринридер объявил состояние загрузки, задайте атрибуты [`aria-busy`](https://doka.guide/a11y/aria-busy/) и [`aria-live`](https://doka.guide/a11y/aria-live/) на `SplitLayout` или другом корневом компоненте обновляемой области.

Скринридер читает видимый текст из `label`. Если `label` не задан, передайте визуально скрытый текст в `children`.

При `state="cancelable"` задайте доступное имя кнопки отмены через `cancelLabel`.

### disableAnimation

Чтобы отключить анимацию индикатора, передайте `disableAnimation`.
