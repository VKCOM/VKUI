# FormStatus [tag:component]

Сообщение о состоянии формы или результате действия, например об успешной отправке или ошибке.

</Overview>

  ```jsx
  <FormStatus title="Некорректный мобильный номер" mode="error">

  </FormStatus>
  ```

## Применение компонента

Используйте `FormStatus` для сообщений о форме целиком, например для подсказки по заполнению или сообщения о результате отправки. Ошибки отдельных полей показывайте рядом с этими полями.

Сформулируйте суть сообщения в `title`, а подробности или инструкции передайте в `children`. Для сообщения об ошибке используйте `mode="error"`.

## Доступность (a11y) [#a11y]

Роль компонента зависит от `mode`:

- `role="status"` для режима `mode="default"` — используется для отображения статуса, который не требует
  немедленного внимания пользователя;
- `role="alert"` для режима `mode="error"` — используется для отображения важных сообщений об ошибках,
  которые требуют внимания пользователя.

Чтобы переопределить роль, передайте `role`.
