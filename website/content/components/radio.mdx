# Radio [tag:component]

Переключатель для выбора одного варианта из группы.
Круглая метка показывает, выбран ли вариант.

</Overview>

{/* @example-description: Выбор способа оплаты с помощью `Radio`. */}
<Playground>
  ```jsx
  <Radio name="pay" value="cash">
    Оплата наличными
  </Radio>
  <Radio name="pay" value="card">
    Оплата картой
  </Radio>
  ```
</Playground>

## Режим работы

- В неконтролируемом режиме компонент хранит значение сам. Чтобы задать начальное значение, передайте `defaultChecked`.
- В контролируемом режиме передайте текущее значение в `checked` и обновляйте его в обработчике `onChange`.

Подробнее о режимах работы в [документации React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

```jsx
// Неконтролируемое состояние, по умолчанию в состоянии "выбран"
<Radio name="pay" value="card" defaultChecked>
  Оплата картой
</Radio>;

// Контролируемое состояние, значение "не выбран"
const [checked, setChecked] = React.useState(false);

<Radio name="pay" value="card" checked={checked} onChange={(event) => setChecked(true)}>
  Оплата картой
</Radio>;
```

> Свойство `value` задаёт значение выбранного варианта, которое отправится с формой. В примере поле `pay` получит значение `card`.

## Состояния

### `disabled`

Свойство `disabled` блокирует взаимодействие с компонентом и показывает, что он недоступен.

{/* @example-description: `Radio` в неактивном состоянии `disabled` с предустановленным выбором. */}
<Playground>
  ```jsx
  <Radio name="pay" value="card" defaultChecked disabled>
    Оплата картой
  </Radio>
  ```
</Playground>

## Применение компонента

- Объединяйте в группу от двух до пяти `Radio`. Если вариантов больше, рассмотрите [`Select`](/components/select).
- Для независимого выбора одного параметра используйте [`Checkbox`](/components/checkbox) или [`Switch`](/components/switch).
- Для выбора нескольких вариантов из списка используйте [`Checkbox`](/components/checkbox).

## Кастомизация

Через `slotProps` передавайте свойства корневому контейнеру и скрытому `input`, например CSS-классы, атрибуты `data-*` и `aria-*` или обработчики событий. Для доступа к элементу передайте `getRootRef`.

{/* @example-description: Кастомизация внутренних элементов `Radio` через `slotProps` и `getRootRef`. */}
<Playground>
  ```jsx
  const inputRef = React.useRef();

  return (
    <Radio
      defaultChecked={false}
      className="my-root-class"
      data-testid="radio-root"
      id="radio-input-id"
      slotProps={{
        root: {
          id: 'radio-root-id',
        },
        input: {
          className: 'my-input-class',
          'aria-label': 'radio',
          getRootRef: inputRef,
        },
      }}
    >
      Оплата картой
    </Radio>
  )
  ```
</Playground>

## Доступность (a11y) [#a11y]

`Radio` использует HTML-элементы `input[type="radio"]` и `label`.

- Объединяйте связанные варианты с помощью [`RadioGroup`](/components/radio-group) или другой обёртки с `role="radiogroup"`.
- Передайте дополнительное описание в `description`.
- При необходимости задайте доступное имя через `aria-label` или `aria-labelledby`.

{/* @example-description: Использование `Radio` внутри `RadioGroup` с подписью через `FormItem` и `aria-labelledby`. */}
<Playground>
  ```jsx
  <FormItem top="Выберите посадку" topId="placement">
    <RadioGroup aria-labelledby="placement">
      <Radio name="fit" value="classic">
        Classic
      </Radio>
      <Radio name="fit" value="regular">
        Regular
      </Radio>
      <Radio name="fit" value="slim" disabled description="Нет в наличии">
        Slim
      </Radio>
    </RadioGroup>
  </FormItem>
  ```
</Playground>
