# Image [tag:component]

Изображение с адаптивными размерами, скруглением углов и элементами поверх него.
Компонент принимает стандартные атрибуты `<img>`, поддерживает скругления из дизайн-системы и размещает индикаторы с учётом размера изображения.

</Overview>

{/* @example-description: Базовый компонент `Image` для отображения изображения заданного размера. */}
<Playground>
  ```jsx
  <Image size={96} src="https://sun9-51.userapi.com/c857024/v857024436/f927/rG9fac2cuac.jpg" />
  ```
</Playground>

## Адаптивные размеры

Размеры задаются так же, как у [`ImageBase`](/components/image-base#sizes).

## Скругления

Радиус можно задать сразу для всех углов или для каждого отдельно.

### Единое скругление

{/* @example-description: Скругление всех углов изображения через свойство `borderRadius`. */}
<Playground>
  ```jsx
  <Image
    size={96}
    borderRadius="m"
    src="https://sun9-51.userapi.com/c857024/v857024436/f927/rG9fac2cuac.jpg"
  />
  ```
</Playground>

### Индивидуальные углы

{/* @example-description: Настройка скругления отдельных углов изображения. */}
<Playground>
  ```jsx
  <Image
    size={64}
    borderStartStartRadius="l"
    borderEndEndRadius="l"
    src="https://sun9-51.userapi.com/c857024/v857024436/f927/rG9fac2cuac.jpg"
  />
  ```
</Playground>

## Дополнительные элементы

### Иконка-заглушка

Если изображение не загружается, компонент показывает иконку из `fallbackIcon`. Подбирайте её размер по размеру изображения.

{/* @example-description: `Image` с fallback-иконкой для случая ошибки загрузки картинки. */}
<Playground>
  ```jsx
  <Image fallbackIcon={<Icon3218CircleOutline />} />
  ```
</Playground>

> Для подбора размера используйте [`getFallbackIconSizeByImageBaseSize`](/components/image-base#getfallbackiconsizebyimagebasesize).

### Индикатор

Индикатор в правом нижнем углу компонента:

{/* @example-description: Индикатор состояния в углу изображения через `Image.Badge`. */}
<Playground>
  ```jsx
  <Image src="https://sun9-51.userapi.com/c857024/v857024436/f927/rG9fac2cuac.jpg">
    <Image.Badge background="stroke">
      <Icon20PrivacyCircleFillRed />
    </Image.Badge>
  </Image>
  ```
</Playground>

> Для подбора размера используйте [`getBadgeIconSizeByImageBaseSize`](/components/image-base#getbadgeiconsizebyimagebasesize).

### Наложение

Используйте `Image.Overlay`, чтобы добавить слой поверх изображения.

{/* @example-description: Оверлей поверх изображения с иконкой действия и постоянной видимостью. */}
<Playground>
  ```jsx
  <Image src="https://sun9-51.userapi.com/c857024/v857024436/f927/rG9fac2cuac.jpg">
    <Image.Overlay theme="dark" visibility="always">
      <Icon24AddOutline />
    </Image.Overlay>
  </Image>
  ```
</Playground>

> Для подбора размера используйте [`getOverlayIconSizeByImageBaseSize`](/components/image-base#getoverlayiconsizebyimagebasesize).

> По умолчанию на устройствах с указателем `Image.Overlay` появляется при наведении на изображение, на устройствах без указателя виден всегда. Это поведение можно изменить через `visibility`.

### Позиционированный компонент

Используйте `Image.FloatElement`, чтобы разместить элемент в нужной точке поверх изображения.

{/* @example-description: Позиционированная кнопка поверх изображения через `Image.FloatElement`. */}
<Playground>
  ```jsx
  <Image size={96} src="https://sun9-51.userapi.com/c857024/v857024436/f927/rG9fac2cuac.jpg">
    <Image.FloatElement placement="top-end" inlineIndent="xs" blockIndent="xs">
      <Button size="s" mode="primary" after={<Icon16MoreHorizontal />} />
    </Image.FloatElement>
  </Image>
  ```
</Playground>
