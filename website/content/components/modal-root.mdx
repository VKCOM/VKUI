# ModalRoot [tag:component]

Менеджер модальных окон.

</Overview>

<Playground>

```jsx
const [activeModal, setActiveModal] = React.useState(null);

const close = () => setActiveModal(null);

const modalRoot = (
  <ModalRoot activeModal={activeModal} onClose={close}>
    <ModalPage id="modal1" onClose={close}>
      <Placeholder
        action={
          <ButtonGroup mode="vertical" align="center">
            <Button onClick={() => setActiveModal("modal2")}>
              Открыть карточку
            </Button>
            <Button onClick={close}>Закрыть</Button>
          </ButtonGroup>
        }
      />
    </ModalPage>
    <ModalCard id="modal2" onClose={close}>
      <Placeholder
        action={
          <ButtonGroup mode="vertical" align="center">
            <Button onClick={() => setActiveModal("modal1")}>
              Вернуться назад
            </Button>
            <Button onClick={close}>Закрыть</Button>
          </ButtonGroup>
        }
      />
    </ModalCard>
  </ModalRoot>
);

return (
  <>
    {modalRoot}
    <Button onClick={() => setActiveModal("modal1")}>Открыть окно</Button>
  </>
);
```

</Playground>

## Спецификация

Передайте в `children` компоненты [`ModalPage`](/components/modal-page) или [`ModalCard`](/components/modal-card) с уникальными `id`.

При смене `activeModal` компонент плавно переключается между окнами. Если передать `activeModal={null}`, текущее окно закроется.

После смахивания вниз, нажатия на кнопку закрытия или на подложку `ModalRoot` вызывает `onClose` с идентификатором активного окна. Чтобы вернуться к предыдущему окну, передайте его идентификатор в `activeModal`. Чтобы закрыть текущее окно, передайте `null`. Поведение отдельного окна можно переопределить его обработчиком `onClose`.

`ModalRoot` создаёт общую подложку `ModalOverlay`, чтобы при переключении окон она не мигала.

> **Safari на iOS**
>
> В Safari до версии 16 смахивание вниз для закрытия окна может вызвать обновление страницы. Попытка заблокировать обновление может нарушить прокрутку. [Обсуждение в GitHub](https://github.com/VKCOM/VKUI/issues/335).
>
> В Safari 16 и новее `overscroll-behavior-y: none` блокирует обновление страницы смахиванием вниз. При открытии окна библиотека добавляет это свойство элементу `html`, а при закрытии удаляет. [Описание свойства в MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/overscroll-behavior-y).

## FAQ

### Создание обёрток для `ModalPage` / `ModalCard`

`ModalRoot` передаёт `activeModal` через контекст. `ModalPage` и `ModalCard` монтируются, когда `activeModal` совпадает с их `id` или `nav`, и размонтируются при смене активного окна.

Если вы оборачиваете окно в свой компонент, запускайте логику при монтировании содержимого окна или проверяйте `activeModal` с помощью `useModalRootContext()`.

```jsx
const SomeAsyncEffect = () => {
  const [data, setData] = useState({});
  useEffect(function fetchData() {
    // Здесь логика, которая должна вызываться при показе окна
    fetch("...")
      .then((r) => r.json())
      .then(setData);
  }, []);
  return <div>{data}</div>;
};

const ModalPageWrapper = ({ id, ...restProps }) => {
  const { activeModal } = useModalRootContext();

  useEffect(
    function enableSomeEffect() {
      if (id === activeModal) {
        // Здесь логика, которая должна вызываться при показе окна
      }
    },
    [id, activeModal],
  );

  return (
    <ModalPage id={id} {...restProps}>
      <SomeAsyncEffect />
    </ModalPage>
  );
};

const App = () => {
  return (
    <ModalRoot activeModal="example-1">
      <ModalPageWrapper id="example-1" />
      {/* или */}
      <ModalPage id="example-2">
        <SomeAsyncEffect />
      </ModalPage>
    </ModalRoot>
  );
};
```

> При `keepMounted` содержимое `ModalPage` или `ModalCard` остаётся смонтированным даже при закрытом окне. Для логики, которая должна выполняться только в открытом окне, проверяйте `activeModal`.

### Отключение заднего фона у конкретного модального окна

Чтобы скрыть подложку для одного окна, передавайте `disableModalOverlay`, когда активно это окно.

```jsx
<ModalRoot
  activeModal={activeModal}
  disableModalOverlay={activeModal === "modal-1"}
>
  <ModalPage id="modal-1" />
  <ModalPage id="modal-2" />
</ModalRoot>
```
