## Визуальное оформление

### Тип отображения

Свойство `mode` задаёт оформление панели.

- `"card"` оформляет панель как карточку с тенью и скруглёнными углами.
- `"plain"` убирает тень и скругления.

По умолчанию оформление зависит от [`viewWidth`](/overview/adaptivity#viewwidth).

| `viewWidth`    | `mode`    |
| -------------- | --------- |
| `SMALL_TABLET` | `"card"`  |
| `MOBILE`       | `"plain"` |

### Центрирование контента

Чтобы выровнять содержимое по центру панели, передайте `centered`.

{/* @example-description: Центрированное содержимое `Panel` через свойство `centered`. */}
<Playground Wrapper={FixedLayoutWrapper} style={{ height: 415, overflow: 'hidden' }}>

```jsx
<Panel centered>
  <PanelHeader>Заголовок экрана</PanelHeader>
  <div>Отцентрованный контент</div>
</Panel>
```

</Playground>

### Фон страницы

Передайте `disableBackground`, чтобы сделать фон панели прозрачным.

{/* @example-description: Панель с отключённым фоном через `disableBackground`. */}
<Playground Wrapper={FixedLayoutWrapper} style={{ height: 415, overflow: 'hidden' }}>

```jsx
<Panel disableBackground>
  <PanelHeader>Заголовок экрана</PanelHeader>
  <Placeholder stretched>За мной нет фона</Placeholder>
</Panel>
```

</Playground>
