# IconButton [tag:component]

Кнопка с иконкой без видимого текста. Наследует свойства [`Tappable`](/components/tappable), в том числе `onClick`, `disabled` и `href`. Свойство `label` задаёт подпись для скринридера.

</Overview>

{/* @example-description: Базовая кнопка-иконка `IconButton` с подписью для скринридера через `label`. */}
<Playground>
  ```jsx
  <IconButton label="Удалить" onClick={() => {}}>
    <Icon16Delete />
  </IconButton>
  ```
</Playground>

## Контент

Передайте иконку в `children`. Рекомендуемые размеры — 16, 24, 28 или 36 пикселей.

## Доступность (a11y) [#a11y]

Компонент использует тег `<button>` по умолчанию и `<a>`, если задан `href`. Поддерживает стандартные атрибуты `aria-*`.

> Если одновременно переданы свойства `href` и `disabled`, компонент отключает `href`,
> чтобы соответствовать требованиям доступности. По возможности избегайте такой комбинации.

Задайте подпись в `label`, чтобы скринридер мог озвучить назначение кнопки.

### Альтернативные способы:

- Оберните текст в `VisuallyHidden` и передайте его в `children` вместе с иконкой.

  ```jsx
  <IconButton>
    <VisuallyHidden>Поиск</VisuallyHidden>
    <Icon16Search />
  </IconButton>
  ```

- Задайте подпись в `aria-label`.

  ```jsx
  <IconButton aria-label="Поиск">
    <Icon16Search />
  </IconButton>
  ```

- Передайте подпись в `title`.

  ```jsx
  <IconButton title="Поиск">
    <Icon16Search />
  </IconButton>
  ```

- Разместите подпись в отдельном элементе и укажите его `id` в `aria-labelledby`.

  ```jsx
  <span id="search-label">Поиск</span>
  <IconButton aria-labelledby="search-label">
  <Icon16Search />
  </IconButton>
  ```
