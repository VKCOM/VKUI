# CellButtonGroup [tag:component]

Группа кнопок [`CellButton`](/components/cell-button) для связанных действий в списке.

Связанные компоненты:

- [`CellButton`](/components/cell-button)

</Overview>

{/* @example-description: Группа из двух `CellButton` с разделителем для связанных действий. */}
<Playground>
  ```jsx
  <CellButtonGroup>
    <CellButton appearance="negative" centered onClick={() => {}}>
      Пожаловаться
    </CellButton>
    <CellButtonGroup.Separator />
    <CellButton centered onClick={() => {}}>
      Отмена
    </CellButton>
  </CellButtonGroup>
  ```
</Playground>

## Особенности использования

- Размер, цвет и состояние задавайте на самих кнопках.
- Группа занимает всю доступную ширину. Кнопки делят её поровну.
- В качестве разделителя используйте подкомпонент [`CellButtonGroup.Separator`](#separator).

### Сочетание с другими компонентами

Внутри одной группы можно сочетать разные варианты `CellButton`.

{/* @example-description: Комбинация кнопок в группе: обычная и кнопка с иконкой в `before`. */}
<Playground>
  ```jsx
  <CellButtonGroup>
    <CellButton appearance="negative" centered onClick={() => {}}>
      Центрированная
    </CellButton>
    <CellButtonGroup.Separator />
    <CellButton before={<Icon24Add />} centered onClick={() => {}}>
      С иконкой
    </CellButton>
  </CellButtonGroup>
  ```
</Playground>

## CellButtonGroup.Separator [#separator] [tag:component]

Разделитель между кнопками. Поддерживает все свойства [`Separator`](/components/separator), кроме:

- `direction` (фиксированно `horizontal`);
- `padding` (автоматически адаптирован).

## Ограничения

`CellButtonGroup` располагает кнопки только горизонтально. Для вертикальной раскладки используйте [`ButtonGroup`](/components/button-group).

## Доступность (a11y) [#a11y]

Для обеспечения доступности рекомендуется:

- группировать логически связанные действия;
- использовать семантические заголовки при необходимости:

  ```jsx
  <Group header={<Header>Действия с профилем</Header>}>
    <CellButtonGroup>{/* ...*/}</CellButtonGroup>
  </Group>
  ```

- добавлять пояснения для скринридеров:

  ```jsx
  <CellButtonGroup role="group" aria-label="Действия с заказом">
    {/* ...*/}
  </CellButtonGroup>
  ```
