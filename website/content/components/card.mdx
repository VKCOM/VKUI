# Card [tag:component]

Карточка для визуального выделения содержимого. По умолчанию использует тег `<li>` и поддерживает разные варианты оформления.

Связанные компоненты:

- [CardGrid](/components/card-grid)
- [CardScroll](/components/card-scroll)

</Overview>

{/* @example-description: Базовая карточка с текстовым содержимым внутри `Div`. */}
<Playground>
  ```jsx
  <Card>
    <Box padding="system">
      <Text>Содержимое карточки</Text>
    </Box>
  </Card>
  ```
</Playground>

## Основные возможности

### Семантическая разметка

Для одиночной карточки вне списка задайте подходящий тег через `Component`.

```jsx
// Карточка в списке
<Card>
  <Text>Элемент списка</Text>
</Card>

// Одиночная карточка
<Card Component="div">
  <Text>Отдельная карточка</Text>
</Card>
```

## Режимы отображения

Задаётся свойством `mode`.

## Доступность (a11y) [#a11y]

Выбирайте тег, подходящий к месту карточки в разметке. При необходимости передавайте ARIA-роли и атрибуты.
