# UnstyledTextField [tag:component]

`UnstyledTextField` сбрасывает стили браузера по умолчанию для `<input>` и `<textarea>`. [О стилях браузера](https://www.geeksforgeeks.org/what-is-a-user-agent-stylesheet/).

</Overview>

{/* @example-description: Базовый `UnstyledTextField` как поле ввода без пользовательских и браузерных стилей. */}
<Playground>
  ```jsx
  <FormItem top="Текст" htmlFor="unstyled-text-field-unstyled-text">
    <UnstyledTextField
      id="unstyled-text-field-unstyled-text"
      as="input"
      name="unstyled-text"
      placeholder="Стилей нет..."
    />
  </FormItem>
  ```
</Playground>

Используйте компонент как основу для поля ввода со своими стилями.

## Обязательные свойства

### Тег компонента [#teg-komponenta]

В свойстве `as` укажите тег поля ввода, `"textarea"` или `"input"`.
