# FormItem [tag:component]

Обёртка для поля формы. Добавляет заголовок и подсказку, показывает результат проверки.
Используйте её для всех полей формы. Если у [`Radio`](/components/radio) или [`Checkbox`](/components/checkbox) нет отдельного заголовка и описания, обёртка им не нужна.

</Overview>

{/* @example-description: Базовый `FormItem` с заголовком поля и связью через `htmlFor/id`. */}
<Playground>
  ```jsx
  const id = React.useId();

  return (
    <FormItem htmlFor={id} top="E-mail">
      <Input type="email" id={id} name="email" autoComplete="email" />
    </FormItem>
  );
  ```
</Playground>

## Структура компонента

Содержимое `FormItem` задают три свойства:

- `top` — заголовок элемента формы;
- `children` — основной контент (поле ввода);
- `bottom` — подсказка или сообщение о статусе валидации.

{/* @example-description: Полная структура `FormItem` с заголовком, полем ввода и пояснением в `bottom`. */}
<Playground>
  ```jsx
  const id = React.useId()
  const bottomId = React.useId()

  return (
    <FormItem
      htmlFor={id}
      top="E-mail"
      bottom="Мы не передаём вашу почту третьим лицам"
      bottomId={bottomId}
    >
      <Input type="email" id={id} name="email" autoComplete="email" aria-labelledby={bottomId} />
    </FormItem>
  );
  ```
</Playground>

### Подкомпоненты

Чтобы собрать заголовок поля из нескольких частей и настроить их доступность, используйте подкомпоненты.

- `<FormItem.Top>` оборачивает составной заголовок, выравнивает его содержимое и задаёт отступы;
- `<FormItem.TopLabel>` выводит заголовок. Если передано `htmlFor`, по умолчанию используется тег `<label>`. Его можно изменить через `Component`;
- `<FormItem.TopAside>` размещает дополнительное содержимое справа от заголовка.

{/* @example-description: Составной заголовок `FormItem` через подкомпоненты `Top`, `TopLabel` и `TopAside`. */}
<Playground>
  ```jsx
  const id = React.useId()

  return (
    <FormItem
      top={
        <FormItem.Top>
          <FormItem.TopLabel htmlFor={id}>Дополнительная информация</FormItem.TopLabel>
          <FormItem.TopAside>0/100</FormItem.TopAside>
        </FormItem.Top>
      }
    >
      <Textarea id={id} name="about" />
    </FormItem>
  );
  ```
</Playground>

## Состояния

#### `disabled`

Свойство `disabled` меняет оформление и блокирует действия вроде удаления поля.

> Свойство `disabled` у `FormItem` блокирует кнопку [удаления](#removable). Чтобы отключить ввод, передайте `disabled` самому полю.

{/* @example-description: `FormItem` и вложенное поле в неактивном состоянии `disabled`. */}
<Playground>
  ```jsx
  const id = React.useId()

  return (
    <FormItem htmlFor={id} top="E-mail" disabled>
      <Input type="email" id={id} name="email" autoComplete="email" disabled />
    </FormItem>
  );
  ```
</Playground>

## Валидация

Задаётся свойством `status`.

- `"default"` — обычное состояние (по умолчанию);
- `"error"` — данные не прошли проверку;
- `"valid"` — данные прошли проверку, в том числе после исправления ошибки.

При ошибке добавьте пояснение, например через `bottom`. При необходимости сообщите и об успешной проверке.

{/* @example-description: Валидационные состояния `FormItem` с сообщением об ошибке и успешным статусом. */}
<Playground direction="column">
  ```jsx
  const emailId = React.useId()
  const emailBottomId = React.useId()
  const textId = React.useId()

  return (
    <>
      <FormItem
        htmlFor={emailId}
        top="E-mail"
        status="error"
        bottom="Пожалуйста, введите e-mail"
        bottomId={emailBottomId}
        required
        noPadding
      >
        <Input aria-labelledby={emailBottomId} id={emailId} type="email" name="email" autoComplete="email" required />
      </FormItem>
      <FormItem htmlFor={textId} top="Описание" status="valid" noPadding>
        <Input id={textId} name="text" />
      </FormItem>
    </>
  );
  ```
</Playground>

## Обязательность поля

Свойство `required` добавляет визуальную отметку обязательного поля. Передайте `required` и самому полю, чтобы сделать его обязательным для заполнения.

```jsx
<FormItem top="Email" required>
  <Input type="email" name="email" autoComplete="email" required />
</FormItem>
```

## Удаление поля [#removable]

Свойство `removable` добавляет кнопку удаления в стиле текущей платформы. Значение `"indent"` добавляет отступ, чтобы выровнять поле по соседним полям с кнопкой удаления.

При `removable={true}` доступны следующие свойства:

- `removePlaceholder` — подпись кнопки удаления (по умолчанию «Удалить»). Скринридер озвучивает её, на iOS она отображается при взаимодействии с кнопкой.
- `onRemove` — обработчик нажатия на кнопку удаления.

{/* @example-description: Удаляемое поле формы `FormItem` с обработчиком `onRemove` и пояснением в `bottom`. */}
<Playground>
  ```jsx
  const id = React.useId()
  const bottomId = React.useId()

  return (
    <FormItem
      htmlFor={id}
      removable
      onRemove={() => alert('Обработчик удаления')}
      top="Отчество"
      bottom="Если у вас нет отчества — удалите этот пункт"
      bottomId={bottomId}
    >
      <Input id={id} aria-labelledby={bottomId} />
    </FormItem>
  );
  ```
</Playground>

## Отступы

По умолчанию компонент добавляет отступы по правилам дизайн-системы, например при использовании в `Group`. Чтобы убрать отступы, передайте `noPadding`.

## Тестирование (e2e) [#e2e]

Для поиска элементов в тестах задайте идентификаторы через свойства:

- `removeButtonTestId` — `id` кнопки удаления при `removable={true}`;
- `toggleButtonTestId` — `id` кнопки подтверждения удаления (**только для iOS**).

## Доступность (a11y) [#a11y]

Свяжите подпись и подсказку с полем, чтобы скринридер мог их озвучить.

- Передайте текст подписи в `top`, а идентификатор поля — в `htmlFor`. У самого поля должен быть такой же `id`.
- Если передаёте подсказку в `bottom`, задайте одинаковое значение для `bottomId` у `FormItem` и `aria-describedby` у поля.
