# File [tag:component]

Кнопка открывает системный диалог выбора файла. Компонент принимает свойства [`Button`](/components/button) и стандартные атрибуты `<input type="file" />`.

</Overview>

{/* @example-description: Базовая кнопка `File` для открытия системного диалога выбора файла. */}
<Playground>
  ```jsx
  <FormItem top="Вложение" htmlFor="file-attachment">
    <File id="file-attachment" name="attachment">Выберите файл</File>
  </FormItem>
  ```
</Playground>


## Кастомизация

Через `slotProps` передавайте свойства вложенным элементам. Например, CSS-классы, атрибуты `data-*` и `aria-*`, обработчики событий или `getRootRef` для доступа к элементу.

{/* @example-description: Кастомизация внутренних элементов `File` через `slotProps` и `getRootRef`. */}
<Playground>
  ```jsx
  const inputRef = React.useRef();

  return (
    <File
      className="my-root-class"
      data-testid="file-root"
      id="file-input-id"
      slotProps={{
        root: {
          id: 'file-root-id',
        },
        input: {
          className: 'my-input-class',
          'aria-label': 'file',
          getRootRef: inputRef,
        },
      }}
    >
      Выберите файл
    </File>
  )
  ```
</Playground>

## Доступность (a11y) [#a11y]

Компонент использует стандартный элемент `<input type="file" />`. Чтобы описать действие, добавьте подпись через `FormItem` или свяжите поле с текстом через `aria-describedby` либо `aria-labelledby`.
