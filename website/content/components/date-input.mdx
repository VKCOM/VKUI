# DateInput [tag:component]

Поле для ввода даты и времени. Дату можно ввести вручную или выбрать в календаре.

## Применение компонента

> Компонент рассчитан на планшеты и настольные компьютеры. На других мобильных устройствах его работа не гарантируется.

Для ввода диапазона дат со всплывающим календарём используйте [`DateRangeInput`](/components/date-range-input).

Если поле ввода не нужно, используйте [`Calendar`](/components/calendar) для выбора даты и времени.

## Режим работы

Компонент работает в контролируемом и неконтролируемом режимах. Подробнее об этих режимах читайте в [документации React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

В неконтролируемом режиме опустите `value`. Чтобы задать начальное значение, передайте `defaultValue`.
В контролируемом режиме передайте текущее значение в `value` и обновляйте его в обработчике `onChange`.

```jsx
// Неконтролируемое состояние
<DateInput defaultValue={new Date()} />;

// Контролируемое состояние
const [date, setDate] = React.useState(new Date());

<DateInput value={date} onChange={setDate} />;
```

## Состояния

### `disabled`

Свойство `disabled` блокирует взаимодействие с компонентом и меняет его внешний вид.

  ```jsx
    <DateInput
  ```

## Валидация

Свойство `status` показывает результат проверки поля. Значение `"error"` отмечает ошибку, `"valid"` — успешную проверку.

> Если вы используете `DateInput` вместе с [`FormItem`](/components/form-item), вам достаточно указать свойство `status` только у
> [`FormItem`](/components/form-item).

{/* @example-description: Валидационные состояния `DateInput`: ошибка и успешное заполнение. */}
<Playground style={{ width: 'fit-content' }}>

## Тестирование (e2e) [#e2e]

В тестах используйте следующие свойства, чтобы задать атрибуты `data-testid` полей:

- `dayFieldTestId` — поле ввода дня;
- `monthFieldTestId` — поле ввода месяца;
- `yearFieldTestId` — поле ввода года;
- `hourFieldTestId` — поле ввода часа;
- `minuteFieldTestId` — поле ввода минут.

Подробности в разделе [«Свойства и методы»](#api).

## Доступность (a11y) [#a11y]

Свойство `accessible` меняет вид календаря и управление им для пользователей ассистивных технологий. Начиная с `v8` оно включено по умолчанию. Оставляйте его включённым. В `v9` свойство планируется удалить.

При включённом `accessible`:

- Кнопка календаря видна и в пустом, и в заполненном поле.
- Календарь открывается при нажатии на кнопку календаря или на поле. Если поле в фокусе, календарь можно открыть клавишей `Space`.
- При открытии фокус переходит в календарь, при закрытии возвращается на `DateInput`. Чтобы отключить захват фокуса, передайте `disableFocusTrap`. Чтобы выбрать, куда возвращать фокус, используйте `restoreFocus`.

Нажатие на связанный с полем `<label>` переводит фокус на `DateInput`, но скринридер не озвучивает подпись. Чтобы скринридер мог озвучить её, продублируйте текст в `aria-label`.

```jsx
<label>
  День рождения
  <DateInput aria-label="День рождения" />
</label>
```

```jsx
<label htmlFor="date"> День рождения</label>
<DateInput id="date" aria-label="День рождения" />
```

```jsx
<FormItem top="День рождения" htmlFor="date">
  <DateInput id="date" aria-label="День рождения" />
</FormItem>
```

## Интернационализация (i18n) [#i18n]

> Названия месяцев и дней недели зависят от `locale` в [`ConfigProvider`](/components/config-provider).

Компонент форматирует даты через [Intl.DateTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat).
Подписи интерактивных элементов, включая календарь, переведите отдельно. Скринридеры озвучивают эти подписи, даже если их нет на экране.

Ниже перечислены основные свойства для перевода. Полный список есть в [таблице свойств](#api).

- `changeHoursLabel`;
- `changeMinutsLabel`;
- `changeDayLabel`;
- `changeMonthLabel`;
- `changeYearLabel`;
- `prevMonthLabel`;
- `nextMonthLabel`;
- `clearFieldLabel`;
- `showCalendarLabel`;
- `calendarLabel`.
