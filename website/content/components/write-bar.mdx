# WriteBar [tag:component]

`WriteBar` — поле ввода сообщения, как в мессенджере. Принимает свойства нативного `<textarea>`.

</Overview>

{/* @example-description: Базовый `WriteBar` с иконкой вложений в слоте `before`. */}
<Playground>
  ```jsx
  <WriteBar name="message" before={<WriteBarIcon mode="attach" />} placeholder="Введите сообщение..." />
  ```
</Playground>

## Режим работы

Поле поддерживает контролируемый и неконтролируемый режимы. [Документация React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

В неконтролируемом режиме опустите `value`. Начальное значение можно задать через `defaultValue`.
В контролируемом режиме передайте текущее значение в `value` и обновляйте его в обработчике `onChange`.

```jsx
// Неконтролируемое состояние
<WriteBar defaultValue="Текст" />;

// Контролируемое состояние
const [text, setText] = React.useState('Текст');

<WriteBar value={text} onChange={(event) => setText(event.target.value)} />;
```

## Основные элементы

- `before` — элементы слева от поля ввода.
- `after` — элементы справа.
- `inlineAfter` — элементы поверх поля (актуально для iOS).

{/* @example-description: Пример `WriteBar` с элементами в `before`, `after` и `inlineAfter`. */}
<Playground>
  ```jsx
  <WriteBar
    name="message-with-actions"
    before={<WriteBarIcon mode="attach" />}
    after={
      <WriteBarIcon label="Записать голосовое сообщение">
        <Icon24VoiceOutline />
      </WriteBarIcon>
    }
    inlineAfter={
      <WriteBarIcon label="Смайлы и стикеры">
        <Icon24SmileOutline />
      </WriteBarIcon>
    }
    placeholder="Введите сообщение..."
  />
  ```
</Playground>

## Использование иконок [#icons]

Для боковых кнопок используйте `WriteBarIcon`, а для выбора размера иконки по плотности интерфейса — [`AdaptiveIconRenderer`](/components/adaptive-icon-renderer).

По правилам дизайн-системы используйте размер `28px` при плотности `"regular"` и `24px` при `"compact"`. На iOS при плотности `"compact"` допустимы иконки размером `28px`.

{/* @example-description: Адаптивные иконки и динамические действия в `WriteBar` в зависимости от введённого текста. */}
<Playground style={{ width: 290 }}>

```jsx
const [text, setText] = React.useState('');
const platform = usePlatform();

const SmileOutlineIcon = (
  <AdaptiveIconRenderer
    IconCompact={platform === 'ios' ? Icon28SmileOutline : Icon24SmileOutline}
    IconRegular={Icon28SmileOutline}
  />
);

const VoiceOutlineIcon = (
  <AdaptiveIconRenderer
    IconCompact={platform === 'ios' ? Icon28VoiceOutline : Icon24VoiceOutline}
    IconRegular={Icon28VoiceOutline}
  />
);

const KeyboardBotsOutlineIcon = (
  <AdaptiveIconRenderer
    IconCompact={platform === 'ios' ? Icon28KeyboardBotsOutline : Icon24KeyboardBotsOutline}
    IconRegular={Icon28KeyboardBotsOutline}
  />
);

return (
  <WriteBar
    name="chat-message"
    value={text}
    onChange={(e) => setText(e.target.value)}
    before={<WriteBarIcon mode="attach" />}
    inlineAfter={
      <>
        {text.length === 0 && (
          <WriteBarIcon label="Открыть меню бота">{KeyboardBotsOutlineIcon}</WriteBarIcon>
        )}
        {text.length > 0 && (
          <WriteBarIcon label="Эмоджи и стикеры">{SmileOutlineIcon}</WriteBarIcon>
        )}
      </>
    }
    after={
      <>
        {text.length === 0 && (
          <WriteBarIcon label="Эмоджи и стикеры">{SmileOutlineIcon}</WriteBarIcon>
        )}
        {text.length === 0 && (
          <WriteBarIcon label="Записать голосовое сообщение">{VoiceOutlineIcon}</WriteBarIcon>
        )}
        {text.length > 0 && <WriteBarIcon mode="send" />}
      </>
    }
    placeholder="Сообщение"
  />
);
```

</Playground>

## WriteBarIcon [tag:component]

`WriteBarIcon` — кнопка с иконкой внутри `WriteBar`.

### Особенности поведения

- Наследует все свойства `<button>`.
- Подбирает иконку и подпись для Android и iOS в предустановленных режимах.

### Предустановленные режимы

Выберите предустановленный режим, чтобы компонент подобрал иконку и подпись для платформы. Если режим распознан, компонент игнорирует `children` и по умолчанию использует русскую подпись в `label`.

- `attach` — «Прикрепить файл».
- `send` — «Отправить».
- `done` — «Готово».

{/* @example-description: Предустановленные режимы `WriteBarIcon`: `attach`, `send`, `done`. */}
<Playground>
  ```jsx
  <WriteBarIcon mode="attach" />
  <WriteBarIcon mode="send" />
  <WriteBarIcon mode="done" />
  ```
</Playground>

### Использование своей иконки [#ispolzovanie-kastomnyh-ikonki]

{/* @example-description: Пример `WriteBarIcon` с пользовательской иконкой и подписью. */}
<Playground>

```jsx
const platform = usePlatform();

return (
  <WriteBarIcon label="Голосовое сообщение">
    <AdaptiveIconRenderer
      IconCompact={platform === 'ios' ? Icon28VoiceOutline : Icon24VoiceOutline}
      IconRegular={Icon28VoiceOutline}
    />
  </WriteBarIcon>
);
```

</Playground>

### Отображение счётчика

Свойство `count` добавляет к кнопке счётчик, например число прикреплённых файлов.

{/* @example-description: Пример `WriteBarIcon` со счётчиком через свойство `count`. */}
<Playground>
  ```jsx
  <WriteBarIcon mode="attach" count={3} label="Прикреплённые файлы" />
  ```
</Playground>

## Кастомизация

Передавайте свойства внутренним элементам через `slotProps`. Это могут быть CSS-классы, атрибуты `data-*` и `aria-*`,
обработчики событий или `getRootRef` для доступа к DOM-элементу.

{/* @example-description: Кастомизация `WriteBar` через `slotProps` для корня и поля ввода. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  const textareaRef = React.useRef();

  return (
    <WriteBar
      before={<WriteBarIcon mode="attach" />}
      placeholder="Введите сообщение..."
      className="my-root-class"
      data-testid="write-bar-root"
      id="write-bar-textarea-id"
      slotProps={{
        root: {
          id: 'write-bar-root-id',
        },
        input: {
          className: 'my-textarea-class',
          'aria-label': 'Пример slotProps',
          getRootRef: textareaRef,
        },
      }}
    />
  )
  ```
</Playground>

### Доступность (a11y) [#a11y]

Укажите текстовое описание одним из способов:

- Через свойство `label`:

  ```jsx
  <WriteBarIcon label="Прикрепить файл">
    <Icon24Attachment />
  </WriteBarIcon>
  ```

- Через ARIA-атрибуты:

  ```jsx
  <WriteBarIcon aria-label="Отправить сообщение">
    <Icon24Send />
  </WriteBarIcon>
  ```

- Через `VisuallyHidden`:

  ```jsx
  <WriteBarIcon>
    <Icon24SmileOutline />
    <VisuallyHidden>Эмодзи</VisuallyHidden>
  </WriteBarIcon>
  ```

- Через `aria-labelledby` со ссылкой на `id` подписи:

  ```jsx
  <VisuallyHidden id="write_bar_icon_voice">Записать голосовое сообщение</VisuallyHidden>
    <WriteBarIcon aria-labelledby="write_bar_icon_voice">
    <Icon28VoiceOutline />
  </WriteBarIcon>
  ```
