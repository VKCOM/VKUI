# Spinner [tag:component]

`Spinner` показывает, что асинхронная операция ещё выполняется.

Связанные компоненты:

- [`ScreenSpinner`](/components/screen-spinner)

</Overview>

{/* @example-description: Базовый индикатор загрузки `Spinner`. */}
<Playground>
  ```jsx
  <Spinner />
  ```
</Playground>

## Настройка отображения

### Размеры

Размер индикатора задаёт свойство `size`.

{/* @example-description: Сравнение размеров `Spinner`: `xl`, `l`, `m`, `s`. */}
<Playground aria-busy={true} aria-live="polite">
  ```jsx
  <Spinner size="xl" />
  <Spinner size="l" />
  <Spinner size="m" />
  <Spinner size="s" />
  ```
</Playground>

### Анимация

Чтобы отключить анимацию, передайте `disableAnimation`.

{/* @example-description: `Spinner` с отключённой анимацией через `disableAnimation`. */}
<Playground>
  ```jsx
  <Spinner disableAnimation />
  ```
</Playground>

### Цвет

По умолчанию индикатор использует цвет `--vkui--color_icon_medium`. Чтобы унаследовать `color` родительского элемента, передайте `noColor`.

{/* @example-description: `Spinner` с пользовательским цветом контейнера и `noColor`. */}
<Playground>
  ```jsx
  <div style={{ color: "#FF0000" }}>
    <Spinner noColor />
  </div>
  ```
</Playground>

## Когда использовать

- Во время загрузки данных.
- Во время фоновых операций.
- В кнопках и формах, пока выполняется действие.

## Альтернатива

Для полной блокировки интерфейса используйте [`ScreenSpinner`](/components/screen-spinner):

```jsx
<ScreenSpinner state="loading" />
```

## Доступность (a11y) [#a11y]

### Базовые требования

Чтобы скринридер сообщал о загрузке, добавьте атрибуты [`aria-busy`](https://doka.guide/a11y/aria-busy/)
и [`aria-live`](https://doka.guide/a11y/aria-live/) контейнеру, содержимое которого обновляется.

```jsx
<div aria-busy={true} aria-live="polite">
  <Spinner />
</div>
```

### Пользовательский текст для скринридеров

Чтобы заменить текст, который прочитает скринридер, передайте его в `children`.
Индикатор скроет текст с экрана и оставит доступным для ассистивных технологий.

```jsx
<Spinner>
  <VisuallyHidden>Идёт загрузка профиля...</VisuallyHidden>
</Spinner>
```

## unstable_ExpressiveSpinner

Нестабильный индикатор загрузки в стиле
[M3 Expressive](https://m3.material.io/components/loading-indicator/overview).
Принимает те же свойства, что и `Spinner`. На платформе `ios` отображается обычный `Spinner`.

<Playground>
  ```jsx
  import { unstable_ExpressiveSpinner as ExpressiveSpinner} from "@vkontakte/vkui";

  <ExpressiveSpinner size="xl" />
  ```
</Playground>
