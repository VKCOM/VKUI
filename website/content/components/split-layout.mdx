# SplitLayout [tag:component]

`SplitLayout` организует многоколоночный интерфейс. Для каждой колонки используйте [`SplitCol`](#split-col).

Чтобы добавить боковые отступы экранам на базе [`Panel`](/components/panel), передайте в [`SplitCol`](#split-col) свойство `autoSpaced`.

Связанные страницы и компоненты:

- [Навигация](/overview/navigation)
- [`Panel`](/components/panel)
- [`PanelHeader`](/components/panel-header)

## Применение компонента

<Callout>Используйте один `SplitLayout` на всё приложение.</Callout>

Разместите `SplitLayout` ближе к корню приложения. [Предварительная настройка навигации](/overview/navigation#initial-setup).

## Выравнивание

Свойство `center` управляет горизонтальным выравниванием содержимого.

- `true` — весь контент выравнивается по центру;
- `false` — выравнивание не применяется.

## Сквозная шапка

Чтобы добавить общую шапку над колонками, передайте [`PanelHeader`](/components/panel-header) в свойство `header`.

{/* @example-description: Общая шапка `PanelHeader` над колонками через свойство `header`. */}
<Playground Wrapper={FixedLayoutWrapper}>

```jsx
const platform = usePlatform();
const hasHeader = platform !== 'vkcom';
const { viewWidth } = useAdaptivityConditionalRender();

return (
  <SplitLayout header={hasHeader && <PanelHeader delimiter="none" />}>
    {viewWidth.tabletPlus && (
      <SplitCol className={viewWidth.tabletPlus.className} fixed width={280} maxWidth={280}>
        <Panel layoutMode="card">
          {hasHeader && <PanelHeader />}
          <Group>
            <Box padding="system">Колонка слева</Box>
          </Group>
        </Panel>
      </SplitCol>
    )}
    <SplitCol maxWidth="560px" stretchedOnMobile autoSpaced>
      <Panel layoutMode="card">
        <PanelHeader>Шапка</PanelHeader>
        <Group layoutMode="card">
          <Box padding="system">Колонка справа</Box>
        </Group>
      </Panel>
    </SplitCol>
  </SplitLayout>
);
```

</Playground>

<Callout>
На платформе `vkcom` свойство `header` можно опустить. Платформу определяет хук [`usePlatform`](/components/platform-provider#use-platform).

```jsx showLineNumbers filename="src/App.tsx"
import { SplitLayout, SplitCol, usePlatform } from '@vkontakte/vkui';

export default function App() {
  const platform = usePlatform();
  const hasHeader = platform !== 'vkcom';

  return (
    <SplitLayout header={hasHeader && <PanelHeader delimiter="none" />}>
      {/* остальной контент */}
    </SplitLayout>
  );
}
```

</Callout>

## Кастомизация

Передавайте свойства внутренним элементам через `slotProps`. Это могут быть CSS-классы, атрибуты `data-*` и `aria-*`,
обработчики событий или `getRootRef` для доступа к DOM-элементу.

{/* @example-description: Кастомизация `SplitLayout` через `slotProps` с добавлением классов, `data-testid` и ссылки на внутренний контейнер. */}
<Playground Wrapper={FixedLayoutWrapper}>

```jsx
const { viewWidth } = useAdaptivityConditionalRender();
const contentRef = React.useRef();

return (
  <SplitLayout
    className="my-root-class"
    data-testid="split-layout-root"
    slotProps={{
      content: {
         className: 'my-content-class',
        'data-testid': 'split-layout-content',
        getRootRef: contentRef,
      },
    }}
  >
    {viewWidth.tabletPlus && (
      <SplitCol fixed width={280} maxWidth={280} className={viewWidth.tabletPlus.className}>
        <div
          style={{
```
