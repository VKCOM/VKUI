Календарь для выбора начальной и конечной дат.
Компонент показывает два месяца одновременно, чтобы было проще выбрать длинный диапазон.

## Применение компонента

> Компонент рассчитан на планшеты и настольные устройства. На смартфонах его работа не гарантируется.


Для ввода диапазона дат в поле со всплывающим календарём используйте [`DateRangeInput`](/components/date-range-input).

Для выбора одной даты и времени используйте [`Calendar`](/components/calendar).

## Режим работы

Подробнее о режимах работы читайте в [документации React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

В неконтролируемом режиме не передавайте `value`. Чтобы задать начальное значение, используйте `defaultValue`.
В контролируемом режиме задавайте значение через `value` и обрабатывайте его изменения в `onChange`.

```jsx
// Неконтролируемое состояние
<CalendarRange defaultValue={[new Date(2024, 2, 1), new Date(2024, 2, 10)]} />;

// Контролируемое состояние
const [date, setDate] = React.useState([new Date(2024, 2, 1), new Date(2024, 2, 10)]);

<CalendarRange value={date} onChange={setDate} />;
```

## Локализация

Чтобы изменить подписи, используйте `changeMonthLabel`, `changeYearLabel` и другие свойства `*Label`.

> Названия месяцев и дней недели зависят от `locale` в [`ConfigProvider`](/components/config-provider).

## Тестирование (e2e) [#e2e]

```jsx

  leftPartHeaderTestsData={{
    monthDropdownTestId: 'left-month-dropdown',
  }}
  rightPartHeaderTestsData={{
    monthDropdownTestId: 'right-month-dropdown',
  }}

```

## Доступность (a11y) [#a11y]

Компонент поддерживает навигацию с клавиатуры и добавляет атрибуты `aria-*` интерактивным элементам.

При использовании компонента убедитесь, что все текстовые метки
(`changeMonthLabel`, `changeYearLabel` и остальные `*Label` свойства) корректно описывают действия для пользователей скринридеров.
