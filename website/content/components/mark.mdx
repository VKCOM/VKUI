# Mark [tag:component]

Компонент выделяет слова и фразы фоном, например в результатах поиска или цитатах.

</Overview>

{/* @example-description: Базовое выделение фрагмента текста компонентом `Mark`. */}
<Playground>
  ```jsx
  <Text>
    Что? <Mark>Где</Mark>? Когда?
  </Text>
  ```
</Playground>

## Особенности

- Принимает стандартные HTML-атрибуты.
- Наследует цвет текста.
- Поддерживает выделение на нескольких строках.

## Рекомендации

- Не используйте для интерактивных элементов.
- Сочетайте с текстовыми компонентами ([`Text`](/components/text), [`Headline`](/components/headline), [`Paragraph`](/components/paragraph)).

## Доступность (a11y) [#a11y]

Компонент обозначает выделенный фрагмент тегом `<mark>`.
