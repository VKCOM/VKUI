# EllipsisText [tag:component]

Компонент ограничивает число строк текста. Если текст не помещается, в конце появляется многоточие.

</Overview>

{/* @example-description: Ограничение длинного текста с отображением многоточия при переполнении. */}
<Playground>
  ```jsx
  <EllipsisText maxWidth={200}>
    Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut
    labore et dolore magna aliqua.
  </EllipsisText>
  ```
</Playground>

## Типографика

Передайте типографический компонент, например [`Text`](/components/text) или [`Paragraph`](/components/paragraph), в свойство `Component`.

{/* @example-description: Использование `EllipsisText` с типографическим компонентом через свойство `Component`. */}
<Playground>
  ```jsx
  <EllipsisText Component={Footnote} maxWidth={100}>
    Мелкий текст скрыт за многоточием
  </EllipsisText>
  ```
</Playground>

## Известные ограничения [#limitations]

Для работы `EllipsisText` ограничьте ширину ближайшего родителя, если она ещё не ограничена.

Например, у [`HorizontalCell`](/components/horizontal-cell) с `size="auto"` ширина не ограничена. В примере она ограничена шириной изображения.

{/* @example-description: Ограничение текста в `HorizontalCell` с явным `maxWidth` для корректного ellipsis. */}
<Playground>
  ```jsx
  <HorizontalCell
    size="auto"
    title={
      <EllipsisText maxWidth={100} maxLines={2}>
        Lorem ipsum dolor sit amet, consectetur adipiscing elit
      </EllipsisText>
    }
  >
    <Image
      size={100}
      borderRadius="l"
      src="https://sun9-24.userapi.com/c639120/v639120173/3fe6f/tgPr7lecAY4.jpg"
    />
  </HorizontalCell>
  ```
</Playground>
