<Overview group="configuration">
# PlatformProvider [tag:component]

Переопределяет платформу для части приложения.

</Overview>

## Платформа

Передайте платформу в `value`.

- `"android"` — базовое оформление для настольных и мобильных устройств.
- `"ios"` — оформление для iOS и iPadOS.
- `"vkcom"` — оформление для приложений, встроенных в [vk.ru](https://vk.ru). Используйте его только для таких приложений, поскольку оно не рассчитано на адаптивный интерфейс.

```jsx
<PlatformProvider value="ios">
  {/* часть вашего приложения, требующая переопределения платформы */}
</PlatformProvider>
```

> **Обратите внимание**
>
> Чтобы стили выбранной платформы применились, вложенный компонент должен принимать `className` и передавать его корневому элементу.
>
> ```jsx
> function BadComponent({ children }) {
>   return (
>     <Box padding="system">
>       <Button>I'm not ios 😔</Button>
>     </Box>
>   );
> }
> function GoodComponent({ className, children }) {
>   return (
>     <Box padding="system" className={className}>
>       <Button>I'm ios 😎</Button>
>     </Box>
>   );
> }
> function InfoBoard({ children }) {
>   return (
>     <PlatformProvider value="ios">
>       <BadComponent /> {/* стили "ios" не применяются */}
>       <GoodComponent /> {/* стили "ios" применяются */}
>     </PlatformProvider>
>   );
> }
> ```

## Хук usePlatform [#use-platform]

Хук `usePlatform` возвращает текущую платформу.

```jsx
import { usePlatform } from '@vkontakte/vkui';
```

```jsx
const platform = usePlatform();
```
