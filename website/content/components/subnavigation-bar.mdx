# SubnavigationBar [tag:component]

Горизонтальная панель с кнопками для навигации по подразделам или управления содержимым.
Стрелки показывают, что часть кнопок можно увидеть, прокрутив панель.

## Когда использовать

- Для переключения между связанными подразделами.
- Для включения фильтров или выбора сортировки.
- Для открытия модальных окон.
- Для группировки действий, когда места мало.

## Режимы работы

### Фиксированная ширина

При `fixed={true}` панель равномерно распределяет пространство между элементами и отключает горизонтальную прокрутку.

Рекомендуется использовать 2–5 элементов. Для длинных подписей настройте `textLevel` у `SubnavigationButton`.

### Горизонтальная прокрутка

При `fixed={false}` (по умолчанию) панель поддерживает горизонтальную прокрутку.
Поддерживает [свойства из HorizontalScroll](/components/horizontal-scroll):

- `showArrows` — управление видимостью стрелок;
- `getScrollToLeft` и `getScrollToRight` — настройка прокрутки влево и вправо;
- `scrollAnimationDuration` — длительность анимации прокрутки.
