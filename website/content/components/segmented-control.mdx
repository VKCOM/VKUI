## Применение компонента

Используйте `SegmentedControl` для навигации, как [`Tabs`](/components/tabs), или для выбора значения в форме, как [`RadioGroup`](/components/radio-group).

Рекомендуется от трёх до семи кнопок на планшетах и десктопах и до пяти на мобильных устройствах.

Оформляйте все кнопки одинаково — только с иконками или только с текстом.

## Режим работы

- В неконтролируемом режиме компонент хранит значение сам. Чтобы задать начальное значение, передайте `defaultValue`.
- В контролируемом режиме передайте текущее значение в `value` и обновляйте его в обработчике `onChange`.

Подробнее о режимах работы в [документации React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

```jsx
const colors = [
  {
    value: 'red',
    label: 'Красный',
  },
  {
    value: 'green',
    label: 'Зелёный',
  },
  {
    value: 'blue',
    label: 'Синий',
  },
];

// Неконтролируемое состояние
<SegmentedControl options={colors} defaultValue="red" />;

// Контролируемое состояние
const [color, setColor] = React.useState('red');

<SegmentedControl options={colors} value={color} onChange={setColor} />;
```

## Доступность (a11y) [#a11y]

По умолчанию компонент использует `role="radiogroup"` и ведёт себя как группа переключателей.

### Использование как навигационного элемента [#tabs-usage]

Чтобы использовать `SegmentedControl` для навигации, свяжите каждый вариант с его панелью.

1. Задайте компоненту `role="tablist"`.
2. Задайте каждому варианту уникальный `id`. В `aria-controls` укажите `id` панели, которая открывается при его выборе.
3. У каждой панели `id` должен совпадать со значением `aria-controls` соответствующего варианта. Добавьте панели `role="tabpanel"` и `tabIndex={0}`, чтобы на неё можно было перейти с клавиатуры. В `aria-labelledby` укажите `id` варианта, который открывает панель.

{/* @example-description: Использование `SegmentedControl` как `tablist` с управлением связанными `tabpanel`. */}
<Playground Wrapper={BlockWrapper}>

```jsx
const [selected, setSelected] = React.useState('news');

return (
  <Group>
    <SegmentedControl
      role="tablist"
      value={selected}
      onChange={(value) => setSelected(value)}
      options={[
        {
          'label': 'Новости',
          'value': 'news',
          'aria-controls': 'tab-content-news',
          'id': 'tab-news',
        },
        {
          'label': 'Интересное',
          'value': 'recommendations',
          'aria-controls': 'tab-content-recommendations',
          'id': 'tab-recommendations',
        },
      ]}
    />
    {selected === 'news' && (
      <Box padding="system" id="tab-content-news" aria-labelledby="tab-news" role="tabpanel" tabIndex={0}>
        Контент новостей
      </Box>
    )}
    {selected === 'recommendations' && (
      <Box padding="system"
        id="tab-content-recommendations"
        aria-labelledby="tab-recommendations"
        role="tabpanel"
        tabIndex={0}
      >
        Контент рекомендаций
      </Box>
    )}
  </Group>
);
```

</Playground>
