# ModalOutsideButton [tag:component]

Кнопка для правого верхнего угла `ModalPage` и `ModalCard` в режиме `compact`. В кнопку рекомендуется передавать иконку размером `20px`.

Передайте кнопку в `outsideButtons`. Если кнопок несколько, объедините их в `React.Fragment`.

## Доступность (a11y)

Передайте имя кнопки через `aria-label`, чтобы скринридер объявлял её назначение.

```jsx
<ModalOutsideButton aria-label="Больше" onClick={() => {}}>
  <Icon20More />
</ModalOutsideButton>
```
