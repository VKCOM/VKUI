# Separator [tag:component]

Горизонтальный или вертикальный разделитель. Цвет и отступы разделителя можно настроить.

</Overview>

## Основное использование

### Горизонтальный разделитель

import { BlockWrapper } from "@/components/wrappers";

{/* @example-description: Базовый горизонтальный разделитель `Separator` между блоками контента. */}
<Playground Wrapper={BlockWrapper}>
  ```jsx
  <Separator />
  ```
</Playground>

### Вертикальный разделитель

Поместите вертикальный разделитель в `flex`-контейнер.

{/* @example-description: Вертикальные разделители `Separator` между элементами в строке. */}
<Playground>
  ```jsx
  <Link href="#news">Новости</Link>
  <Separator direction="vertical" size="xl" />
  <Link href="#calls">Звонки</Link>
  <Separator direction="vertical" size="xl" />
  <Link href="#friends">Друзья</Link>
  ```
</Playground>

## Отступы

Чтобы добавить отступы вокруг разделителя, передайте в `size` значение из дизайн-системы (например, `"s"`, `"m"`, `"l"`), число или CSS-переменную.

```jsx
<Separator size="xs" /> // 4px
<Separator size={32} /> // 32px
<Separator size="var(--custom-spacing)" /> // Кастомная CSS-переменная
```

## Свойства компонентов раскладки

> `Separator` принимает те же свойства `flex`, что и [`Box`](/components/box/#flex-props).
