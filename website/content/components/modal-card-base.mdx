# ModalCardBase [tag:component]

Основа модальной карточки с настраиваемым содержимым.
Используется в `ModalCard`.

Связанные компоненты:

- [`ModalCard`](/components/modal-card)

</Overview>

{/* @example-description: Базовый `ModalCardBase` с иконкой, описанием и группой кнопок действий. */}
<Playground>
  ```jsx
  <ModalCardBase
    icon={<Icon56MoneyTransferOutline />}
    title="Подтверждение перевода"
    description="Сумма: 5 000 ₽ · Получатель: Иван Петров"
    actions={
      <ButtonGroup mode="horizontal" gap="s" stretched>
        <Button size="l" mode="primary" stretched>
          Подтвердить
        </Button>
        <Button size="l" mode="secondary" stretched>
          Отмена
        </Button>
      </ButtonGroup>
    }
    dismissLabel="Закрыть"
  />
  ```

## Ключевые элементы

### Визуальные компоненты

#### Иконка

В `icon` рекомендуется передавать контурную иконку или аватар.

- контурные иконки размером `56px` (`<Icon56...Outline />`);
- аватары размером `72px` (`<Avatar size={72} src={...} />`).

#### Текстовые блоки

- В `title` передайте заголовок.
- В `description` передайте поясняющий текст.

### Интерактивные элементы

- В `actions` передайте группу кнопок (`Button`).
- В `outsideButtons` передайте дополнительные кнопки для режима `compact`. Для них рекомендуется [`ModalOutsideButton`](/components/modal-outside-button).

## Блокировка закрытия

В `ModalCard` свойство `preventClose` отключает закрытие по нажатию на подложку, смахиванию и клавише `Esc`. `ModalCardBase` отвечает за вёрстку, поэтому при самостоятельном использовании логику закрытия нужно настроить отдельно.

## Размеры и адаптивность

Компонент подстраивается под ширину экрана. В `size` можно задать максимальную ширину на десктопе. По умолчанию она равна `450px`.

## Кнопка для закрытия

Свойство `dismissButtonMode` определяет, будет ли кнопка закрытия внутри (`inside`), снаружи (`outside`) или скрыта (`none`).
Внешняя кнопка доступна только в режиме `compact` на десктопах и планшетах. На iOS в мобильном режиме кнопка отображается внутри, если она включена.

> Если вы скрываете кнопку закрытия через `dismissButtonMode="none"` или отключаете стандартные способы закрытия через `preventClose`, предусмотрите способ закрыть окно.

## Отступы между контентом и кнопками действий (`actions`)

По умолчанию отступ над кнопками в `actions` равен `16px`. Если для содержимого карточки по дизайн-системе нужен отступ больше, добавьте [`Spacing`](/components/spacing) в `actions`.

{/* @example-description: `ModalCardBase` с ручной настройкой отступа перед блоком `actions` через `Spacing`. */}
<Playground>
  ```jsx
  <ModalCardBase
    dismissButtonMode="inside"
    dismissLabel="Закрыть"
    title="Десктопная и планшетная версии с крестиком внутри"
    description="Сверху будет безопасный отступ до иконки"
    actions={
      <React.Fragment>
        <Spacing size={16} />
        <Button size="l" mode="primary" stretched>
          Некая кнопка
        </Button>
      </React.Fragment>
    }
  />
  ```
</Playground>

## Доступность (a11y)

Если `ModalCardBase` служит модальным окном, задайте `role="dialog"` и `aria-modal="true"` на самом компоненте или его родителе. Так ассистивные технологии распознают окно как модальное.

Задайте краткое доступное имя окна, чтобы скринридер объявлял его назначение.

- Если заголовок передан в `title`, укажите одинаковые значения в `titleId` и `aria-labelledby`. Задайте `aria-labelledby` на элементе с `role="dialog"`.
- Если заголовок находится в другом элементе, укажите его `id` в `aria-labelledby`.
- Если видимого заголовка нет, передайте имя в `aria-label`.

Кнопка закрытия содержит визуально скрытый текст для скринридеров. Чтобы изменить его, передайте нужный текст в `dismissLabel`.
