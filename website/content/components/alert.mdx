# Alert [tag:component]

Модальное окно для важных сообщений и подтверждения действий.
Например, покажите его, чтобы предупредить об удалении данных и запросить подтверждение.
Внешний вид зависит от платформы. На iOS окно ведёт себя как [нативное оповещение](https://developer.apple.com/design/human-interface-guidelines/alerts).

</Overview>

```jsx
/>
```

```jsx
const [alert, setAlert] = React.useState(null);

const showAlert = () => {
  if (alert) return;
  setAlert(
    <Alert
      onClosed={() => setAlert(null)}
      dismissLabel="Отмена"
      actions={[
        { title: 'Отмена', mode: 'cancel' },
        { title: 'Удалить', mode: 'destructive' },
      ]}
      title="Удаление документа"
      description="Вы уверены, что хотите удалить этот документ?"
    />,
  );
};

return (
  <>
    <Button onClick={showAlert}>Показать оповещение</Button>
    {alert}
  </>
);
```

## Обязательные свойства

### `onClosed`

Компонент вызывает `onClosed` после завершения анимации закрытия. Удалите `Alert` из DOM в этом обработчике, иначе окно продолжит мешать взаимодействию со страницей и повторному открытию.

## Шапка

Передайте заголовок уведомления в `title`, а описание — в `description`.

```jsx
<Alert title="Удаление документа" description="Вы уверены что хотите удалить этот документ?" />
```

## Кнопки действий

Передайте в `actions` массив объектов, описывающих кнопки.

```jsx
const actions = [
  { title: 'Отмена', mode: 'cancel' },
  {
    title: 'Удалить',
    mode: 'destructive',
    action: () => console.log('Документ удален.'),
  },
];

<Alert
  actions={actions}
  dismissLabel="Отмена"
  onClosed={closePopout}
  title="Удаление документа"
  description="Вы уверены, что хотите удалить этот документ?"
/>;
```

Для каждой кнопки можно указать текст, тип и дополнительные параметры.
Кнопки могут быть ссылками (передайте `href`) или другим компонентом (передайте `Component`).

Свойство `mode` отвечает за внешний вид кнопки:

- `"default"` — стандартный стиль отображения текста;
- `"destructive"` — стиль критических действий (чаще всего красный);
- `"cancel"` — стиль действия отмены.

Используйте `"cancel"` для кнопки, которая закрывает окно и возвращает пользователя к прежнему состоянию без выполнения действия. Добавляйте одну такую кнопку на `Alert` и размещайте её слева или снизу.

Используйте `"destructive"` для действия с разрушительными последствиями, которые пользователь явно не выбирал.

Во всех остальных случаях используйте стиль `"default"`.

Свойство `title` задаёт текст кнопки. Назовите действие, которое произойдёт при нажатии, например «Удалить» или «Отменить подписку». По подписям «Да» и «Нет» труднее понять результат.
Подпись кнопки в стиле `"cancel"` можно уточнить, чтобы пользователь видел разницу между отменой и подтверждением.

```jsx
const actions = [
  { title: 'Не сейчас', mode: 'cancel' },
  {
    title: 'Отменить подписку',
    mode: 'destructive',
    action: () => console.log('Подписка отменена.'),
  },
];

<Alert
  actions={actions}
  dismissLabel="Не сейчас"
  onClosed={closePopout}
  title="Отмена подписки"
  description="Вы уверены, что хотите отменить подписку?"
/>;
```

Передайте обработчик нажатия в `action`. Если включить `autoCloseDisabled`, обработчик получит объект с функцией `close` для закрытия `Alert` вручную.

По умолчанию нажатие на кнопку закрывает окно и вызывает `onClosed`. Чтобы отключить автоматическое закрытие, передайте `autoCloseDisabled`.

Свойство `actionsAlign` задаёт выравнивание кнопок.

- `"left"` — выравнивание по левому краю;
- `"center"` — выравнивание по центру;
- `"right"` — выравнивание по правому краю (по умолчанию).

> Свойство недоступно на платформе iOS.

Свойство `actionsLayout` задаёт расположение кнопок.

- `"horizontal"` — горизонтальное расположение (по умолчанию).
- `"vertical"` — вертикальное расположение;

> На платформе `vkcom` возможно только горизонтальное расположение.

### Пользовательские кнопки

Свойство `renderAction` позволяет отобразить свои кнопки, например чтобы они выглядели одинаково на всех платформах.

```jsx
const renderAction = ({ mode, ...restProps }) => {
  return <Button mode={mode === 'cancel' ? 'secondary' : 'primary'} size="m" {...restProps} />;
};

<Alert
  actions={[
    { title: 'Лишить права', mode: 'destructive' },
    { title: 'Отмена', mode: 'cancel' },
  ]}
  dismissLabel="Отмена"
  renderAction={renderAction}
  title="Подтвердите действие"
  description="Вы уверены, что хотите лишить пользователя права на модерацию контента?"
/>;
```

## Кнопка закрытия

Свойство `dismissButtonMode` задаёт положение кнопки закрытия.

- `"outside"` — кнопка закрытия располагается снаружи элемента (по умолчанию);
- `"inside"` — кнопка закрытия располагается внутри элемента;
- `"none"` — кнопка закрытия не отображается.

> **Обратите внимание**
>
> Кнопка закрытия не отображается на платформе iOS и в мобильном представлении (`regular`-режиме)

См. рекомендации по [доступным именам кнопок](#a11y-buttons).

## Управление фокусом

### `autoFocus`

При открытии окна компонент по умолчанию переводит фокус на первый интерактивный элемент. Чтобы отключить автоматическую установку фокуса, передайте `autoFocus={false}`.

Чтобы перевести фокус на контейнер окна, передайте `autoFocus="root"`. Так можно избежать появления подсказки у первого интерактивного элемента сразу при открытии.

### `restoreFocus`

После закрытия окна компонент по умолчанию возвращает фокус на последний активный элемент. Чтобы отключить восстановление фокуса, передайте `restoreFocus={false}`.

В `restoreFocus` также можно передать функцию. Верните `HTMLElement`, чтобы перевести фокус на этот элемент, `false`, чтобы оставить его без восстановления, или `true`, чтобы применить поведение по умолчанию.

## Управление порталами

VKUI использует [порталы](https://react.dev/reference/react-dom/createPortal) для рендеринга `Alert`.

Свойство `usePortal` позволяет настраивать порталы:

- `true` — размещает окно в `AppRoot.portalRoot`, а если контейнер не задан, то в `document.body`. Это поведение по умолчанию.
- `false` или `null` — размещает окно по месту объявления компонента.

Также можно указать конкретный `DOM`-элемент (полученный, например, через `document.getElementById`)
или ссылку на `DOM`-элемент ([`ref`-объект](https://react.dev/learn/manipulating-the-dom-with-refs)).

## Браузерные события

### Click Event

По умолчанию событие `click` не всплывает, что позволяет изолировать компонент от остального приложения.
Если нужно обрабатывать это событие (например, есть глобальный обработчик клика для аналитики), используйте свойство `allowClickPropagation`.

## Тестирование (e2e) [#e2e]

Для тестирования доступны свойства с постфиксом `*TestId` — они помогают находить нужные части компонента:

- `titleTestId` — `id` для заголовка;
- `descriptionTestId` — `id` для описания;
- `dismissButtonTestId` — `id` для кнопки закрытия.

## Доступность (a11y) [#a11y]

Задайте модальному окну `Alert` (`role="dialog"`) доступное имя, чтобы пользователи скринридеров понимали его назначение. Для этого используйте `title`, `aria-label` или `aria-labelledby`.

### Доступные имена кнопок [#a11y-buttons]

Давайте одинаковые имена кнопкам, которые выполняют одно и то же действие. Если кнопка «Отмена» только закрывает `Alert`, задайте кнопке закрытия то же имя через `dismissLabel`.

```jsx
<Alert
  dismissLabel="Отмена"
  actions={[
    { title: 'Отмена', mode: 'cancel' },
    { title: 'Удалить', mode: 'destructive', action: () => addActionLogItem('Документ удален.') },
  ]}
  title="Удаление документа"
  description="Вы уверены, что хотите удалить этот документ?"
/>
```
