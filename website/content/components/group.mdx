## Вложенные Group

Для вложенного `Group` обычно используют `mode="plain"`. Этот режим делает фон прозрачным и скрывает рамку.

## Group.ExpandedContent [#group-expanded-content] [tag:component]

Компенсирует внутренние отступы `Group`.

{/* @example-description: `Group.ExpandedContent` для прокрутки `HorizontalScroll` без горизонтальных отступов группы. */}
<Playground Wrapper={BlockWrapper}>
  ```jsx
  <Group header={<Header>Удаляем для HorizontalScroll отступы Group по горизонтали</Header>}>
    <Group.ExpandedContent direction="inline">
      <HorizontalScroll showArrows>
        {Array.from({ length: 20 }).map((_, index) => {
          return (
            <HorizontalCell key={index} header={index}>
              <Avatar size={56} />
            </HorizontalCell>
          );
        })}
      </HorizontalScroll>
    </Group.ExpandedContent>
  </Group>
  ```
</Playground>

## Подкомпонентный подход

Чтобы собрать `Group` по частям, используйте подкомпоненты.

- `Group.Container` задаёт скругления и внутренние отступы. Принимает основные свойства `Group`, кроме `header` и `description`.
- `Group.Header` выводит заголовок и соответствует свойству `header`. Внутрь рекомендуется передавать [`Header`](#header).
- `Group.Description` добавляет подпись внизу группы и соответствует свойству `description`.

import { BlockWrapper } from '@/components/wrappers';

{/* @example-description: Сборка `Group` из подкомпонентов `Container`, `Header` и `Description`. */}
<Playground Wrapper={BlockWrapper}>
  ```jsx
  <Group.Container separator="hide">
    <Group.Header>
      <Header>Адреса</Header>
    </Group.Header>
    <CellButton onClick={() => {}}>Добавить домашний адрес</CellButton>
    <CellButton onClick={() => {}}>Добавить рабочий адрес</CellButton>
    <Group.Description>
      Для использования в мини-приложениях, Delivery Club, VK Taxi и других сервисах ВКонтакте. Эти
      адреса видны только Вам.
    </Group.Description>
  </Group.Container>
  ```
</Playground>
