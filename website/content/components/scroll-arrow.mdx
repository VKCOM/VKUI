# ScrollArrow [tag:component]

Стрелка для прокрутки содержимого.
Используется внутри [`HorizontalScroll`](/components/horizontal-scroll) и [`Gallery`](/components/gallery).

</Overview>

{/* @example-description: Базовая стрелка `ScrollArrow` с направлением вверх. */}
<Playground>
  ```jsx
  <ScrollArrow direction="up" />
  ```
</Playground>

## Обязательные свойства

### Направление стрелки

Передайте направление в `direction`.

```jsx
<ScrollArrow direction="up" />
<ScrollArrow direction="right" />
<ScrollArrow direction="down" />
<ScrollArrow direction="left" />
```

## Вертикальное смещение

Передайте вертикальное смещение в `offsetY` числом или строкой.

```jsx
<ScrollArrow direction="up" offsetY="-5px" label="Скролл к началу" />
```

## Пользовательские иконки

Чтобы заменить стандартную стрелку, передайте свою иконку в `children`.

{/* @example-description: `ScrollArrow` с пользовательской иконкой вместо стандартной стрелки. */}
<Playground>
  ```jsx
  <ScrollArrow direction="left">
    <Icon24ArrowLeftSquareOutline />
  </ScrollArrow>
  ```
</Playground>

## Особенности

- Компонент учитывает направление письма справа налево (`RTL`).
- Компонент принимает свойства HTML-элемента `<button>`.

## Доступность (a11y) [#a11y]

### Обязательные параметры

Чтобы скринридер объявлял назначение кнопки, передайте в `label` название действия, например «Предыдущий слайд».

  ```jsx
  <ScrollArrow direction="left" label="Предыдущий слайд" />
  ```

### Автоматические метки

Если `label` не указан, используется текст по умолчанию в зависимости от значения `direction`:

- `left` и `up` — «Назад».
- `right` и `down` — «Вперед».
