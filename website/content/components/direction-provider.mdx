# DirectionProvider [tag:component]

Компонент задаёт направление содержимого.

</Overview>

## Направление контента

Задаётся свойством `value`.

- `"ltr"` — слева направо, как в большинстве языков;
- `"rtl"` — справа налево, как в арабском и иврите.

```jsx
<DirectionProvider value="rtl">
  {/* часть вашего приложения, требующая переопределения направления контента */}
</DirectionProvider>
```

> **Обратите внимание**
>
> Всегда задавайте атрибут `dir` корневому элементу внутри `DirectionProvider`. По этому атрибуту браузер определяет направление логических свойств CSS.
>
> ```jsx {2,13,15}
> function MyContent() {
>   const direction = useDirection();
>
>   return (
>     <div dir={direction}>
>       <div style={{ marginInlineStart: '16px' }}>Отступ слева для LTR и справа для RTL</div>
>     </div>
>   );
> }
>
> function App() {
>   return (
>     <DirectionProvider value="rtl">
>       <MyContent />
>     </DirectionProvider>
>   );
> }
> ```

## Хук useDirection [#use-direction]

Хук `useDirection` возвращает текущее направление содержимого.

```jsx
import { useDirection } from '@vkontakte/vkui';
```

```jsx
const direction = useDirection();
```
