## Автопрокрутка

Чтобы включить автопрокрутку, задайте в `timeout` ненулевой интервал между слайдами в миллисекундах.

{/* @example-description: Автоматическая смена слайдов в `Gallery` через свойство `timeout`. */}
<Playground Wrapper={BlockWrapper}>
  ```jsx
  <Gallery slideWidth="90%" align="center" timeout={3000}>
    <div style={{ backgroundColor: 'var(--vkui--color_background_negative)' }} />
    <div style={{ backgroundColor: 'var(--vkui--color_background_positive)' }} />
    <div style={{ backgroundColor: 'var(--vkui--color_background_accent)' }} />
  </Gallery>
  ```
</Playground>

## Кастомизация стрелок навигации

- `arrowSize` — размер стрелок.
- `arrowAreaHeight` — высота области, в которой можно нажать на стрелку. `"stretch"` растягивает её на всю высоту галереи, `"fit"` задаёт фиксированную высоту.
- `showArrows` — показ стрелок при наведении.

{/* @example-description: Кастомизация стрелок `Gallery` через `arrowSize` и `arrowAreaHeight`. */}
<Playground Wrapper={BlockWrapper}>
  ```jsx
  <Gallery slideWidth="90%" showArrows arrowAreaHeight="fit" arrowSize="s">
    <div style={{ backgroundColor: 'var(--vkui--color_background_negative)' }} />
    <div style={{ backgroundColor: 'var(--vkui--color_background_positive)' }} />
    <div style={{ backgroundColor: 'var(--vkui--color_background_accent)' }} />
  </Gallery>
  ```
</Playground>

## Индикатор прогресса

Свойство `bullets` задаёт оформление индикатора слайдов.

- `false` — индикатор скрыт (по умолчанию).
- `"light"` — светлые точки.
- `"dark"` — тёмные точки.
- `"overlay"` — светлые точки на подложке.

{/* @example-description: Включенный индикатор прогресса `bullets` для навигации по слайдам. */}
<Playground Wrapper={BlockWrapper}>
  ```jsx
  <Gallery slideWidth="90%" bullets="overlay" showArrows>
    <div style={{ backgroundColor: 'var(--vkui--color_background_negative)' }} />
    <div style={{ backgroundColor: 'var(--vkui--color_background_positive)' }} />
    <div style={{ backgroundColor: 'var(--vkui--color_background_accent)' }} />
  </Gallery>
  ```
</Playground>

## Контролируемое состояние

Чтобы управлять активным слайдом из своего кода, передайте его индекс в `slideIndex` и обновляйте его в `onChange`.

{/* @example-description: Контролируемая галерея с внешним управлением текущим слайдом. */}
<Playground Wrapper={BlockWrapper}>

```jsx
const [slideIndex, setSlideIndex] = React.useState(0);
return (
  <>
    <Gallery slideWidth="90%" align="center" slideIndex={slideIndex} onChange={setSlideIndex}>
      <div style={{ backgroundColor: 'var(--vkui--color_background_negative)' }} />
      <div style={{ backgroundColor: 'var(--vkui--color_background_positive)' }} />
      <div style={{ backgroundColor: 'var(--vkui--color_background_accent)' }} />
    </Gallery>
    <Flex gap="m" margin="auto" justify="center">
      <Button size="s" onClick={() => setSlideIndex((slideIndex + 2) % 3)}>
        Предыдущий
      </Button>
      <Button size="s" onClick={() => setSlideIndex((slideIndex + 1) % 3)}>
        Следующий
      </Button>
    </Flex>
  </>
);
```

</Playground>

## Параметры анимации

Свойство `animationDuration` задаёт длительность перехода между слайдами, `animationEasing` — скорость перехода в каждый момент анимации. В `animationEasing` можно передать готовое значение или массив аргументов CSS-функции [`cubic-bezier`](https://developer.mozilla.org/en-US/docs/Web/CSS/easing-function/cubic-bezier).

{/* @example-description: Настройка параметров анимации смены слайдов через `animationDuration` и `animationEasing`. */}
<Playground Wrapper={BlockWrapper}>
  ```jsx
  <Gallery
    slideWidth="90%"
    bullets="overlay"
    showArrows
    animationDuration={1000}
    animationEasing={[0, 0, 0.2, 1]}
  >
    <Placeholder style={{ backgroundColor: 'var(--vkui--color_background_negative)' }} title="1" />
    <Placeholder style={{ backgroundColor: 'var(--vkui--color_background_positive)' }} title="2" />
    <Placeholder style={{ backgroundColor: 'var(--vkui--color_background_accent)' }} title="3" />
    <Placeholder style={{ backgroundColor: 'var(--vkui--color_background_negative)' }} title="4" />
    <Placeholder style={{ backgroundColor: 'var(--vkui--color_background_positive)' }} title="5" />
  ```

## Доступность (a11y) [#a11y]

### 1. Навигация

- Сохраняйте ручное переключение слайдов при включённой автопрокрутке.
- Задавайте понятные подписи кнопок через `arrowPrevLabel` и `arrowNextLabel`.
  ```jsx
  arrowPrevLabel = 'Предыдущий слайд';
  arrowNextLabel = 'Следующий слайд';
  ```

### 2. Метаданные галереи

Задайте название галереи через `aria-label` или свяжите её с заголовком через `aria-labelledby`.

```jsx
// Плохо
aria-label="Карусель" // роль указывается автоматически через `aria-roledescription="Карусель"`

// Хорошо
aria-label="Фотографии нового смартфона"
```

### 3. Описание слайдов

Передайте в `slideLabel` функцию, которая возвращает описание для каждого слайда.

```jsx
// Плохо (нет конкретного обозначения, что на слайде)
slideLabel={({ index, total }) => `Слайд ${index}`}

// Хорошо
slideLabel={({ index, total }) => `Техническая схема (${index + 1} из ${total})`}
```

### 4. Контент внутри слайдов

Добавляйте к изображениям содержательный `alt`.

```jsx
// Плохо (неконкретное описание)
<img src="product.jpg" alt="Картинка" />

// Хорошо
<img src="product.jpg" alt="Смартфон на белом фоне с открытой коробкой" />
```

### 5. Дополнительные настройки

При необходимости переопределите стандартные описания ролей.

```jsx
aria-roledescription="Карусель" // Для галереи
slideRoleDescription="Изображение продукта" // Для слайда
```
