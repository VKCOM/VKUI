## Область применения

- Уведомление о новой функции.
- Форма для ввода СМС-кода.

## Анатомия

`ModalCard` использует вёрстку и свойства [`ModalCardBase`](/components/modal-card-base). Внутренние компоненты отвечают за поведение карточки.

- `ModalOutlet` размещает карточку поверх страницы с помощью контейнера с фиксированным позиционированием.
- `ModalOverlay` создаёт интерактивную подложку.
- `ModalCardInternal` управляет поведением карточки.

## Поведение

Свойство `open` открывает и закрывает карточку. По умолчанию она закрыта. При `open={false}` компонент размонтируется. Чтобы сохранить его в DOM, передайте `keepMounted`.

Компонент анимирует карточку и подложку. Он вызывает `onOpen` в начале открытия, `onOpened` после открытия и `onClosed` после закрытия. Когда пользователь пытается закрыть карточку, компонент вызывает `onClose` и передаёт причину. Чтобы закрыть карточку, установите `open={false}`.

В обоих режимах открытая карточка удерживает фокус внутри себя при навигации с помощью `Tab` и `Shift` + `Tab`.

> Когда открываете модальное окно поверх другого, задайте нижнему окну `disableFocusTrap`, чтобы верхнее могло удерживать фокус.

### Настольный режим

В настольном режиме карточка выглядит как диалоговое окно. Настольный режим включается при ширине от 768 пикселей, если у устройства есть указатель или высота области просмотра достигает `ViewHeight.MEDIUM`. На платформе `vkcom` настольный режим включён всегда.

По умолчанию `onClose` получает один из следующих аргументов.

- `click-close-button` при нажатии на кнопку закрытия.
- `click-overlay` при нажатии на подложку `ModalOverlay`.
- `escape-key` при нажатии `Esc`.

### Мобильный режим

В мобильном режиме карточка выдвигается снизу как панель (bottom card).

По умолчанию `onClose` получает один из следующих аргументов.

- `click-overlay` при нажатии на подложку `ModalOverlay`.
- `escape-key` при нажатии `Esc`.
- `swipe-down` при смахивании или перетаскивании панели вниз по правилам ниже.

#### Взаимодействие через тач или указатель мыши

> `<ConfigProvider platform="vkcom" />`
>
> Платформа `vkcom` включает настольный режим. Высота карточки зависит от содержимого, а перетаскивание отключено.

При перетаскивании панели вниз подложка `ModalOverlay` становится прозрачнее.

Компонент вызывает `onClose('swipe-down')` в трёх случаях.

- Высота панели достигла нуля во время перетаскивания.
- Пользователь отпустил панель, когда её высота была меньше половины высоты содержимого.
- Пользователь резко смахнул панель вниз.

Перетаскивание блокируется при взаимодействии с горизонтальной прокруткой, текстовым полем или выделенным текстом. Оно также блокируется, если элемент вызывает `event.stopPropagation()` в `onTouchStart` или `onMouseDown` либо имеет атрибут `data-vkui-block-sheet-behavior`.

## Хук `useModalManager`

Чтобы управлять модальными окнами, воспользуйтесь хуком [`useModalManager`](/components/use-modal-manager).

## Доступность (a11y)

У `ModalCard` с ролью `dialog` должно быть доступное имя. Скринридер объявляет его при открытии карточки.

- Если передать заголовок в `title`, карточка свяжет его с диалоговым окном через `aria-labelledby`.
- Имя также можно передать напрямую через `aria-label` или связать с другим элементом через `aria-labelledby`.
- Если вложить [`ModalPageHeader`](/components/modal-page-header), он свяжет свой заголовок с карточкой через `aria-labelledby`.

## FAQ

### Как правильно применять параметр `autoFocus`?

В React `autoFocus` может прервать CSS-анимацию открытия. Чтобы сфокусировать поле после анимации, вызовите `focus()` в обработчике `onOpened`.

{/* @example-description: Ручная установка фокуса в `ModalCard` после открытия через обработчик `onOpened`. */}
<Playground>

```jsx
const [open, setOpen] = React.useState(false);

const inputRef = React.useRef(null);

const handleOpen = React.useCallback(() => {
  if (inputRef.current) {
    inputRef.current.focus();
  }
}, []);

return (
  <>
    <Button onClick={() => setOpen(true)}>Открыть</Button>
    <ModalCard
      id="modal-with-auto-focus"
      title="Введите ПИН-код"
      open={open}
      onOpened={handleOpen}
      onClose={() => setOpen(false)}
    >
      <Spacing size="xl" />
      <Flex direction="row" gap={24} noWrap>
        <Input type="number" min={0} max={9} pattern="[0-9]{2}" getRootRef={inputRef} />
        <Input type="number" min={0} max={9} pattern="[0-9]{2}" />
        <Input type="number" min={0} max={9} pattern="[0-9]{2}" />
        <Input type="number" min={0} max={9} pattern="[0-9]{2}" />
      </Flex>
    </ModalCard>
  </>
);
```
