# ButtonGroup [tag:component]

Располагает кнопки [`Button`](/components/button) по горизонтали или по вертикали. Позволяет задавать выравнивание и отступы между кнопками.

Связанные компоненты:

- [`Button`](/components/button)

</Overview>

{/* @example-description: Базовая горизонтальная группа из нескольких кнопок. */}
<Playground>
  ```jsx
  <ButtonGroup>
    <Button>Button</Button>
    <Button>Button</Button>
    <Button>Button</Button>
  </ButtonGroup>
  ```
</Playground>

## Особенности использования

- Размер, цвет и состояние задавайте на самих кнопках.
- `stretched` растягивает группу. Если нужно растянуть вложенные кнопки или группы, задайте это отдельно.

## Вложенные `ButtonGroup`

Группы можно вкладывать друг в друга, например чтобы разместить ряд кнопок внутри вертикальной группы.

{/* @example-description: Вертикальная группа с вложенной горизонтальной подгруппой действий. */}
<Playground>
  ```jsx
  <ButtonGroup mode="vertical" gap="m">
    <Button size="l" appearance="accent" stretched>
      Разрешить
    </Button>
    <Button size="l" appearance="accent" stretched>
      Завершить
    </Button>
    <ButtonGroup mode="horizontal" gap="s" stretched>
      <Button size="l" appearance="negative" stretched>
        Не сейчас
      </Button>
      <Button size="l" appearance="positive" stretched>
        Продолжить
      </Button>
    </ButtonGroup>
  </ButtonGroup>
  ```
</Playground>

## Выравнивание кнопок

Чтобы выровнять кнопки по горизонтали в растянутой группе (`stretched`), задайте `align`.

{/* @example-description: Выравнивание растянутой группы кнопок по правому краю контейнера. */}
<Playground>
  ```jsx
  <ButtonGroup gap="s" stretched align="right">
    <Button before={<Icon12Add />} aria-label="Добавить" />
    <Button before={<Icon12Favorite />} aria-label="В Избранное" />
  </ButtonGroup>
  ```
</Playground>

## Доступность (a11y) [#a11y]

`ButtonGroup` по умолчанию использует `role="group"`. Учитывайте рекомендации по доступности для каждой кнопки в группе.
