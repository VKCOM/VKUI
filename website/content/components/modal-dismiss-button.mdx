# ModalDismissButton [tag:component]

Кнопка для закрытия модальных окон на широком экране.
Поместите кнопку в контейнер с `position: relative` и показывайте её на экранах шириной от `ViewWidth.SMALL_TABLET`.

## Доступность (a11y)

Скринридер по умолчанию объявляет кнопку как «Закрыть». Чтобы заменить визуально скрытый текст, передайте его в `children`.

```jsx
<ModalDismissButton>Закрыть кастомное модальное окно</ModalDismissButton>
```
