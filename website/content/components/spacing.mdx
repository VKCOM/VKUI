# Spacing [tag:component]

Вертикальный отступ между элементами интерфейса.

</Overview>

## Основное использование

import { BlockWrapper } from '@/components/wrappers';

{/* @example-description: Базовый вертикальный отступ `Spacing` между двумя текстовыми блоками. */}
<Playground Wrapper={BlockWrapper}>
  ```jsx
  <Text>Текст над отступом</Text>
  <Spacing size="4xl" />
  <Text>Текст под отступом</Text>
  ```
</Playground>

## Размеры отступа

Передайте высоту отступа в `size`. Свойство принимает число, CSS-переменную или значение из дизайн-системы, например `"s"`, `"m"` или `"l"`.

```jsx
<Spacing size="xs" /> // 4px
<Spacing size={32} /> // 32px
<Spacing size="var(--custom-spacing)" /> // Кастомная CSS-переменная
```

## Особенности

`Spacing` добавляет пустой прозрачный блок заданной высоты. Свойство `children` устарело. Чтобы добавить разделительную линию, используйте [`Separator`](/components/separator).
