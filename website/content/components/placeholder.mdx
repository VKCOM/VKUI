# Placeholder [tag:component]

Заглушка для пустого состояния или ошибки.

</Overview>

{/* @example-description: Базовый `Placeholder` для пустого состояния с заголовком и описанием. */}
<Playground>
  ```jsx
  <Placeholder title="Находите друзей">
    Здесь будут отображаться люди, которых вы добавите в друзья
  </Placeholder>
  ```
</Playground>

## Полноэкранный режим (stretched)

Передайте `stretched`, чтобы разместить заглушку по центру пустого экрана и обратить внимание на его состояние.

## Отображение нескольких кнопок

Чтобы показать несколько кнопок, передайте в `action` группу [`ButtonGroup`](/components/button-group).

{/* @example-description: `Placeholder` с несколькими действиями в `ButtonGroup` внутри `action`. */}
<Playground>
  ```jsx
  <Placeholder
    title="Находите друзей"
    action={
      <ButtonGroup mode="vertical" align="center">
        <Button size="m">Найти друзей</Button>
        <Button size="m" mode="tertiary">
          Подробнее
        </Button>
      </ButtonGroup>
    }
  >
    Здесь будут отображаться люди, которых вы добавите в друзья.
  </Placeholder>
  ```
</Playground>

> Добавляйте до трёх кнопок. Выделите основное действие, остальные оформите как вспомогательные.

## Рекомендации по использованию

- Используйте контурные иконки размером от `56px`. У таких иконок из `@vkontakte/icons` в названии есть `Outline`.
- Используйте кнопки размера `l` в режиме `primary` или `tertiary`.
- Включайте `stretched` на экранах без другого содержимого.
- Размещайте интерактивные элементы в `action`.

## Подкомпоненты [#podkomponentyj-podhod]

Заглушку также можно собрать из отдельных подкомпонентов.

{/* @example-description: Сборка `Placeholder` из подкомпонентов `Container`, `Icon`, `Title`, `Description`, `Actions`. */}
<Playground>
  ```jsx
  <Placeholder.Container>
    <Placeholder.Icon>
      <Icon56UserAddOutline />
    </Placeholder.Icon>
    <Placeholder.Title>Находите друзей</Placeholder.Title>
    <Placeholder.Description>
      Здесь будут отображаться люди, которых вы добавите в друзья.
    </Placeholder.Description>
    <Placeholder.Actions>
      <ButtonGroup mode="vertical" align="center">
        <Button size="m">Найти друзей</Button>
        <Button size="m" mode="tertiary">
          Скрыть
        </Button>
      </ButtonGroup>
    </Placeholder.Actions>
  </Placeholder.Container>
  ```
</Playground>
