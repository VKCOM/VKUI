# ChipsInput [tag:component]

Поле для ввода и отображения нескольких значений.
Пользователь может добавлять, удалять и редактировать значения. Компонент отображает каждое значение как `Chip`.

Связанные компоненты:

- [`Chip`](/components/chip)

</Overview>

{/* @example-description: Базовый `ChipsInput` с начальными значениями и плейсхолдером. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <ChipsInput
    defaultValue={[
      { value: 'red', label: 'Красный' },
      { value: 'blue', label: 'Синий' },
    ]}
    placeholder="Введите значение"
  />
  ```

## Режим работы

Подробнее о режимах работы читайте в [документации React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

В неконтролируемом режиме не передавайте `value`. Чтобы задать начальное значение, используйте `defaultValue`.
В контролируемом режиме задавайте значение через `value` и обрабатывайте его изменения в `onChange`.

```jsx
// Неконтролируемое состояние
<ChipsInput
  defaultValue={[
    {
      value: 'red',
      label: 'Красный',
    },
  ]}
/>;

// Контролируемое состояние
const [colors, setColors] = React.useState([]);

<ChipsInput value={colors} onChange={setColors} />;
```

## Управление вводом

### Разделитель

Свойство `delimiter` разбивает введённый или вставленный текст на несколько значений. Например, при `delimiter=","` из текста «Красный,Синий» получится два элемента — «Красный» и «Синий».

В `delimiter` можно передать строку, массив строк или регулярное выражение.

{/* @example-description: Добавление нескольких элементов за один ввод через разделитель `delimiter`. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <ChipsInput placeholder="Используйте запятую" delimiter="," />
  ```
</Playground>

### Потеря фокуса

По умолчанию при потере фокуса компонент не добавляет введённое значение. Чтобы добавлять его, передайте `addOnBlur`.

{/* @example-description: Автодобавление значения при потере фокуса с включенным `addOnBlur`. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <ChipsInput
    defaultValue={[
      {
        value: 'red',
        label: 'Красный',
      },
    ]}
    placeholder="Введите значение"
    addOnBlur
  />
  ```
</Playground>

## Состояния

### `disabled`

Свойство `disabled` делает поле недоступным и меняет его внешний вид.

{/* @example-description: `ChipsInput` в состоянии `disabled` без возможности редактирования. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <ChipsInput defaultValue={[{ value: 'red', label: 'Красный' }]} disabled />
  ```
</Playground>

## Валидация

Свойство `status` показывает результат проверки поля. Передайте `"error"` при ошибке или `"valid"` после успешной проверки.

> Если поле находится внутри [`FormItem`](/components/form-item), достаточно задать `status` у `FormItem`.

{/* @example-description: Варианты валидации `ChipsInput` со статусами `error` и `valid`. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <ChipsInput defaultValue={[{ value: 'red', label: 'Красный' }]} status="error" />
  <ChipsInput defaultValue={[{ value: 'green', label: 'Зелёный' }]} status="valid" />
  ```
</Playground>

## Кастомизация

### Визуальное оформление

Чтобы изменить оформление значения, передайте `renderChip`. В обработчике можно настроить `Chip` или вернуть свой компонент.

{/* @example-description: Кастомный рендер `Chip` с аватаром пользователя через `renderChip`. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  <ChipsInput
    defaultValue={[
      {
        value: '1',
        label: 'Алексей',
        src: 'https://avatars.githubusercontent.com/u/91548592?s=50',
      },
      { value: '2', label: 'Никита', src: 'https://avatars.githubusercontent.com/u/32414396?s=50' },
    ]}
    renderChip={({ value, label, ...rest }, { src }) => (
      <Chip value={value} before={<Avatar src={src} size={20} aria-hidden />} {...rest}>
        {label}
      </Chip>
    )}
  />
  ```
</Playground>

Первый аргумент `renderChip` содержит свойства, необходимые для доступности. Если возвращаете свой компонент, передайте ему эти свойства и обработайте их. Второй аргумент содержит объект со значением из `value` или `defaultValue`.

## slotProps

Передавайте свойства внутренним элементам через `slotProps`.
Например, передайте CSS-класс, атрибут `data-*` или `aria-*`, обработчик события или `getRootRef` для доступа к элементу.

{/* @example-description: Настройка внутренних слотов `ChipsInput` через `slotProps` и `getRootRef`. */}
<Playground style={{ maxWidth: 270 }}>
  ```jsx
  const inputRef = React.useRef();

  return (
    <ChipsInput
      defaultValue={[
        { value: 'red', label: 'Красный' },
        { value: 'blue', label: 'Синий' },
      ]}
      placeholder="Введите значение"
      className="my-root-class"
      data-testid="chips-input-root"
      id="colors-input-id"
      slotProps={{
        root: {
          id: 'chips-input-root-id',
        },
        input: {
          className: 'my-input-class',
          'aria-label': 'Пример slotProps',
          getRootRef: inputRef,
        },
      }}
    />
  )
  ```
</Playground>

## Доступность (a11y) [#a11y]

Компонент обеспечивает базовую доступность через стандартные `HTML`-атрибуты и `ARIA`-роли.

Задайте полю доступное имя одним из следующих способов.

- Оберните поле в `<label>`.

  ```jsx
  <label>
    Список исполнителей
    <ChipsInput placeholder="Введите название" />
  </label>
  ```

- Задайте полю `id` и укажите этот идентификатор в `htmlFor` у `<label>` или [`FormItem`](/components/form-item).

  ```jsx
  <label htmlFor="chips">Список исполнителей</label>
  <ChipsInput placeholder="Введите название" id="chips"/>
  ```

  ```jsx
  <FormItem top="Список исполнителей" htmlFor="chips">
    <ChipsInput placeholder="Введите название" id="chips" />
  </FormItem>
  ```

- Укажите `aria-label`.

  ```jsx
  <ChipsInput placeholder="Введите название" aria-label="Список исполнителей" />
  ```

Чтобы задать имя списку выбранных значений, используйте `chipsListLabel`.
