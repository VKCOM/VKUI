# ConfigProvider [tag:component]

Оберните всё приложение в [`ConfigProvider`](/overview/install#step4), чтобы задать платформу, тему, локализацию и другие глобальные настройки.

</Overview>

## Платформа

Свойство `platform` влияет на внешний вид компонентов, анимации и поведение интерфейса.

- `"android"` — для настольных устройств и устройств на Android.
- `"ios"` — для устройств на iOS и iPadOS.
- `"vkcom"` — платформа для приложений, встроенных в [vk.ru](https://vk.ru). Используйте её только в этом случае. Она не рассчитана на адаптивный интерфейс.

По умолчанию VKUI определяет платформу по данным браузера.

### Локальное переопределение

Оберните нужную часть приложения в [`PlatformProvider`](/components/platform-provider).

## Цветовая схема

Свойство `colorScheme` задаёт цветовую схему. По умолчанию VKUI использует настройку операционной системы.

- `"light"` — светлая схема;
- `"dark"` — тёмная схема.

### Локальное переопределение

Оберните нужную часть приложения в [`ColorSchemeProvider`](/components/color-scheme-provider).

## Локализация

Свойство `locale` принимает [языковую метку BCP 47](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry). По умолчанию используется `"ru"`.

> Для интернационализации (`i18n`) и локализации (`l10n`) приложения используйте сторонние решения. Получить локаль из VKUI можно через `useLocale`.
>
> Компоненты календаря используют эту локаль для названий месяцев и дней недели.

### Локальное переопределение

Оберните нужную часть приложения в [`LocaleProvider`](/components/locale-provider).

## Направление контента

Свойство `direction` задаёт направление текста. По умолчанию VKUI определяет направление по атрибуту `dir` у `<body>`.

- `"ltr"` — слева направо, как в большинстве языков.
- `"rtl"` — справа налево, как в арабском и иврите.

### Локальное переопределение

Оберните нужную часть приложения в [`DirectionProvider`](/components/direction-provider).

## Токены тем

Свойство `tokensClassNames` задаёт CSS-классы для тем и платформ.

```jsx
<ConfigProvider tokensClassNames={{ light: 'custom-light-theme', dark: 'custom-dark-theme' }}>
  <App />
</ConfigProvider>
```

## Анимации переходов [#animation]

Задаётся свойством `transitionMotionEnabled`.

- `true` — включены анимации переходов между экранами в [`Root`](/components/root) и [`View`](/components/view);
- `false` — анимации отключены.

## WebView

Передайте `isWebView={true}`, если приложение работает внутри WebView мобильного приложения.

<Callout>
  При `isWebView={true}` и `platform="ios"` в [`View`](/components/view) можно переходить между экранами жестом смахивания.
</Callout>

## Хук useConfigProvider [#use-config-provider]

Хук `useConfigProvider` возвращает текущие настройки приложения.

```jsx
import { useConfigProvider } from '@vkontakte/vkui';
```

```jsx
const { colorScheme, platform, locale, direction, ...restProps } = useConfigProvider();
```
