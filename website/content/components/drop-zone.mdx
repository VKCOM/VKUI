# DropZone [tag:component]

Область для загрузки файлов перетаскиванием.

</Overview>

{/* @example-description: Базовая зона перетаскивания файлов с обработкой `onDrop` и списком имён файлов. */}
<Playground>

```jsx
<DropZone.Grid>
  <DropZone
    onDragOver={(event) => {
      event.preventDefault();
    }}
    onDrop={(event) => {
      event.preventDefault();

      const files = event.dataTransfer.files;
      const fileNames = Array.from(files).map((file) => file.name);
      alert(`Файлы: \n${fileNames.join('\n')}`);
    }}
  >
    <Placeholder title="Быстрая отправка">Перенесите файл сюда для быстрой отправки.</Placeholder>
  </DropZone>
</DropZone.Grid>
```

</Playground>

## Структура

`DropZone.Grid` размещает несколько зон загрузки в сетке. Свойство `direction` задаёт направление — строка или столбец. В столбце первая зона занимает всю доступную ширину.

{/* @example-description: Сетка из нескольких `DropZone` в строку через `DropZone.Grid`. */}
<Playground>

```jsx
<DropZone.Grid direction="row">
  <DropZone>
    <Placeholder title="Быстрая отправка">Перенесите файл сюда для быстрой отправки.</Placeholder>
  </DropZone>
  <DropZone>
    <Placeholder title="Быстрая отправка">Перенесите файл сюда для быстрой отправки.</Placeholder>
  </DropZone>
  <DropZone>
    <Placeholder title="Быстрая отправка">Перенесите файл сюда для быстрой отправки.</Placeholder>
  </DropZone>
  <DropZone>
    <Placeholder title="Быстрая отправка">Перенесите файл сюда для быстрой отправки.</Placeholder>
  </DropZone>
</DropZone.Grid>
```

</Playground>

## Функция-рендер

Передайте функцию в `children`, чтобы менять оформление зоны при перетаскивании. Параметр `active` показывает, находится ли файл над зоной.

{/* @example-description: Кастомное состояние зоны загрузки через функцию-рендер и флаг `active`. */}
<Playground>

```jsx
<DropZone
  onDragOver={(event) => {
    event.preventDefault();
  }}
  onDrop={(event) => {
    event.preventDefault();
  }}
>
  {({ active }) => (
    <Placeholder
      icon={<Icon56CameraOutline fill={active ? 'var(--vkui--color_icon_accent)' : undefined} />}
      title="Загрузка файлов"
    >
      {active ? 'Отпустите файлы здесь.' : 'Перенесите файл сюда.'}
    </Placeholder>
  )}
</DropZone>
```

</Playground>
