# AppRoot [tag:component]

Оберните всё приложение в [`AppRoot`](/overview/install#step4). Компонент управляет режимом встраивания, прокруткой, безопасными отступами и порталами.

</Overview>

## Режимы встраивания

Задаётся свойством `mode`.

- `"full"` — ваше приложение полностью реализовано с помощью VKUI;
- `"embedded"` — ваше приложение реализовано в виде блока, встроенного в основное приложение
  (например, Марусю или базовое приложение ВКонтакте);
- `"partial"` — ваше приложение реализовано с помощью сторонних решений и использует некоторые компоненты библиотеки VKUI.

### Full

В режиме `full`, который действует по умолчанию, VKUI управляет всей страницей. Разместите корневой элемент приложения прямо внутри `<body>`. VKUI добавит классы к `<html>` и корневому элементу.
Рекомендуем использовать его для `standalone`-проектов или при [интеграции с платформой VK Mini Apps](/integrations/vk-mini-apps).

### Embedded

В режиме `embedded` VKUI управляет только корневым контейнером и добавляет к нему классы `.vkui__root` и `.vkui__root--embedded`.

В режиме `embedded` VKUI применяет к контейнеру `transform: translate3d(0, 0, 0)`. Элементы с `position: fixed` позиционируются относительно этого контейнера.
Это поведение можно отключить с помощью свойства `disableParentTransformForPositionFixedElements`.

### Partial

Используйте `partial`, чтобы встроить небольшой блок в существующую страницу. Этот режим рассчитан на компоненты вне раздела `Layout`. VKUI не добавляет классы к `<html>` и корневому элементу.

## Визуальное оформление

Свойство `layoutMode` глобально задаёт тип оформления макета для компонентов [`Panel`](/components/panel) и [`Group`](/components/group).

- `"card"` — карточный дизайн с тенями и скруглениями;
- `"plain"` — плоский дизайн без теней и скруглений.

## Управление порталами

VKUI использует [порталы](https://react.dev/reference/react-dom/createPortal) для модальных окон, подсказок и других всплывающих элементов. По умолчанию они размещаются в `document.body`. Чтобы выбрать другой контейнер, передайте DOM-элемент или `ref`-объект в `portalRoot`.

Передайте `disablePortal`, чтобы размещать всплывающие элементы по месту объявления.

## Управление полосой прокрутки

Задаётся свойством `scroll`.

- `"global"` — приложение VKUI прокручивается вместе со страницей.
- `"contain"` — приложение прокручивается внутри `AppRoot` независимо от страницы, например внутри модального окна.

В режимах `full` и `embedded` VKUI управляет прокруткой приложения. Например, блокирует её при открытии модального окна или запоминает положение при переходе между панелями (`Panel`).

При `scroll="global"` VKUI отслеживает прокрутку страницы через `window` и `document`. При `scroll="contain"` отслеживает прокрутку корневого элемента. Это подходит для режима `embedded`.

## Безопасные отступы (safe-area-inset-\*) [#safe-area-insets]

Задаётся свойством `safeAreaInsets`.

VKUI использует переменные `safe-area-inset-*`, чтобы элементы приложения не перекрывали системные элементы и не попадали под вырезы экрана. См. [документацию CSS](https://developer.mozilla.org/en-US/docs/Web/CSS/env#safe-area-inset-top).

Если мини-приложению или встроенному интерфейсу нужны свои отступы, задайте их в `safeAreaInsets`.

```jsx
const customSafeAreaInsets = {
  top?: number;
  right?: number;
  bottom?: number;
  left?: number;
}

// Переопределяем стандартные отступы
<AppRoot safeAreaInsets={customSafeAreaInsets}>
  <App />
</AppRoot>
```

Можно переопределить только нужные отступы, например `bottom` или `top`. Остальные сохранят значения по умолчанию.

## Выделение текста

Задаётся свойством `userSelectMode`.

По умолчанию VKUI отключает выделение текста в приложениях, открытых в WebView. Чтобы изменить это поведение, задайте `userSelectMode`.

- `"enabled-with-pointer"` – разрешается выделять текст, если устройство ввода типа `pointer` (например, мышь), в остальных случаях запрещается;
- `"disabled"` – запрещается выделять текст;
- `"enabled"` – разрешается выделять текст.
