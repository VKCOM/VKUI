# PullToRefresh [tag:component]

На сенсорном устройстве пользователь тянет содержимое вниз, чтобы обновить его.

</Overview>

{/* @example-description: Базовый `PullToRefresh` с жестом обновления и контролем состояния загрузки. */}
<Playground style={{ userSelect: 'none', alignItems: 'unset', height: 150, overflow: 'auto' }}>

```jsx
const [users, setUsers] = React.useState([]);
const [fetching, setFetching] = React.useState(false);

const onRefresh = React.useCallback(() => {
  setFetching(true);

  setTimeout(() => {
    setFetching(false);
    setUsers(Array.from({ length: 20 }));
  }, 2000);
}, []);

return (
  <PullToRefresh onRefresh={onRefresh} isFetching={fetching}>
    <Box padding="system">
      {!users.length && <Text>Потяните вниз</Text>}
      {users.map((_, i) => {
        return (
          <Cell key={i} before={<Avatar />}>
            {i}
          </Cell>
        );
      })}
    </Box>
  </PullToRefresh>
);
```

</Playground>

## Обязательные свойства

### Обработчик `onRefresh`

Передайте в `onRefresh` мемоизированный обработчик, который запускает обновление данных.

## Особенности работы

### Управление состоянием

- Устанавливайте `isFetching={true}` при начале загрузки.
- Устанавливайте `isFetching={false}` после завершения загрузки.

## Доступность (a11y) [#a11y]

VoiceOver перехватывает жест обновления. Например, смахивание вниз тремя пальцами не запускает `PullToRefresh`.

Компонент добавляет кнопку «Обновить». Она появляется при переходе к ней с помощью `Tab`, а скринридер объявляет её имя. Нажатие `Enter` или пробела вызывает `onRefresh`. Пока данные загружаются, кнопка недоступна, а состояние области передаётся через `aria-busy` и `aria-live="polite"`.

Чтобы изменить имя области или кнопки, передайте `accessibilityLabel` или `refreshLabel`.

```jsx
<PullToRefresh
  onRefresh={onRefresh}
  isFetching={fetching}
  accessibilityLabel="Лента пользователей"
  refreshLabel="Обновить ленту"
>
  {content}
</PullToRefresh>
```

- `accessibilityLabel` — подпись области (по умолчанию «Обновление контента»).
- `refreshLabel` — текст кнопки (по умолчанию «Обновить»).

> Чтобы кнопка была видна постоянно, добавьте отдельную кнопку с тем же `onRefresh`, например в `PanelHeader`.
