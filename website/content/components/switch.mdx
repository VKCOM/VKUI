# Switch [tag:component]

Переключатель между двумя состояниями, например «Включено» и «Выключено».
Принимает свойства нативного `<input type="checkbox">` и поддерживает настройку внутренних элементов.

## Режим работы

Переключатель поддерживает контролируемый и неконтролируемый режимы. [Документация React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

В неконтролируемом режиме опустите `checked`. Начальное состояние можно задать через `defaultChecked`.
В контролируемом режиме передайте текущее состояние в `checked` и обновляйте его в обработчике `onChange`.

```jsx
// Неконтролируемое состояние, по умолчанию в состоянии "выбран"
<Switch defaultChecked />;

// Контролируемое состояние, значение "не выбран"
const [checked, setChecked] = React.useState(false);

<Switch checked={checked} onChange={(event) => setChecked(event.target.checked)} />;
```

## Состояния

### `disabled`

Свойство `disabled` блокирует переключатель и показывает, что он недоступен.

{/* @example-description: Пример неактивного `Switch` в состоянии `disabled`. */}
<Playground>
  ```jsx
  <Switch defaultChecked disabled />
  ```
</Playground>

## Кастомизация

Через `slotProps` передавайте свойства корневому контейнеру и скрытому `input`. Можно задать CSS-классы,
атрибуты `data-*` и `aria-*`, обработчики событий или `getRootRef` для доступа к DOM-элементу.

{/* @example-description: Кастомизация `Switch` через `slotProps` для корня и внутреннего `input`. */}
<Playground>
  ```jsx
  const inputRef = React.useRef();

  return (
    <Switch
      defaultChecked
      className="my-root-class"
      data-testid="switch-root"
      id="switch-input-id"
      slotProps={{
        root: {
          id: 'switch-root-id',
        },
        input: {
          className: 'my-input-class',
          'aria-label': 'switch',
          getRootRef: inputRef,
        },
      }}
    />
  )
  ```
</Playground>
