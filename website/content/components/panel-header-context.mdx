# PanelHeaderContext [tag:component]

Всплывающее меню для перехода между разделами приложения. Размещайте его рядом с [`PanelHeader`](/components/panel-header), чтобы открывать по нажатию на шапку.

Связанные компоненты:

- [`PanelHeader`](/components/panel-header)

```jsx
const [contextOpened, setContextOpened] = React.useState(false);

const toggleContext = () => {
  setContextOpened((prev) => !prev);
};

return (
  <Panel>
    <PanelHeader>
      <PanelHeaderContent onClick={toggleContext}>Нажми</PanelHeaderContent>
    </PanelHeader>
    <PanelHeaderContext opened={contextOpened} onClose={toggleContext}>
      <SimpleCell onClick={() => setContextOpened(false)}>Пункт один</SimpleCell>
      <SimpleCell onClick={() => setContextOpened(false)}>Пункт два</SimpleCell>
    </PanelHeaderContext>
    <Group>
      <div style={{ height: 150 }} />
    </Group>
  </Panel>
);
```

## Контент

Передайте содержимое меню в `children`. Для пунктов меню рекомендуется использовать `SimpleCell`.

## Состояния

### Раскрытие

Свойство `opened` управляет видимостью меню.

- `false` — компонент скрыт (по умолчанию);
- `true` — компонент раскрыт.

## Обработчики событий

Компонент вызывает `onClose` при нажатии за пределами меню. Передайте обработчик, который установит `opened` в `false`.

Чтобы закрывать меню после выбора пункта, вызовите тот же обработчик при нажатии на пункт.
