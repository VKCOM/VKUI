Поле для ввода диапазона дат. Начальную и конечную даты можно ввести вручную или выбрать в календаре.

## Применение компонента

> Компонент рассчитан на планшеты и настольные компьютеры. На других мобильных устройствах его работа не гарантируется.

Для выбора диапазона дат без поля ввода используйте [`CalendarRange`](/components/calendar-range).

Для ввода одной даты и времени со всплывающим календарём используйте [`DateInput`](/components/date-input).

## Режим работы

Компонент работает в контролируемом и неконтролируемом режимах. Подробнее об этих режимах читайте в [документации React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

В неконтролируемом режиме опустите `value`. Чтобы задать начальное значение, передайте `defaultValue`.
В контролируемом режиме передайте текущее значение в `value` и обновляйте его в обработчике `onChange`.

```jsx
// Неконтролируемое состояние
<DateRangeInput defaultValue={[new Date(2024, 2, 1), new Date(2024, 2, 10)]} />;

// Контролируемое состояние
const [date, setDate] = React.useState([new Date(2024, 2, 1), new Date(2024, 2, 10)]);

<DateRangeInput value={date} onChange={setDate} />;
```

## Валидация

Свойство `status` показывает результат проверки поля. Значение `"error"` отмечает ошибку, `"valid"` — успешную проверку.

> Если вы используете `DateRangeInput` вместе с [`FormItem`](/components/form-item), вам достаточно указать свойство `status` только у
> [`FormItem`](/components/form-item).

## Доступность (a11y) [#a11y]

Свойство `accessible` меняет вид календаря и управление им для пользователей ассистивных технологий. Начиная с `v8` оно включено по умолчанию. Оставляйте его включённым. В `v9` свойство планируется удалить.

При включённом `accessible`:

- Кнопка календаря видна и в пустом, и в заполненном поле.
- Календарь открывается при нажатии на кнопку календаря или на поле. Если поле в фокусе, календарь можно открыть клавишей `Space`.
- При открытии фокус переходит в календарь, при закрытии возвращается на `DateRangeInput`. Чтобы отключить захват фокуса, передайте `disableFocusTrap`. Чтобы выбрать, куда возвращать фокус, используйте `restoreFocus`.

Нажатие на связанный с полем `<label>` переводит фокус на `DateRangeInput`, но скринридер не озвучивает подпись. Чтобы скринридер мог озвучить её, продублируйте текст в `aria-label`.

```jsx
<label>
  Период проживания
  <DateRangeInput aria-label="Период проживания" />
</label>
```

```jsx
<label htmlFor="date">Срок действия договора</label>
<DateRangeInput
  id="date"
  aria-label="Срок действия договора"
/>
```

```jsx
<FormItem top="Период бронирования" htmlFor="date">
  <DateRangeInput id="date" aria-label="Период бронирования" />
</FormItem>
```

## Интернационализация (i18n) [#i18n]

> Названия месяцев и дней недели зависят от `locale` в [`ConfigProvider`](/components/config-provider).

Компонент форматирует даты через [Intl.DateTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat).
Подписи интерактивных элементов, включая календарь, переведите отдельно. Скринридеры озвучивают эти подписи, даже если их нет на экране.

Ниже перечислены основные свойства для перевода. Полный список есть в [таблице свойств](#api).

- `changeDayLabel`;
- `changeMonthLabel`;
- `changeYearLabel`;
- `changeStartDayLabel`;
- `changeStartMonthLabel`;
- `changeStartYearLabel`;
- `changeEndDayLabel`;
- `changeEndMonthLabel`;
- `changeEndYearLabel`;
- `prevMonthLabel`;
- `nextMonthLabel`;
- `clearFieldLabel`;
- `showCalendarLabel`;
- `calendarLabel`.
