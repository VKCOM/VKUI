## Режим работы

- В неконтролируемом режиме компонент хранит значение сам. Чтобы задать начальное значение, передайте `defaultValue`.
- В контролируемом режиме передайте текущее значение в `value` и обновляйте его в обработчике `onChange`.

Подробнее о режимах работы в [документации React](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable).

```jsx
// Неконтролируемое состояние
<Search defaultValue="Поиск" />;

// Контролируемое состояние
const [value, setValue] = React.useState('Поиск');

<Search value={value} onChange={(event) => setValue(event.target.value)} />;
```

## Пользовательская иконка поиска

Чтобы заменить иконку поиска, передайте её в `icon`. Для управления отрисовкой передайте в `icon` функцию. Она получит функцию отрисовки кнопки типа `RenderIconButtonFn`.

{/* @example-description: Кастомная кнопка иконки поиска с фильтрами через `Popover` в свойстве `icon`. */}
<Playground>
  ```jsx
  <Search
    defaultValue="value"
    icon={(renderButton) => (
      <Popover
        content={({ onClose }) => (
          <Box padding="system">
            <CellButton before={<Icon28TagOutline />} onClick={onClose}>
              По тегам
            </CellButton>
            <CellButton before={<Icon28CalendarOutline />} onClick={onClose}>
              По дате
            </CellButton>
          </Box>
        )}
      >
        {renderButton(<Icon24Filter />, { 'aria-label': 'Фильтры' })}
      </Popover>
    )}
  />
  ```
</Playground>

## Кнопка «Найти»

Передайте обработчик в `onFindButtonClick`, чтобы показать кнопку «Найти».

{/* @example-description: `Search` с кнопкой «Найти» и обработчиком `onFindButtonClick`. */}
<Playground>
  ```jsx
  <Search defaultValue="Поиск" onFindButtonClick={() => alert('Кто ищет, тот всегда найдёт.')} />
  ```
</Playground>

## Кастомизация

Через `slotProps` передавайте свойства внутренним элементам, например CSS-классы, атрибуты `data-*` и `aria-*` или обработчики событий. Для доступа к элементу передайте `getRootRef`.

{/* @example-description: Кастомизация внутренних слотов `Search` через `slotProps` и `getRootRef`. */}
<Playground style={{ maxWidth: 280 }}>
  ```jsx
  const inputRef = React.useRef();

  return (
    <Search
      defaultValue="Пример со slotProps"
      className="my-root-class"
      data-testid="search-root"
      id="search-input-id"
      slotProps={{
        root: {
          id: 'search-root-id',
        },
        input: {
          className: 'my-input-class',
          'aria-label': 'Пример slotProps',
          getRootRef: inputRef,
        },
      }}
    />
  )
  ```
</Playground>
