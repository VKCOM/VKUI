# Counter [tag:component]

Числовой индикатор для ячеек, кнопок и других элементов интерфейса.
Принимает отформатированные числа и текст для скринридеров.

</Overview>

{/* @example-description: Базовый счётчик уведомлений в режиме `primary`. */}
<Playground>
  ```jsx
  <Counter mode="primary">21</Counter>
  ```
</Playground>

## Использование

Передавайте число (`5`) или строку с отформатированным числом (`"1,234"`, `"5k"`).

## Режимы отображения

Задаётся свойством `mode`.

- `"primary"` — акцентный индикатор для важных уведомлений;
- `"contrast"` — индикатор контрастного цвета, заданного дизайн-системой (в стандартных темах — белый);
- `"tertiary"` — индикатор без фона для уведомлений, которые не нужно выделять;
- `"inherit"` — режим зависит от родительского компонента.

## Визуальное оформление

### Цвет

Задаётся свойством `appearance`.

#### `"accent"`

Значение задаёт индикатору акцентный цвет, который может меняться в зависимости от светлой или тёмной схемы.

{/* @example-description: Цвет `accent` для всех режимов отображения `Counter`. */}
<Playground>
  ```jsx
  <Counter appearance="accent" mode="primary">
    4
  </Counter>
  <Counter appearance="accent" mode="contrast">
    4
  </Counter>
  <Counter appearance="accent" mode="tertiary">
    4
  </Counter>
  <Counter appearance="accent" mode="inherit">
    4
  </Counter>
  ```
</Playground>

#### `"neutral"`

Нейтральный цвет можно использовать как альтернативный акцент.

{/* @example-description: Нейтральная цветовая схема `Counter` для разных `mode`. */}
<Playground>
  ```jsx
  <Counter appearance="neutral" mode="primary">
    8
  </Counter>
  <Counter appearance="neutral" mode="contrast">
    8
  </Counter>
  <Counter appearance="neutral" mode="tertiary">
    8
  </Counter>
  <Counter appearance="neutral" mode="inherit">
    8
  </Counter>
  ```
</Playground>

#### `"accent-green"`

Цвет для положительных уведомлений, обычно зелёный.

{/* @example-description: Позитивный вариант `Counter` с `appearance="accent-green"`. */}
<Playground>

#### `"negative"`

Цвет для критических уведомлений, обычно красный.

## Пользовательский цвет

Укажите `appearance="custom"` и передайте цвет в свойство `color`.

- В режиме `"primary"` меняется цвет фона.
- В режимах `"contrast"` и `"tertiary"` меняется цвет текста.
- В режиме `"inherit"`, который включён по умолчанию, настройка цвета не действует.

{/* @example-description: Пользовательский цвет счётчика через `appearance="custom"` и `color`. */}
<Playground>
  ```jsx
  <Counter appearance="custom" mode="primary" color="#FFA500">
    12
  </Counter>
  <Counter appearance="custom" mode="contrast" color="#FFA500">
    12
  </Counter>
  <Counter appearance="custom" mode="tertiary" color="#FFA500">
    12
  </Counter>
  ```
</Playground>

## Индикатор в кнопке

В кнопке индикатор подстраивается под её оформление по правилам дизайн-системы.

{/* @example-description: Примеры использования `Counter` внутри кнопок разных размеров и режимов. */}
<Playground>
  ```jsx
  <Button mode="secondary" size="m" after={<Counter>16</Counter>}>
    Secondary medium
  </Button>
  <Button mode="tertiary" after={<Counter size="s">6</Counter>}>
    Tertiary small
  </Button>
  <Button mode="outline" size="m" after={<Counter>20</Counter>}>
    Outline medium
  </Button>
  <Button mode="primary" appearance="positive" size="m" after={<Counter>4</Counter>}>
    Commerce medium
  </Button>
  <Button size="l" after={<Counter>8</Counter>}>
    Primary large
  </Button>
  ```
</Playground>

## Доступность (a11y) [#a11y]

Для скринридеров можно добавить поясняющий текст:

```jsx
<Counter mode="primary" size="m">
  5<VisuallyHidden>новых сообщений</VisuallyHidden>
</Counter>
```
