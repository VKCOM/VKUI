<Overview group="layout">
# FormLayoutGroup [tag:component]

Контейнер для нескольких полей формы (`FormItem`). Размещает их в строку или столбец.

</Overview>

{/* @example-description: Горизонтальная группировка двух полей формы в `FormLayoutGroup`. */}
<Playground>
  ```jsx
  <FormLayoutGroup mode="horizontal">
    <FormItem htmlFor="name" top="Имя">
      <Input id="name" autoComplete="given-name" />
    </FormItem>
    <FormItem htmlFor="lastName" top="Фамилия">
      <Input id="lastName" autoComplete="family-name" />
    </FormItem>
  </FormLayoutGroup>
  ```
</Playground>

## Вариант группировки

Задаётся свойством `mode`.

- `"vertical"` — поля располагаются в столбец (по умолчанию);
- `"horizontal"` — поля располагаются в строку.

На узком экране поля сжимаются пропорционально. В режиме `"horizontal"` размещайте не больше трёх `FormItem` в строке.

{/* @example-description: Вертикальная сегментированная группа связанных полей документа. */}
<Playground>
  ```jsx
  <FormLayoutGroup mode="vertical" segmented>
    <FormItem htmlFor="doctype" top="Документ, удостоверяющий личность">
      <Select
        name="form-layout-group-option-1"
        id="doctype"
        options={['Паспорт гражданина РФ', 'Загранпаспорт'].map((i) => ({
          label: i,
          value: i,
        }))}
        defaultValue={'Загранпаспорт'}
      />
    </FormItem>
    <FormItem htmlFor="docnumber">
      <Input id="docnumber" placeholder="Номер документа" />
    </FormItem>
  </FormLayoutGroup>
  ```
</Playground>

## Удаление группы

> Поддерживается только для `mode="horizontal"`.

Свойство `removable` добавляет кнопку удаления группы в стиле текущей платформы. Значение `"indent"` добавляет отступ, чтобы выровнять группу по соседним группам с кнопкой удаления.

При `removable={true}` можно использовать следующие свойства:

- `removePlaceholder` — подпись кнопки удаления (по умолчанию «Удалить»). Скринридер озвучивает её, на iOS она отображается при взаимодействии с кнопкой.
- `onRemove` — обработчик нажатия на кнопку удаления.

{/* @example-description: Удаляемая горизонтальная группа дат с кнопкой удаления группы. */}
<Playground>
  ```jsx
  <FormLayoutGroup mode="horizontal" removable onRemove={() => alert('Обработчик удаления')}>
    <FormItem top="Дата начала поездки" htmlFor="start" topMultiline>
      <DateInput id="start" disableCalendar />
    </FormItem>
    <FormItem top="Дата конца поездки" htmlFor="end" topMultiline>
      <DateInput id="end" disableCalendar />
    </FormItem>
  </FormLayoutGroup>
  ```
</Playground>

## Сегментированный вид

Свойство `segmented` визуально объединяет связанные поля в режимах `"vertical"` и `"horizontal"`. Если у `FormItem` нет `htmlFor` или `top`, см. [рекомендации по доступности](#a11y).

{/* @example-description: Сегментированная горизонтальная группа из `Input` и `Select` для единого e-mail поля. */}
<Playground>
  ```jsx
  <FormLayoutGroup mode="horizontal" segmented>
    <FormItem htmlFor="email" top="E-mail">
      <Input id="email" autoComplete="username" slotProps={{ input: { 'aria-label': 'Имя пользователя' } }} />
    </FormItem>
    <FormItem>
      <Select
        name="form-layout-group-option-2"
        id="form-layout-group-input-2"
        slotProps={{ input: { 'aria-label': 'Имя домена' } }}
        options={['@mail.ru', '@internet.ru', '@bk.ru', '@inbox.ru', '@list.ru'].map((i) => ({
          label: i,
          value: i,
        }))}
        defaultValue="@mail.ru"
      />
    </FormItem>
  </FormLayoutGroup>
  ```
</Playground>

## Тестирование

Для поиска элементов в тестах задайте идентификаторы через свойства:

- `removeButtonTestId` — `id` кнопки удаления при `removable={true}`;
- `toggleButtonTestId` — `id` кнопки подтверждения удаления (**только для iOS**).

## Доступность (a11y) [#a11y]

Компонент использует тег `<fieldset>`, которому соответствует роль [`group`](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/group_role). Задайте название группы через `aria-labelledby` или `aria-label`, описание — через `aria-describedby`.

Если в сегментированном режиме у [`FormItem`](/components/form-item) нет `htmlFor` и `top`, продублируйте текст из `placeholder` в скрытой подписи. Используйте [`VisuallyHidden`](/components/visually-hidden) и свяжите подпись с полем через `htmlFor` и `id`.
