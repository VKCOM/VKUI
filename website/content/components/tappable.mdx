# Tappable [tag:component]

`Tappable` выбирает HTML-тег по переданным свойствам и обрабатывает наведение, нажатие и фокус.
Компонент поддерживает:

- подсветку фона;
- эффект волны при нажатии на Android;
- автоматическую установку `cursor: pointer`.

На `Tappable` построены интерактивные компоненты, например [`Button`](/components/button),
[`Cell`](/components/cell) и [`ActionSheetItem`](/components/action-sheet#action-sheet-item).

## Логика выбора элемента

HTML-тег зависит от переданных свойств.

| Условия              | Тег       | Роль/Атрибуты                 | Особенности                      |
| -------------------- | --------- | ----------------------------- | -------------------------------- |
| Передан `Component`  | Кастомный | Наследует переданные свойства | Требует ручной настройки a11y    |
| Указан `href`        | `<a>`     | `role="link"` при `disabled`  | Блокировка через `aria-disabled` |
| Указан `onClick`     | `<div>`   | `role="button" tabIndex="0"`  | Обработка клавиш Space/Enter     |
| Без `href`/`onClick` | `<div>`   | -                             | Неинтерактивный контейнер        |

## Особенности состояний

### Наведение

- `hasHover` управляет реакцией на наведение.
- `hovered` включает состояние наведения.
- `hoverMode` задаёт оформление наведения. Если передать произвольную строку, компонент добавит её как CSS-класс при наведении.

### Нажатие

- `hasActive` управляет реакцией на нажатие.
- `activated` включает состояние нажатия.
- `activeMode` задаёт оформление нажатия. Если передать произвольную строку, компонент добавит её как CSS-класс во время нажатия. Свойство `activeClassName` устарело.
- `activeEffectDelay` задаёт длительность подсветки в миллисекундах.

### Focus (фокус)

Свойство `focusVisibleMode` задаёт оформление фокуса. Если передать произвольную строку, компонент добавит её как CSS-класс при `:focus-visible`.

## Скругление углов

Свойство `borderRadiusMode` управляет скруглением.

- `auto` — адаптивный режим (нет скруглений на мобильных);
- `inherit` — наследует скругление от родительского элемента.

## Взаимодействие с дочерними элементами

### Групповая подсветка

```jsx
// Родитель сохраняет hover при наведении на детей
<Tappable hasHoverWithChildren>
  <IconButton />
  <IconButton />
</Tappable>
```

### Проброс состояния

```jsx
// Дочерний элемент активирует hover родителя
<Tappable>
  <IconButton unlockParentHover />
</Tappable>
```

## Доступность (a11y) [#a11y]

### Основные принципы

- **Автоматическая семантика**

  Компонент сам выбирает подходящий HTML-тег:
  - `<a>` при передаче `href`;
  - `<div role="button">` при наличии `onClick`;
  - в остальных случаях `<div>`.

- **Блокировка элементов**

  При `disabled`:
  - Для ссылок: `aria-disabled="true"` + удаление `href`
  - Для кнопок: `aria-disabled="true"` + `tabIndex="-1"`

- **Клавиатурные события**

  Кнопки (`role="button"`) обрабатывают:
  - Нажатие клавиш `Space`/`Enter`
  - Фокус через клавишу `Tab`

### Критические правила

- **Иконки без текста**

  Всегда добавляйте текстовую метку:

  ```jsx
  // Плохо
  <Tappable><Icon16Close /></Tappable>

  // Хорошо
  <Tappable aria-label="Закрыть">
    <Icon16Close />
  </Tappable>
  ```

- **Смешение href и onClick**

  Избегайте сочетания `href` и `onClick`, чтобы сохранить семантику элемента.

  ```jsx
  // Антипаттерн
  <Tappable href="/page" onClick={handleClick} />

  // Правильно
  <Tappable href="/page">Ссылка</Tappable>
  <Tappable onClick={handleClick}>Кнопка</Tappable>
  ```

- **Кастомные элементы**

  Для нестандартных тегов явно укажите:

  ```jsx
  <Tappable Component="span" role="button" tabIndex={0} aria-label="Действие" />
  ```

### Визуальный фокус

- Настраивайте оформление фокуса через `focusVisibleMode`.
- Не переопределяйте `:focus-visible` без веской причины.
