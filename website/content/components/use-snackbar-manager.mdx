# useSnackbarManager

`useSnackbarManager` открывает, обновляет и закрывает уведомления `Snackbar`.

Связанные компоненты:

- [Snackbar](/components/snackbar)

</Overview>

import { BlockWrapper } from "@/components/wrappers";

## Быстрый старт

Вызовите хук, чтобы получить методы управления снекбарами, и добавьте возвращённый React-элемент в разметку.

```jsx
const [snackbarApi, snackbarHolder] = useSnackbarManager();

// Показать уведомление
snackbarApi.open({
  children: "Привет, мир!",
});

// Не забудьте добавить holder в JSX
return (
  <>
    {/* Ваш контент */}
    {snackbarHolder}
  </>
);
```

## API

### Параметры

Все параметры необязательны. Хук можно вызвать без аргументов — `useSnackbarManager()`.

| Параметр        | Тип                  | Описание                                                                                                                                                                     |
| --------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `limit` | `number` | Максимум одновременно открытых снекбаров для одного значения `placement`. По умолчанию — `4`. |
| `queueStrategy` | `"queue" \| "shift"` | Когда достигнут лимит, при `"queue"` новые снекбары ждут свободного места, а при `"shift"` закрывают старые. По умолчанию — `"shift"`. |
| `offsetYStart` | `string \| number` | Отступ контейнера от верхнего края страницы. Его можно использовать вместе с `FixedLayout`. |
| `offsetYEnd` | `string \| number` | Отступ контейнера от нижнего края страницы. Его можно использовать вместе с `FixedLayout`. |
| `zIndex`        | `string \| number`   | Значение `z-index` для контейнера снекбаров.                                                                                                                                 |

### Возвращаемое значение

Хук возвращает массив из двух элементов:

1. **`snackbarApi`** — методы управления снекбарами.
2. **`snackbarHolder`** — React-элемент, который нужно добавить в JSX компонента.

### Методы

#### `open(config)` — открыть снекбар

Показывает новое уведомление. Принимает те же свойства, что и компонент `Snackbar` (кроме `open` и `offsetY`).

Метод возвращает объект [OpenReturn](#open-return) для управления открытым снекбаром.

```jsx
const result = snackbarApi.open({
  children: "Операция выполнена успешно",
  action: "Закрыть",
  onActionClick: () => console.log("Кнопка нажата"),
});

// Можно сразу закрыть
result.close();
```

#### `openCustom(payload)` — открыть кастомный снекбар

Открывает снекбар со своей разметкой. [Пользовательские снекбары](#custom-snackbar).

#### `close(id)` — закрыть снекбар

Закрывает снекбар по его идентификатору.

```jsx
const result = snackbarApi.open({ children: "Уведомление" });
snackbarApi.close(result.id);
```

#### `closeAll()` — закрыть все снекбары

Закрывает все открытые снекбары одновременно.

```jsx
snackbarApi.closeAll();
```

#### `update(id, config)` — обновить свойства снекбара

Обновляет свойства открытого снекбара. Свойства `id` и `placement` поменять нельзя.

```jsx
const result = snackbarApi.open({ children: "Старый текст" });

// Позже обновляем содержимое
snackbarApi.update(result.id, {
  children: "Новый текст",
  action: "ОК",
});
```

#### `setLimit(count)` — изменить лимит снекбаров

Меняет максимальное количество одновременно открытых снекбаров.

```jsx
snackbarApi.setLimit(6); // Теперь можно показать до 6 снекбаров
```

#### `setQueueStrategy(behavior)` — изменить стратегию очереди

Выбирает поведение при достижении лимита — `"queue"` или `"shift"`.

```jsx
snackbarApi.setQueueStrategy("queue"); // Новые снекбары будут ждать
```

#### `setOffsetYStart(offset)` и `setOffsetYEnd(offset)` — изменить отступы

Задают верхний и нижний отступы контейнера со снекбарами от краёв страницы.

```jsx
snackbarApi.setOffsetYStart(60); // Отступ сверху 60px
snackbarApi.setOffsetYEnd(20); // Отступ снизу 20px
```

#### `setZIndex(zIndex)` — изменить z-index

Меняет значение `z-index` контейнера снекбаров.

```jsx
snackbarApi.setZIndex(9999);
```

### OpenReturn [#open-return]

Методы `open` и `openCustom` возвращают этот объект для управления открытым снекбаром.

| Свойство            | Тип                     | Описание                                                                                    |
| ------------------- | ----------------------- | ------------------------------------------------------------------------------------------- |
| `id`                | `string`                | Идентификатор снекбара. Если при открытии его не задали, хук создаёт его автоматически. |
| `close()`           | `() => void`            | Закрывает этот снекбар.                                                                     |
| `update(props)`     | `(props) => void`       | Обновляет свойства снекбара.                                                                |
| `onClose(resolve?)` | `(resolve?) => Promise` | Возвращает промис, который разрешается при закрытии снекбара. |

**Пример использования `onClose`:**

```jsx
const result = snackbarApi.open({ children: "Сообщение" });

// Выполнить действие после закрытия
result.onClose().then(() => {
  console.log("Снекбар закрыт!");
});
```

### Настройка лимита и стратегии очереди

{/* @example-description: Настройка лимита и стратегии очереди снекбаров (`limit` и `queueStrategy`). */}
<Playground Wrapper={BlockWrapper}>

```jsx
const [snackbarApi, snackbarHolder] = useSnackbarManager({
  limit: 2, // Максимум 2 снекбара одновременно
  queueStrategy: "queue", // Новые будут ждать
});
const [snackbarsShowed, setSnackbarsShowed] = React.useState(false);

const showMultiple = () => {
  if (snackbarsShowed) {
    snackbarApi.closeAll();
    setSnackbarsShowed(false);
    return;
  }

  setSnackbarsShowed(true);
  Promise.all([
    snackbarApi.open({ children: "Первое уведомление" }).onClose(),
    snackbarApi.open({ children: "Второе уведомление" }).onClose(),
    snackbarApi.open({ children: "Третье (будет ждать)" }).onClose(),
  ]).then(() => setSnackbarsShowed(false));
};

return (
  <>
    <Button onClick={showMultiple}>{snackbarsShowed ? 'Закрыть все' : 'Показать несколько'}</Button>
    {snackbarHolder}
  </>
);
```

</Playground>

## Пользовательские снекбары [#custom-snackbar]

Метод `openCustom` открывает снекбар со своей разметкой. Используйте его, чтобы передать дополнительные данные, задать содержимое, которое нельзя описать свойствами `open`, либо отделить вызов снекбара от его разметки.

### Как это работает

Передайте React-компонент, который выводит содержимое снекбара. Он получит:

- `snackbarProps` — свойства для `Snackbar`;
- `id` — идентификатор снекбара;
- `close()` — функцию закрытия;
- `update(props)` — функцию обновления свойств;
- дополнительные свойства, если их передали.

### Два способа использования

Чтобы передать дополнительные свойства, используйте объект настроек.

```jsx
snackbarApi.openCustom({
  component: MySnackbarComponent,
  additionalProps: {
    userName: "Иван",
  },
  baseProps: {
    // Свойства для Snackbar
    action: "ОК",
  },
});
```

Если дополнительных свойств нет, передайте компонент напрямую.

```jsx
snackbarApi.openCustom(MySnackbarComponent);
```

### Типы

**`CustomSnackbar.Payload<AdditionalProps>`** — объект с настройками:

- `component` — React-компонент, который выводит содержимое снекбара;
- `additionalProps?` — дополнительные свойства для компонента
- `baseProps?` — базовые свойства для `Snackbar`
- `id?` — идентификатор (генерируется автоматически, если не указан)

**`CustomSnackbar.Props<AdditionalProps>`** — свойства, которые получает ваш компонент:

- дополнительные свойства из `AdditionalProps`;
- `snackbarProps` — свойства для `Snackbar`
- `id` — идентификатор снекбара
- `close()` — функция закрытия снекбара;
- `update(props)` — функция обновления свойств.

> Ключи `update`, `close`, `id` и `snackbarProps` зарезервированы. Не добавляйте их в `AdditionalProps`. Типы экспортируются вместе с хуком.

### Пример с дополнительными свойствами

В примере дополнительное свойство передаёт имя пользователя.

{/* @example-description: Снекбар со своей разметкой и дополнительными свойствами. */}
<Playground Wrapper={BlockWrapper}>

```jsx
const SnackbarComponent = ({
  userName,
  update,
  close,
  snackbarProps,
}: CustomSnackbar.Props<{ userName: string }>) => {
  return (
    <Snackbar action="Хорошо" {...snackbarProps}>
      Отправлено пользователю: {userName}
    </Snackbar>
  );
};

const [snackbarApi, snackbarHolder] = useSnackbarManager();

const showSnackbar = () => {
  snackbarApi.openCustom({
    component: SnackbarComponent,
    additionalProps: {
      userName: "Иван Барышев",
    },
  });
};

return (
  <>
    <Button onClick={showSnackbar}>Показать уведомление</Button>
    {snackbarHolder}
  </>
);
```

</Playground>
