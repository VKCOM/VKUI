# LocaleProvider [tag:component]

Компонент переопределяет локаль для вложенных элементов.

</Overview>

## Локаль

Передайте в `value` строку с [языковой меткой BCP 47](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

```jsx
<LocaleProvider value="en">
  {/* часть вашего приложения, требующая переопределения локали */}
</LocaleProvider>
```

## Хук useLocale [#use-locale]

Хук `useLocale` возвращает текущую локаль.

```jsx
import { useLocale } from '@vkontakte/vkui';
```

```jsx
const locale = useLocale();
```
