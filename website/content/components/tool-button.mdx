# ToolButton [tag:component]

`ToolButton` подходит для разового действия и для переключения режима. Например, кнопка может добавлять вложение или включать форматирование.

Компонент наследует свойства [`Tappable`](/components/tappable), включая `onClick` для обработки нажатия,
`disabled` для блокировки и `href` для ссылки.

## Обязательные свойства

### Адаптивные иконки

В обязательных свойствах `IconCompact` и `IconRegular` передайте иконки для соответствующих режимов плотности. [Размеры элементов интерфейса](/overview/adaptivity#density).

## Контент

Текст кнопки передайте в `children`. Свойство `direction` управляет расположением иконки и текста.

- `row` — иконка рядом с текстом. Это значение по умолчанию.
- `column` — иконка над текстом.

{/* @example-description: Пример `ToolButton` с текстом и направлениями контента `row` и `column`. */}
<Playground style={{ width: 'unset' }}>
  ```jsx
  <ToolButton IconCompact={Icon20Add} IconRegular={Icon24Add} direction="row">
    row
  </ToolButton>
  <ToolButton IconCompact={Icon20Add} IconRegular={Icon24Add} direction="column">
    column
  </ToolButton>
  ```
</Playground>

## Режимы отображения

Оформление кнопки задаёт свойство `mode`.

- `primary` — акцентная кнопка для основного действия.
- `secondary` — кнопка с полупрозрачным фоном для второстепенного действия.
- `tertiary` — кнопка без фона для второстепенного действия.
- `outline` — кнопка с обводкой для второстепенного действия рядом с `primary` и для основного действия рядом со ссылкой.

## Визуальное оформление

### Цвет

Задаётся свойством `appearance`.

#### `"accent"`

Акцентный цвет зависит от светлой или тёмной схемы.

### Скругление

При `rounded={true}` кнопка получает скругление 50 %. Свойство не действует при `direction="column"`, если переданы `children`.

{/* @example-description: Пример круглой `ToolButton` с `rounded`. */}
<Playground style={{ width: 'unset' }}>
  ```jsx
  <ToolButton
    IconCompact={Icon20Add}
    IconRegular={Icon24Add}
    aria-label="Добавить вложение"
    rounded
  />
  ```
</Playground>

## Доступность (a11y) [#a11y]

По умолчанию `ToolButton` использует `button`. Если передать `href`, компонент использует `a`.

Компонент поддерживает стандартные ARIA-атрибуты.

> Если одновременно переданы свойства `href` и `disabled`, компонент отключает `href`,
> чтобы соответствовать требованиям доступности. По возможности избегайте такой комбинации.

### Кнопки с иконками

Если на кнопке только иконка, опишите действие в `aria-label`. Эту подпись прочитает скринридер.

```jsx
<ToolButton
  IconRegular={Icon24Add}
  IconCompact={Icon20Add}
  mode="primary"
  appearance="accent"
  aria-label="Добавить вложение"
/>
```
