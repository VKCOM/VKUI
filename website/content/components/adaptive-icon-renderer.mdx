# AdaptiveIconRenderer [tag:component]

Компонент выбирает иконку по [плотности интерфейса](/overview/adaptivity#density) — `compact` или `regular`.

Связанные страницы:

- [Адаптивность](/overview/adaptivity)

</Overview>

## Когда использовать? [#when-to-use]

Используйте меньшие иконки на настольных экранах и более крупные на мобильных. Рекомендуемые размеры указаны в документации отдельных компонентов.

## Пример использования [#example]

В примере [`AdaptivityProvider`](/components/adaptivity-provider) задаёт плотность, чтобы показать оба размера иконки. В приложении `AdaptiveIconRenderer` выбирает иконку по текущей плотности интерфейса.

{/* @example-description: Демонстрация автоматической подстановки размеров иконок для `compact` и `regular` плотности интерфейса. */}
<Playground direction="column">
  ```jsx
  <AdaptivityProvider density="compact">
    <Text>Icon size 24</Text>
    <AdaptiveIconRenderer IconCompact={Icon24SmileOutline} IconRegular={Icon28SmileOutline} />
  </AdaptivityProvider>
  <AdaptivityProvider density="regular">
    <Text>Icon size 28</Text>
    <AdaptiveIconRenderer IconCompact={Icon24SmileOutline} IconRegular={Icon28SmileOutline} />
  </AdaptivityProvider>
  ```
</Playground>

## Передача свойств в иконки [#providing-props-to-icons]

```jsx
const StyledIcon24 = (props) => <Icon24SmileOutline {...props} className="my-class-24" />;
const StyledIcon28 = (props) => <Icon28SmileOutline {...props} className="my-class-28" />;

<AdaptiveIconRenderer IconCompact={StyledIcon24} IconRegular={StyledIcon28} />;
```
