# ImageBase [tag:component]

Базовый компонент для [`Avatar`](/components/avatar) и [`Image`](/components/image). Принимает стандартные атрибуты `<img>` и позволяет размещать элементы поверх изображения.

</Overview>

{/* @example-description: Базовый `ImageBase` для отображения изображения фиксированного размера. */}
<Playground>
  ```jsx
  <ImageBase
    size={96}
    src="https://sun9-26.userapi.com/YZ5-1A6cVgL7g1opJGQIWg1Bl5ynfPi8p41SkQ/IYIUDqGkkBE.jpg"
  />
  ```
</Playground>

## Адаптивные размеры [#sizes]

Для квадратного контейнера задайте `size`. Если ширина и высота различаются, используйте `widthSize` и `heightSize`.

Атрибуты `width` и `height` задают размеры самого изображения.

Используйте предопределённые размеры (`16 | 20 | 24 | 28 | 32 | 36 | 40 | 44 | 48 | 56 | 64 | 72 | 80 | 88 | 96`).

Чтобы дизайн-система могла рассчитать радиус скругления, задавайте свои размеры числом или строкой в пикселях, например `"33px"`.

### Сохранение пропорций

Включите `keepAspectRatio` и задайте одну сторону, чтобы сохранить исходные пропорции изображения.

Чтобы занять всю ширину или высоту контейнера, передайте `"100%"` в `widthSize` или `heightSize` соответственно.

{/* @example-description: Сохранение исходных пропорций изображения через `keepAspectRatio`. */}
<Playground>
  ```jsx
  <ImageBase
    keepAspectRatio
    widthSize="200px"
    src="https://sun9-26.userapi.com/YZ5-1A6cVgL7g1opJGQIWg1Bl5ynfPi8p41SkQ/IYIUDqGkkBE.jpg"
  />
  ```
</Playground>

## Дополнительные элементы

### Иконка-заглушка

Если изображение не загружается, компонент показывает иконку из `fallbackIcon`. Подбирайте её размер по размеру изображения.

{/* @example-description: `ImageBase` с кастомной иконкой-заглушкой для отсутствующего изображения. */}
<Playground>
  ```jsx
  <ImageBase size={96} fallbackIcon={<Icon3218CircleOutline />} />
  ```
</Playground>

> Для подбора размера используйте [`getFallbackIconSizeByImageBaseSize`](#getfallbackiconsizebyimagebasesize).

### Индикатор

Индикатор в правом нижнем углу компонента:

{/* @example-description: Добавление бейджа в `ImageBase` через подкомпонент `ImageBase.Badge`. */}
<Playground>
  ```jsx
  <ImageBase
    size={96}
    src="https://sun9-26.userapi.com/YZ5-1A6cVgL7g1opJGQIWg1Bl5ynfPi8p41SkQ/IYIUDqGkkBE.jpg"
  >
    <ImageBase.Badge background="stroke">
      <Icon24StarCircleFillGreen />
    </ImageBase.Badge>
  </ImageBase>
  ```
</Playground>

> Для подбора размера используйте [`getBadgeIconSizeByImageBaseSize`](#getbadgeiconsizebyimagebasesize).

### Наложение

Используйте `ImageBase.Overlay`, чтобы добавить слой поверх изображения.

{/* @example-description: Наложение действия поверх изображения через `ImageBase.Overlay`. */}
<Playground>
  ```jsx
  <ImageBase
    size={96}
    src="https://sun9-26.userapi.com/YZ5-1A6cVgL7g1opJGQIWg1Bl5ynfPi8p41SkQ/IYIUDqGkkBE.jpg"
  >
    <ImageBase.Overlay visibility="always">
      <Icon24AddOutline />
    </ImageBase.Overlay>
  </ImageBase>
  ```
</Playground>

Свойство `visibility` задаёт видимость наложения. По умолчанию на устройствах с указателем наложение появляется при наведении (`"on-hover"`). На устройствах без указателя оно видно всегда.

Свойство `theme` задаёт цвет наложения. По умолчанию компонент наследует тему приложения.

> Для подбора размера используйте [`getOverlayIconSizeByImageBaseSize`](#getoverlayiconsizebyimagebasesize).

### Позиционированный компонент

Используйте `ImageBase.FloatElement`, чтобы разместить элемент в нужной точке поверх изображения.

{/* @example-description: Произвольный плавающий элемент поверх изображения через `ImageBase.FloatElement`. */}
<Playground>
  ```jsx
  <ImageBase
    size={96}
    src="https://sun9-26.userapi.com/YZ5-1A6cVgL7g1opJGQIWg1Bl5ynfPi8p41SkQ/IYIUDqGkkBE.jpg"
  >
    <ImageBase.FloatElement placement="top-end" inlineIndent="xs" blockIndent="xs">
      <Button size="s" mode="primary" after={<Icon16MoreHorizontal />} />
    </ImageBase.FloatElement>
  </ImageBase>
  ```
</Playground>

## Вспомогательные функции

### getBadgeIconSizeByImageBaseSize

Функция `getBadgeIconSizeByImageBaseSize` подбирает размер иконки индикатора по правилам дизайн-системы. Например, для изображения 28 × 28 пикселей она возвращает размер 12 × 12 пикселей.

```jsx
import { ImageBaseContext, getBadgeIconSizeByImageBaseSize } from '@vkontakte/vkui';

// Убедитесь, что используете контекст в компоненте или хуке, который расположен ниже `ImageBase`.
const { size } = React.useContext(ImageBaseContext);
const iconSize = getBadgeIconSizeByImageBaseSize(size);
// ИЛИ если размер изображения статичный и всегда равен одному значению
const iconSize = getFallbackIconSizeByImageBaseSize(56);

// Теперь используйте iconSize для выбора иконки в нужном размере
```

### getOverlayIconSizeByImageBaseSize

Функция `getOverlayIconSizeByImageBaseSize` подбирает размер иконки наложения. Например, для изображения 32 × 32 пикселя она возвращает размер 20 × 20 пикселей.

```jsx
import { ImageBaseContext, getOverlayIconSizeByImageBaseSize } from '@vkontakte/vkui';

// ИЛИ если размер изображения статичный и всегда равен одному значению

// Теперь используйте iconSize для выбора иконки в нужном размере
```

### getFallbackIconSizeByImageBaseSize

Функция `getFallbackIconSizeByImageBaseSize` подбирает размер иконки-заглушки. Например, для изображения 32 × 32 пикселя она возвращает размер 20 × 20 пикселей.
