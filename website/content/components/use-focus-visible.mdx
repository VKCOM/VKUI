<Overview type="hook">

# useFocusVisible

`useFocusVisible` помогает выделять элемент, который получил фокус при навигации с клавиатуры.

</Overview>

## API

### Возвращаемое значение

Хук возвращает состояние фокуса и два обработчика.

| Свойство       | Тип                           | Описание                                                       |
| -------------- | ----------------------------- | -------------------------------------------------------------- |
| `focusVisible` | `boolean`                     | Видим ли фокус при навигации с клавиатуры. |
| `onFocus`      | `(event: FocusEvent) => void` | Обработчик получения фокуса. |
| `onBlur`       | `(event: FocusEvent) => void` | Обработчик потери фокуса. |

## Особенности работы

Фокус отображается при навигации клавишами `Tab`, `Shift+Tab` и стрелками. При щелчке мышью стили фокуса не применяются.

## Рекомендации

Используйте хук для кнопок, ссылок, полей ввода и других компонентов с собственной логикой фокуса. Плавное появление фокуса можно настроить через CSS-переходы.

## Пример использования

{/* @example-description: Фокус только с клавиатуры. */}
<Playground>
  ```jsx
  const { focusVisible, onFocus, onBlur } = useFocusVisible();

  return (
    <Box
      role="button"
      tabIndex={1}
      onFocus={onFocus}
      onBlur={onBlur}
      padding="system"
      style={{
        borderRadius: '8px',
        outline: focusVisible ? "2px solid #2D81E0" : "none",
        outlineOffset: 2,
        transition: "outline 0.15s ease-in",
      }}
    >
      Сфокусируйся на меня через Tab
    </Box>
  );
  ```
</Playground>
