# ActionSheet [tag:component]

Всплывающее меню со списком действий.
Внешний вид зависит от платформы и размера экрана. На iOS компонент ведёт себя как [нативное меню действий](https://developer.apple.com/design/human-interface-guidelines/action-sheets/).
Добавляйте пункты меню с помощью [`ActionSheetItem`](#action-sheet-item).

</Overview>

```jsx
<ActionSheet mode="sheet" onClosed={() => {}}>

  <ActionSheetItem>Поделиться</ActionSheetItem>
  <ActionSheetItem>Скопировать ссылку</ActionSheetItem>
</ActionSheet>
```

<Playground>

```jsx
const [actionSheet, setActionSheet] = React.useState(null);
const targetRef = React.useRef(null);

function handleClose() {
  setActionSheet(null);
}

function handleOpen() {
  setActionSheet(
    <ActionSheet toggleRef={targetRef} onClosed={handleClose}>
      <ActionSheetItem>Слушать далее</ActionSheetItem>
      <ActionSheetItem>Поделиться</ActionSheetItem>
      <ActionSheetItem>Скопировать ссылку</ActionSheetItem>
    </ActionSheet>,
  );
}

return (
  <>
    {actionSheet}
    <Button getRootRef={targetRef} onClick={handleOpen} aria-expanded={Boolean(actionSheet)}>
      Туц-туц
    </Button>
  </>
);
```

</Playground>

Показывайте `ActionSheet`, когда нужно предложить варианты в ответ на действие пользователя. Например, при отмене редактирования письма предложите «Удалить изменения», «Сохранить черновик» и «Вернуться к редактированию».

> Apple рекомендует включать в меню не более четырёх действий, включая «Отмену».

> Для подтверждения действий и предупреждений используйте [`Alert`](/components/alert).

## Обязательные свойства

### `onClosed`

Компонент вызывает `onClosed` после завершения анимации закрытия. Удалите `ActionSheet` из DOM в этом обработчике, иначе прозрачная подложка помешает взаимодействовать со страницей и повторно открыть меню.

Функция принимает объект с информацией о причине закрытия:

```jsx
function handleClosed({ closedBy }) {
  if (closedBy === 'action-item') {
    // закрытие произошло по выбору действия из списка
  } else if (closedBy === 'cancel-item') {
    // закрытие произошло по нажатию на кнопку отмены
  } else {
    // закрытие произошло по другим причинам (например, клик вне области всплывающего окна)
  }
}
```

### `toggleRef` (якорный элемент)

Передайте в `toggleRef` ссылку на элемент, рядом с которым откроется меню в режиме `menu`. Эта ссылка нужна и когда компонент выбирает режим автоматически. Рекомендуем передавать [ref-объект](https://react.dev/learn/manipulating-the-dom-with-refs).

## Режимы отображения

Свойство `mode` задаёт режим отображения. По умолчанию компонент выбирает режим по размеру экрана.

- `"sheet"` — окно у нижнего края экрана. По умолчанию на мобильных устройствах.
- `"menu"` — меню у якорного элемента. По умолчанию на настольных устройствах.

## Шапка

Передайте заголовок меню в `title`, а описание — в `description`.

```jsx
<ActionSheet title="Выберите действие" description="Это описание для списка действий">
  <ActionSheetItem>Действие 1</ActionSheetItem>
  <ActionSheetItem>Действие 2</ActionSheetItem>
  <ActionSheetItem>Действие 3</ActionSheetItem>
</ActionSheet>
```

## Позиционирование

### `placement`

`placement` задаёт предпочтительное положение меню относительно якорного элемента. Свойство действует в режиме `menu`, в том числе при автоматическом выборе режима. Если места в заданном положении не хватает, компонент выбирает другое. Поддерживаются значения библиотеки [Floating UI](https://floating-ui.com/docs/tutorial#placements).

### `popupOffsetDistance`

Свойство `popupOffsetDistance` задаёт отступ от якорного элемента в пикселях.

## Стилизация всплывающей панели

Используйте `slotProps.dropdown.style` и `slotProps.dropdown.className`, чтобы настроить панель
с заголовком и списком действий в режимах `menu` и `sheet`:

```jsx
<ActionSheet
  toggleRef={toggleRef}
  onClosed={handleClosed}
  slotProps={{ dropdown: { style: { maxWidth: 350 } } }}
>
  <ActionSheetItem>Действие</ActionSheetItem>
</ActionSheet>
```

Ограничение ширины через `style` самого `ActionSheet` сужает также подложку и область клика снаружи.
Перенесите такие стили в `slotProps.dropdown.style`, чтобы подложка занимала всю доступную область.
В режиме `menu` стили слота имеют приоритет над одноимёнными стилями из `style`.

## Браузерные события

### Click Event

По умолчанию событие `click` не всплывает. Передайте `allowClickPropagation`, чтобы родительские элементы получали событие, например для аналитики.

## Управление фокусом

### `autoFocus`

При открытии меню компонент по умолчанию переводит фокус на первый интерактивный элемент. Чтобы отключить автоматическую установку фокуса, передайте `autoFocus={false}`.

Чтобы перевести фокус на контейнер меню, передайте `autoFocus="root"`. Так можно избежать появления подсказки у первого интерактивного элемента сразу при открытии.

### `restoreFocus`

После закрытия меню компонент по умолчанию возвращает фокус на последний активный элемент. Чтобы отключить восстановление фокуса, передайте `restoreFocus={false}`.

В `restoreFocus` также можно передать функцию. Верните `HTMLElement`, чтобы перевести фокус на этот элемент, `false`, чтобы оставить его без восстановления, или `true`, чтобы применить поведение по умолчанию.

### `timeout`

Задаёт задержку (в миллисекундах) при установке и восстановлении фокуса.

## Кнопка «Отмена» [#cancel-item]

Согласно рекомендациям **Apple**, в `ActionSheet` должен быть вариант действия «Отмена», закрывающий окно без выполнения дополнительных действий.

Передайте собственную кнопку «Отмена» в `iosCloseItem`. По умолчанию `ActionSheet` использует `ActionSheetDefaultIosCloseItem`.

> Свойство действует только на iOS в режиме `sheet`, в том числе при автоматическом выборе режима.

```jsx
import { ActionSheet, ActionSheetDefaultIosCloseItem } from '@vkontakte/vkui';

<ActionSheet
  iosCloseItem={<ActionSheetDefaultIosCloseItem>{cancelLabel}</ActionSheetDefaultIosCloseItem>}
>
  {/* ActionSheetItem */}
  {/* ActionSheetItem */}
  {/* ActionSheetItem */}
</ActionSheet>;
```

Чтобы настроить стандартную кнопку, передайте её свойства в `slotProps.iosCloseItem`.

```jsx
<ActionSheet
  slotProps={{
    iosCloseItem: {
      children: cancelLabel,
    },
  }}
>
  {/* ActionSheetItem */}
  {/* ActionSheetItem */}
  {/* ActionSheetItem */}
</ActionSheet>;
```

## Доступность (a11y) [#a11y]

- По умолчанию `ActionSheet` устанавливает `role="dialog"` и `aria-modal="true"`. Пока диалог открыт, с остальной страницей нельзя взаимодействовать. Чтобы изменить значения этих атрибутов, передайте их компоненту.
- Укажите `aria-expanded` на элементе, который открывает меню.
- При `selectable={true}` задайте всем `ActionSheetItem` одинаковый `name`, чтобы по пунктам можно было перемещаться как по группе радиокнопок.
- Для выбираемого пункта компонент использует тег `label`, в остальных случаях — `div`.
