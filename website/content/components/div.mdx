# Div [tag:component]

Обёртка со стандартными отступами для текущей платформы. Помогает выровнять содержимое по соседним компонентам VKUI.

</Overview>

{/* @example-description: Базовое использование `Div` для применения стандартных внутренних отступов. */}
<Playground>
  ```jsx
  <Div style={{ border: '1px dashed blue' }}>
    {/** !!! свойство style используется в демонстрационных целях !!! **/}
    <Div style={{ border: '1px dashed green' }}>Контент</Div>
  </Div>
  ```
</Playground>

## Пример использования

У [`Header`](/components/group#header) и [`SimpleCell`](/components/simple-cell) уже есть стандартные отступы для текущей платформы. Оберните текст или свой компонент в `Div`, чтобы выровнять его по этим элементам.

{/* @example-description: Сравнение контента без отступов и с отступами внутри `Div` в составе `Group`. */}
<Playground>
  ```jsx
  <Group layoutMode="card" header={<Header size="s">Разделы</Header>}>
    <Text>Примечание к странице без стандартных отступов</Text>
    <Div>
      <Text>Примечание к странице с отступами</Text>
    </Div>
    <SimpleCell onClick={() => {}}>Аккаунт</SimpleCell>
    <SimpleCell onClick={() => {}}>Настройки</SimpleCell>
  </Group>
  ```
</Playground>

## Альтернатива

Отступы можно задать напрямую через CSS-переменные. Для вертикальных отступов используйте `--vkui--size_base_padding_vertical--regular`, для горизонтальных — `--vkui--size_base_padding_horizontal--regular`.

```jsx filename="MyComponent.tsx"
import styles from './MyComponent.module.css';

function MyComponent({ children }) {
  return <div className={styles.paddings}>{children}</div>;
}
```

```css filename="MyComponent.module.css"
.paddings {
  padding-top: var(--vkui--size_base_padding_vertical--regular);
  padding-bottom: var(--vkui--size_base_padding_vertical--regular);
  padding-left: var(--vkui--size_base_padding_horizontal--regular);
  padding-right: var(--vkui--size_base_padding_horizontal--regular);
}
```
