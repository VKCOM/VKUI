#### Ключевые правила

| Сценарий                   | Решение                       | Почему важно                       |
| -------------------------- | ----------------------------- | ---------------------------------- |
| Глобальный подвал страницы | Один подвал на страницу       | Соответствует рекомендациям WAI-ARIA |
| Несколько подвалов         | Добавить `aria-label` каждому | Скринридеры различают разделы  |
| Декоративный элемент       | `<Footer Component="div">`    | Элемент остаётся декоративным          |

### Доступность (a11y) [#a11y]

#### Семантическая роль

По умолчанию компонент использует HTML-тег `<footer>` и добавляет `role="contentinfo"` [для Safari 13 и более ранних версий](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/footer#accessibility).

Предназначен для:

- контактной информации;
- ссылок на разделы сайта;
- копирайта и юридических данных;
- сведений о содержимом.
