# HorizontalScroll [tag:component]

Контейнер с горизонтальной прокруткой.
Поддерживает навигацию жестами и с клавиатуры. Например, внутри можно разместить список карточек [`HorizontalCell`](/components/horizontal-cell).

Связанные компоненты:

- [`HorizontalCell`](/components/horizontal-cell)

## Параметры прокрутки

### Величина прокрутки

Функции `getScrollToLeft` и `getScrollToRight` задают новое положение прокрутки при нажатии на левую и правую стрелки соответственно.

```jsx
function handleScrollToLeft(currentPosition) {
  // сдвигаем текущее положение прокрутки на 120px назад
  return currentPosition - 120;
}

function handleScrollToRight(currentPosition) {
  // сдвигаем текущее положение прокрутки на 120px вперёд
  return currentPosition + 120;
}

<HorizontalScroll getScrollToLeft={handleScrollToLeft} getScrollToRight={handleScrollToRight}>
  {/* контент для прокрутки */}
</HorizontalScroll>;
```

По умолчанию сдвиг происходит на всю ширину видимого контента.

### Длительность анимации прокрутки

Свойство `scrollAnimationDuration` задаёт длительность анимации при нажатии на стрелку. По умолчанию — 250 мс.

### Прокрутка колесом мыши

По умолчанию для горизонтальной прокрутки колесом мыши удерживайте `Shift`.

Включите `scrollOnAnyWheel`, чтобы колесо прокручивало содержимое по горизонтали без `Shift`, когда указатель находится над компонентом или его потомками.

> В области стрелок колесо прокручивает страницу по вертикали.

## Стрелки навигации

### Видимость стрелок

Задаётся свойством `showArrows`.

- `true` — стрелки показываются при наведении на компонент (по умолчанию);
- `false` — стрелки скрыты;
- `"always"` — стрелки всегда видны.

У края прокрутки стрелка в соответствующем направлении скрывается.

### Размер стрелок

Задаётся свойством `arrowSize`.

- `"s"` — уменьшенный размер;
- `"m"` — стандартный размер (по умолчанию).

### Смещение стрелок по вертикали

Свойство `arrowOffsetY` задаёт вертикальное смещение стрелок. Передайте число в пикселях или строку с токеном.
Положительное значение сдвигает стрелку вниз, отрицательное — вверх.

## Обёртка для контента

По умолчанию компонент оборачивает содержимое в `<div>`. Чтобы изменить тег обёртки, передайте его в `ContentWrapperComponent`. Например, используйте `ul`, если внутри элементы `li`.

Через `contentWrapperClassName` задайте CSS-класс обёртки, через `contentWrapperRef` получите [ссылку на её DOM-элемент](https://react.dev/learn/manipulating-the-dom-with-refs).

```jsx
const refContainer = React.useRef(null);

<HorizontalScroll
  ContentWrapperComponent="ul"
  contentWrapperRef={refContainer}
  contentWrapperClassName="custom-class"
>
  <li>Первый</li>
  <li>Второй</li>
  <li>Третий</li>
</HorizontalScroll>;
```

## Поддержка RTL

В режиме RTL направление стрелок и прокрутки меняется на противоположное.

## Тестирование (e2e) [#e2e]

Для поиска стрелок в тестах задайте их идентификаторы:

- `nextButtonTestId` — `id` стрелки навигации в направлении следующего элемента;
- `prevButtonTestId` — `id` стрелки навигации в направлении предыдущего элемента.

## HorizontalCellShowMore [#horizontal-cell-show-more]

Кнопка «Показать все» в конце списка `HorizontalScroll`.

{/* @example-description: Использование `HorizontalCellShowMore` как завершающего элемента горизонтального списка. */}
<Playground>
  ```jsx
  <HorizontalScroll getScrollToLeft={(i) => i - 120} getScrollToRight={(i) => i + 120}>
    <HorizontalCell size="m" onClick={() => {}} title="Первый">
      <Image size={88} borderRadius="l" />
    </HorizontalCell>
    <HorizontalCell size="m" onClick={() => {}} title="Второй">
      <Image size={88} borderRadius="l" />
    </HorizontalCell>
    <HorizontalCellShowMore onClick={() => {}} size="m" height={56} centered />
  </HorizontalScroll>
  ```
</Playground>

### Размеры

Задаётся свойством `size`.

- `"s"` — уменьшенный размер (по умолчанию);
- `"m"` — стандартный размер.

Если у карточек `HorizontalCell` задано `size="s"`, выберите тот же размер для `HorizontalCellShowMore`. Для остальных размеров карточек подойдёт `size="m"`.

### Высота

Задайте в `height` высоту соседних элементов.

```jsx
<HorizontalScroll>
  <HorizontalCell size="xl" title="Команда" subtitle="4 фотографии">
    <img />
  </HorizontalCell>
  <HorizontalCell size="xl" title="Медиагалерея Вконтакте" subtitle="64 фотографии">
    <img />
  </HorizontalCell>
  <HorizontalCellShowMore size="m" height={124} />
</HorizontalScroll>
```

> Свойство не имеет эффекта при `size="s"`.

### Текст

Задаётся через `children`.

- для `size="s"` по умолчанию отображается «Все»;
- для `size="m"` по умолчанию отображается «Показать все».

```jsx
<HorizontalCellShowMore size="m">Ещё</HorizontalCellShowMore>
```

### Выравнивание

Задаётся свойством `centered`.

- `false` — стандартное выравнивание (по умолчанию);
- `true` — выравнивание по центру относительно родителя.

```jsx
<HorizontalCellShowMore centered />
```
