# VK Mini Apps

[VK Mini Apps](https://vk.ru/miniapps) — кроссплатформенные мини-приложения [ВКонтакте](https://vk.ru/). VKUI изначально создавали для таких приложений. На этой странице описано, как подключить VKUI к VK Bridge, настроить навигацию и добавить виброотклик.

</Overview>

<Callout>
  Подробнее о разработке VK Mini Apps читайте в [статье «Мини-приложения» на портале VK для разработчиков](https://dev.vk.ru/mini-apps/overview).
</Callout>

## Конфигурация VKUI

<Callout>
  Рекомендуем использовать шаблон [`@vkontakte/create-vk-mini-app`](https://dev.vk.ru/ru/mini-apps/getting-started/create-vk-mini-app). В нём VKUI уже настроен, как показано ниже.
</Callout>

Установите библиотеки:

- [`@vkontakte/vk-bridge`](https://www.npmjs.com/package/@vkontakte/vk-bridge)
- [`@vkontakte/vk-bridge-react`](https://www.npmjs.com/package/@vkontakte/vk-bridge-react)

<PackageManagers
  npm="npm i --save @vkontakte/vk-bridge @vkontakte/vk-bridge-react"
  yarn="yarn add @vkontakte/vk-bridge @vkontakte/vk-bridge-react"
  pnpm="pnpm add @vkontakte/vk-bridge @vkontakte/vk-bridge-react"
/>

Получите цветовую схему и отступы безопасной зоны через хуки `useAppearance()` и `useInsets()` из `@vkontakte/vk-bridge-react`. Передайте цветовую схему в `ConfigProvider`, а отступы — в `AppRoot`. Преобразуйте результат `useAdaptivity()` с помощью `transformVKBridgeAdaptivity` и передайте полученные параметры в `AdaptivityProvider`.

```jsx filename="App.tsx"
import * as React from 'react';
import { createRoot } from 'react-dom/client';
import vkBridge, { parseURLSearchParamsForGetLaunchParams } from '@vkontakte/vk-bridge';
import { useAppearance, useInsets, useAdaptivity } from '@vkontakte/vk-bridge-react';
import { Platform, ConfigProvider, AdaptivityProvider, AppRoot } from '@vkontakte/vkui';
import { transformVKBridgeAdaptivity } from './helpers/transformVKBridgeAdaptivity';

// Инициализируем мини-приложение
vkBridge.send('VKWebAppInit');

const App = () => {
  const vkBridgeColorScheme = useAppearance() || undefined; // Вместо undefined можно задать значение по умолчанию
  const vkBridgeInsets = useInsets() || undefined; // Вместо undefined можно задать значение по умолчанию
  const vkBridgeAdaptivityProps = transformVKBridgeAdaptivity(useAdaptivity()); // Преобразуем данные VK Bridge в параметры AdaptivityProvider
  const { vk_platform } = parseURLSearchParamsForGetLaunchParams(window.location.search); // Платформа может быть указана в параметрах запуска (https://dev.vk.ru/mini-apps/development/launch-params#vk_platform)

  return (
    <ConfigProvider
      colorScheme={vkBridgeColorScheme}
      platform={vk_platform === 'desktop_web' ? 'vkcom' : undefined}
      isWebView={vkBridge.isWebView()}
      hasCustomPanelHeaderAfter={true} // Резервируем место для кнопок управления мини-приложением
    >
      <AdaptivityProvider {...vkBridgeAdaptivityProps}>
        {/* Для мини-приложений рекомендуем режим full. Он используется по умолчанию. */}
        <AppRoot mode="full" safeAreaInsets={vkBridgeInsets}>
          {/* Ваше приложение */}
        </AppRoot>
      </AdaptivityProvider>
    </ConfigProvider>
  );
};

const container = document.getElementById('root');
const root = createRoot(container); // createRoot(container!), если используется TypeScript
root.render(<App />);
```

```ts filename="./helpers/transformVKBridgeAdaptivity.ts"
import {
  type AdaptivityProps,
  getViewWidthByViewportWidth,
  getViewHeightByViewportHeight,
  ViewWidth,
} from '@vkontakte/vkui';
import type { UseAdaptivity } from '@vkontakte/vk-bridge-react';

/**
 * Преобразует данные VK Bridge в параметры AdaptivityProvider.
 */
export const transformVKBridgeAdaptivity = ({
  type,
  viewportWidth,
  viewportHeight,
}: UseAdaptivity): AdaptivityProps => {
  switch (type) {
    case 'adaptive':
      return {
        viewWidth: getViewWidthByViewportWidth(viewportWidth),
        viewHeight: getViewHeightByViewportHeight(viewportHeight),
      };
    case 'force_mobile':
    case 'force_mobile_compact':
      return {
        viewWidth: ViewWidth.MOBILE,
        density: type === 'force_mobile_compact' ? 'compact' : 'regular',
      };
    default:
      return {};
  }
};
```

## Навигация

### `View`

Включите жест возврата в приложении ВКонтакте на первой панели, чтобы пользователь мог выйти из мини-приложения. Выберите вызов VK Bridge по типу мини-приложения:

- Для _стандартного_ мини-приложения вызывайте [`VKWebAppSetSwipeSettings`](https://dev.vk.ru/bridge/VKWebAppSetSwipeSettings) с `history: true` на первой панели и `history: false` на остальных.
- Для _внутреннего_ мини-приложения вызывайте [`VKWebAppEnableSwipeBack`](https://dev.vk.ru/bridge/VKWebAppEnableSwipeBack) на первой панели и [`VKWebAppDisableSwipeBack`](https://dev.vk.ru/bridge/VKWebAppDisableSwipeBack) на остальных.

В примере показаны оба варианта. Оставьте вызов для вашего типа мини-приложения.

```jsx {15,17}
import vkBridge from '@vkontakte/vk-bridge';

const SomeViews = () => {
  const [history, setHistory] = useState(['main']);
  const activePanel = history[history.length - 1];
  const isFirst = history.length === 1;

  const go = React.useCallback((panel) => setHistory((prevHistory) => [...prevHistory, panel]), []);
  const goBack = React.useCallback(() => setHistory((prevHistory) => prevHistory.slice(0, -1)), []);
  const handleProfileClick = () => go('profile');
  const handleMainClick = () => go('main');

  React.useEffect(() => {
    // Для стандартных мини-приложений
    vkBridge.send('VKWebAppSetSwipeSettings', { history: isFirst });
    // Для внутренних мини-приложений
    vkBridge.send(isFirst ? 'VKWebAppEnableSwipeBack' : 'VKWebAppDisableSwipeBack');
  }, [isFirst]);

  return (
    <View history={history} activePanel={activePanel} onSwipeBack={goBack}>
      <Panel id="main">
        <div onClick={handleProfileClick}>Main</div>
      </Panel>
      <Panel id="profile">
        <div onClick={handleMainClick}>Profile</div>
      </Panel>
    </View>
  );
};
```

<Callout>
В примере выше история переходов хранится в состоянии React и используется для жеста возврата. На Android кнопка **Назад** обращается к [истории WebView](https://developer.mozilla.org/ru/docs/Web/API/Window/history). Если предыдущей записи нет, приложение ВКонтакте закрывает мини-приложение. Чтобы кнопка возвращала пользователя на предыдущий экран мини-приложения, используйте роутер, который записывает переходы в историю WebView, например `BrowserRouter` из `react-router`.

</Callout>

### `PanelHeader`

На каждом экране используйте [`PanelHeader`](/components/panel-header) с названием мини-приложения. Там, где пользователь может вернуться на предыдущий экран, добавьте кнопку **Назад** через [`PanelHeaderBack`](/components/panel-header#panel-header-back).

<Callout>
В правом верхнем углу `PanelHeader` приложение ВКонтакте показывает кнопки управления мини-приложением. Оставьте эту область свободной.

Задайте `hasCustomPanelHeaderAfter` в [`ConfigProvider`](/components/config-provider). VKUI скроет содержимое слота `after` и зарезервирует место для кнопок. Минимальную ширину этой области задаёт `customPanelHeaderAfterMinWidth` (по умолчанию 90 пикселей). В модальных окнах VKUI содержимое `after` остаётся видимым.

</Callout>

## Виброотклик (Taptic Engine)

VK Bridge позволяет вызвать виброотклик на устройствах, которые его поддерживают.

Функция `runTapticImpactOccurredAsync` из [`@vkontakte/vk-bridge-react`](https://www.npmjs.com/package/@vkontakte/vk-bridge-react) проверяет, поддерживает ли клиент метод [`VKWebAppTapticImpactOccurred`](https://dev.vk.ru/bridge/VKWebAppTapticImpactOccurred), и вызывает его, если метод доступен.

Например, вызовите эту функцию в обработчике `onRefresh` компонента [`PullToRefresh`](/components/pull-to-refresh).

```jsx {2,13}
import * as React from 'react';
import { runTapticImpactOccurredAsync } from '@vkontakte/vk-bridge-react';

const Users = () => {
  const [users, setUsers] = React.useState([
    { id: 1, name: 'Placeholder', avatarUrl: 'https://placehold.co/100' },
  ]);
  const [fetching, setFetching] = React.useState(false);

  const onRefresh = React.useCallback(() => {
    setFetching(true);
    // Вызываем виброотклик
    void runTapticImpactOccurredAsync('light');
  }, []);

  return (
    <View activePanel="users">
      <Panel id="users">
        <PanelHeader>Пользователи</PanelHeader>

        <PullToRefresh onRefresh={onRefresh} isFetching={fetching}>
          <Group>
            <List>
              {users.map(({ id, name, avatarUrl }, i) => {
                return (
                  <Cell key={i} before={<Avatar src={avatarUrl} />}>
                    {name}
                  </Cell>
                );
              })}
            </List>
          </Group>
        </PullToRefresh>
      </Panel>
    </View>
  );
};
```
